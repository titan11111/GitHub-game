# SPEC — 木琴とネコ（228-mokkin-neko）

- 作成: 2026-09-08
- 公開URL: https://titan11111.github.io/228-mokkin-neko/
- 実体: `index.html` 単一ファイル（外部アセット・外部CDN依存なし）

## 1. コンセプト

部屋の奥にいるネコを、手前の木琴を叩いて **60秒でくつろがせる**。
点を稼ぐゲームではなく「叩き方の質」を測るゲーム。速く叩くほど不利になる。

## 2. コアループ

木琴を叩く → 直近2.8秒の打鍵列を `judge()` がフレーズとして判定 → `apply()` がくつろぎ度を増減 →
ネコの行動（喜ぶ／首をかしげる／驚く／不機嫌／威嚇／ひっかき／噛みつき）が変わる → 演奏を調整する

## 3. 操作

| 環境 | 操作 |
|---|---|
| スマホ | 木琴（画面下部の8鍵）をタップ。バチは自動で表示・跳ね返る |
| PC | キー `A S D F G H J K`（左＝低音 → 右＝高音） |

音階は ド・レ・ミ・ファ・ソ・ラ・シ・ド（261.63〜523.25Hz）。音は Web Audio の合成音（音源ファイルなし）。

## 4. ルール

- 制限時間 **60秒**、くつろぎ度は **50 から開始**、範囲 0〜100
- 無操作の静けさでも回復するが、**上限50まで**（放置で勝てない）
- 加点フレーズは 0.65 秒に1回までしか加算しない（連打で稼げない）

### フレーズ判定（`PAT`）

| キー | 条件の要旨 | 増減 |
|---|---|---|
| `drift` しずかな間 | 打鍵の間隔が空く | +5 |
| `down` 下りの音階 | 3打が下降 | +5 |
| `low` 低音のゆらぎ | 低い3鍵をゆっくり | +4 |
| `slow` ゆっくりの間 | 間隔 1.2秒超 | +3 |
| `chord` ふたつ同時 | 0.09秒未満の別音 | +2 |
| `up` のぼる音階 | 3打が上昇 | +2 |
| `leap` 大きな跳躍 | 4鍵以上飛ぶ | 0 |
| `same` 同じ音の連打 | 同音3連 | −7 |
| `high` 高音の連続 | 右2鍵を1.2秒未満で連続 | −9 |
| `rush` 速すぎる連打 | 0.65秒に3打以上 | −12 |

**優先順位**: `rush` は `chord`・音階ボーナスより先に成立する（高速交互連打で稼げない）。

### ネコの攻撃条件

1. くつろぎ度 **30未満** で初回のみ **威嚇（シャーッ）**。1.6秒後を攻撃可能時刻とする
2. 威嚇済み・**25未満**・攻撃可能時刻を過ぎている → **ひっかき／噛みつき**を交互に。次の攻撃まで3秒
3. 行動中（`actionEnd` まで）は毎打鍵で上書きしない
4. 穏やかな演奏に戻すと警戒姿勢を解いて定位置へ戻る

流血・負傷の描写はなし。コミカルな演出に留める。

## 5. 結果（`TIERS`）

| くつろぎ度 | 評価 |
|---|---|
| 85以上 | 完全にとろけた |
| 65以上 | ごきげん |
| 45以上 | まあまあ |
| 25以上 | そわそわ |
| 25未満 | 不機嫌（ゴロゴロ音は鳴らさない） |

再挑戦時は行動・攻撃回数・バチ・文字送りタイマーをすべて初期化する。

## 6. iOS要件（適用済み）

- `viewport-fit=cover` ＋ `env(safe-area-inset-top)`
- `touch-action:none` / `user-select:none` / `-webkit-touch-callout:none` / `-webkit-tap-highlight-color:transparent`
- `contextmenu`・`dblclick` を `preventDefault`（ダブルタップ拡大の防止）
- `pointerdown` で入力を取り、開始タップで `AudioContext` を生成・`resume()`
- 画面回転対応（縦・横）。横画面ではネコを縮小して木琴との重なりを減らす
- `prefers-reduced-motion` を参照
