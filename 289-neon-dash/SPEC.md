# SPEC — 289｜LUNAR STRIKER（月面機動ロボ）

- 作成日: 2026-10-03（旧「NEON DASH 99」を置き換え。フォルダ番号・フォルダ名は変更しない）
- ベース: `robot-action.html`（SVGロボのモーション試験。機体・関節アニメ・入力をそのまま継承）
- ジャンル: 横スクロール宇宙アクション（エンドレス＋定期ボス）
- 想定プレイ時間: 1回1〜4分

## 0. 操作/設定UI（最初に決める）

| 項目 | 決定 |
|---|---|
| 入力方式 | DOMボタン6個（◀ ▶ しゃがむ ／ ショット ダッシュ ジャンプ）。Pointer Events＋`setPointerCapture`。キーボード併用（←→/AD、↓/S、Space/↑/W、J/Z、K/X/Shift） |
| 配置 | 縦持ち＝画面の下に2クラスタ（親指圏）。横持ち（高さ520px以下）＝画面の左右にクラスタを振り分け |
| ポーズ | ヘッダーの「ポーズ」ボタン／P・Esc。`visibilitychange` でも自動ポーズ。ポーズ中は AudioContext を suspend |
| ミュート | ヘッダーの「音 ON/OFF」ボタン／M。master gain を 0 にする |
| 保存 | `tg.289.best`（ベストスコア）／`tg.289.mute`（ミュート状態） |
| 音声unlock | 最初の pointerdown / keydown で `unlock()`（audioInit → resume → bgmStart） |

## 1. コアループ

右へ進むほど敵が濃くなる。撃つ（立ち／しゃがみで高さが変わる）・跳ぶ（2段）・ダッシュ（無敵）の3択を、敵の高さと種類で使い分ける。

## 2. 敵とギミック

| 種類 | 対処 |
|---|---|
| ドローン（空中・HP1） | 高さ226=立ち撃ち、262=しゃがみ撃ち、それ以外はジャンプ撃ち。Lv1以降は狙い撃ちしてくる |
| ウォーカー（地上・HP3） | 撃って倒す。水平弾は**しゃがむと頭上を通過** |
| 結晶スパイク（地上・破壊不可） | ジャンプで越える／ダッシュで抜ける |
| 隕石 | 着弾地点に警告マーカー。撃ち落とすか離れる |
| ガンシップ（ボス・HP30） | 600m地点、以後は撃破から800mごと。3way弾＋隕石。撃破で回復カプセル |

- HP5。被弾後1.3秒無敵。ダッシュ中は無敵
- スコア = 走行距離(m) ＋ 撃破点（ドローン100／隕石150／ウォーカー300／ボス2000）

## 3. 背景（3枚重ね＋足場）

| 層 | 内容 | スクロール率 |
|---|---|---|
| ① 星空 | 天の川状の星雲・星900個・輝星・暗黒帯。実行時に瞬きと流れ星を加算 | 0.035 |
| ② 月 | 巨大な月（海・クレーター46個・光条・欠け際の陰影・ハロー）＋環のある惑星＋小さな衛星 | 0.07 |
| ③ 岩の大地 | 岩塊（明暗2面＋稜線の縁光＋亀裂）を重ねた遠近2本の稜線、尖塔岩、テーブル岩、霞 | 0.32 |
| 足場 | 月面の地表帯（クレーター・小石）＋断崖（地層・亀裂・発光鉱脈） | 1.0 |

すべて起動時にオフスクリーンcanvasへ1回だけ描き、毎フレームは `drawImage` のみ（画像ファイル0本）。

## 4. 描画構成

canvas(背景・敵) ＋ SVG(ロボ・残像) ＋ canvas(弾・爆発・粒子・ビネット) の3枚重ね。論理解像度 640×400、内部2倍。

## 5. 画面

- タイトル: ロボの自動デモが背景で流れる → 「タップでスタート」
- プレイ: 左上HP、右上SCORE/距離
- ゲームオーバー: スコア・ベスト・「もういちど」
