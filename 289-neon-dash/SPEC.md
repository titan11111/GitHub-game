# SPEC — 289｜NEON DASH 99

- 作成日: 2026-09-06
- フォルダ: `289-neon-dash`
- ジャンル: ワンタップ・ランナー
- 想定プレイ時間: 1回30秒〜2分

## 1. コアループ（何が面白いか）

「跳ぶ／跳ばない」の二択しかないのに、低い障害物（跳ぶ）と上のバー（跳ばない）が交互に来るのでリズムが生まれる。光のリングをくぐるとコンボと加速が乗り、欲張るほど速くなって危険になる——リスクとリターンが1本の指の中で完結する。

## 2. 操作

- タップ: ジャンプ（押している時間が長いほど高く跳ぶ）
- 空中でもう一度タップ: 二段ジャンプ（残数を頭上のドットで表示）
- 離す: 上昇を打ち切って早く落ちる

片手・親指1本で完結。二本指操作・スワイプジェスチャ・長い説明文を必要としない。

## 3. ルール

- 低いブロックはジャンプで越える／高いバーは跳ばずにくぐる
- 光のリングを通ると距離ボーナス＋一時加速、5連続ごとにCOMBO演出
- 障害物に触れた瞬間に終了。スコアは走行距離(m)

## 4. 難易度カーブ

速度は 340 → 760px/s へ経過時間で線形に上がり上限で頭打ち。リング取得の加速は最大+150で減衰するため「上手い人ほど速い＝自分で難易度を上げている」形にした。

## 5. 手応え設計（ゲームデザイナー観点）

- ジャンプは押した長さで高さが変わる可変ジャンプ（固定ジャンプは操作感が痩せる）
- 着地・ジャンプ・被弾それぞれに別の音と粒子
- 残ジャンプ数を頭上ドットで可視化し、二段ジャンプの有無を考えずに済むようにした
- 画面下のスピードバーで「今どれだけ速いか」を常時提示

## 6. 画面構成

- タイトル: 番号 / タイトル / 一行コンセプト / 操作3行 / 「タップでスタート」
- プレイ: 左上にDISTANCE、右上にBEST、それ以外はゲーム画面
- リザルト: スコア / ベスト / ハイスコア更新演出 / 「タップでリトライ」

## 7. 技術

- 単一 `index.html`（共通ミニエンジンをインライン同梱）
- Canvas 2D / requestAnimationFrame / dt上限0.05秒でタブ復帰時の暴走を防止
- 音: WebAudioのオシレータ＋ノイズ合成（音声ファイル0本）
- 保存: localStorage にベストスコアのみ
- iOS: `touch-action:none` / `gesturestart`と`dblclick`のpreventDefault / safe-area padding / devicePixelRatio上限2.5
