## 0. 操作/設定UI（最初に決める）

画面下は「コックピットの操作卓」1枚に整理（2026-10-03 改訂）。

| 項目 | 決定 |

| START | 開始／ポーズ／再開／リトライ。`visibilitychange` でも自動ポーズ。ポーズ中は AudioContext を suspend |
| ミュート | ヘッダー右の「音 ON/OFF」／M。master gain を 0 に |
| 保存 | `tg.289.best` / `tg.289.mute` / `tg.289.robo` |
| キーボード | ←→↑↓/WASD/Space(上)、J・Z=A、K・X=B、C・Shift・Tab=SELECT、Enter=START、P・Esc=ポーズ |
| iOS | viewport（拡大禁止・viewport-fit=cover）、safe-area、300msダブルタップ防止、dblclick/contextmenu/touchmove/gesturestart 抑止、全ボタン pointerdown 即反応、押下時 scale＋`navigator.vibrate`、WebAudio unlock |

## 1. ロボ3機

| 機体 | A | B | Bため（0.75秒） |
|---|---|---|---|
| **A ストライカー**（白） | ショット（押しっぱなし連射） | ダッシュ（無敵） | **ブーストラッシュ**（無敵の体当たり。盾ごと粉砕） |
| **B クラッシャー**（赤・格闘） | パンチ | キック | **ムーンサルト**（無敵の後方宙返り→着地で衝撃波） |
| **C アーセナル**（金・多武装） | ホーミング弾（**ファンネルから発射**・威力は半分・連射） | 2連弾 | **ギャラクシー砲**（約1秒の極太ビーム。使用後2.2秒は再チャージ不可） |

- ロボCは**ファンネル**を2基（パワーLv3で3基）従える。機体の後ろを漂い、ホーミング弾はファンネルから順番に出る。ため中とギャラクシー砲の発射中は銃口の周りに集まって回る
- ロボBは状態で技が変わる：立ち／ジャンプ／しゃがみ × パンチ／キック の6種。しゃがみキックは足元、しゃがみパンチは低空の敵に届く
- ロボBの打撃は敵弾を打ち消す。結晶スパイクは打撃・ムーンサルト・ギャラクシー砲で壊せる（通常弾は通過）
- ダメージ：ショット2／ホーミング1／2連弾 2×2／パンチ4／キック6／ムーンサルト8＋着地6／ギャラクシー砲 毎秒45
- 敵の耐久：ドローン2／隕石2／スパイク6／ウォーカー6／ボス60
- ボスは5〜7秒ごとに自機の目の前まで降りてくる（格闘が届く間合いを作るため）

## 2. ステージ進行（2026-10-03 拡張）

| 面 | 見た目 | ボスまで | 新しく出る敵 | ボス |
|---|---|---|---|---|
| STAGE 1 月面 | 元の配色 | 400m | ドローン／ウォーカー／結晶スパイク／隕石 | **ガンシップ**（耐久60）：3way弾・隕石・突進 |
| STAGE 2 蒼の氷原 | 星空・岩・足場を青へ色替え | 450m | **シールダー**／**ホッパー** | **クラブ・タンク**（95）：踏みつけ衝撃波・迫撃弾3連・突進 |
| STAGE 3 紅の要塞宙域 | 赤へ色替え＋赤い月 | 500m | **砲台** | **要塞コア**（130）：回る盾2枚・高低2種の掃射レーザー・全方位弾・増援 |

- **ボス戦の入り**: 規定距離で画面スクロールが止まる → WARNING → 上下に黒帯が入り、ボスが右から約3.4秒かけて進入（この間は無敵・攻撃なし）→ BATTLE START。戦闘中は画面固定で、自機は画面内を自由に動ける
- **足場2つ**: ボス登場と同時に浮遊足場が下からせり上がる。低い足場（高さ80・1回のジャンプで届く）と高い足場（高さ150・低い足場から1回のジャンプ、または地上から2段ジャンプ）。下からはすり抜けて乗れ、**足場の上で下を押すと降りる**（足場の上ではしゃがめない）。衝撃波や低いレーザーは足場の上でかわせる。ボス撃破で消える
- ボス撃破 → STAGE CLEAR → **強化を3択から1つ** → 次の面（HP+1回復）。3面クリアで MISSION COMPLETE → 2周目（敵の耐久1.5倍・全種類の敵が最初から出る）
- 色替えは面の切替時に1回だけ（canvas の `color` 合成で事前描画レイヤーを塗り直す）。実行時コストは増えない

### 敵

| 種類 | 対処 |
|---|---|
| ドローン（空中） | 高さ226=立ち撃ち、262=しゃがみ撃ち、それ以外はジャンプ撃ち |
| ウォーカー（地上） | 撃って倒す。水平弾は**しゃがむと頭上を通過** |
| 結晶スパイク | 跳ぶ／ダッシュで抜ける／打撃・特殊技で壊す |
| 隕石 | 落下点に警告。撃ち落とすか離れる |
| **シールダー** | 正面からの弾は盾が弾く。**背後から撃つ**／打撃で盾を割る（キック2発）／ため技は盾ごと貫通 |
| **ホッパー** | 飛びかかってくる。地上では背が低く立ち撃ちが当たらない。空中を撃つ／ホーミング／しゃがみキック |
| **砲台** | 山なりの迫撃弾。**しゃがみ撃ちの高さ**でしか当たらない。足を止めない |

### 成長

- **パワーチップ**: 敵を倒すと出る（近づくと吸い寄せ）。7枚でLv2、20枚でLv3。**被弾で5枚失う**

| 機体 | Lv2 | Lv3 |
|---|---|---|
| A | ショット威力1.5倍 | 3方向ショット |
| B | 打撃1.5倍・間合い+8 | 打撃2倍・パンチから拳圧が飛ぶ・ムーンサルト衝撃波拡大 |
| C | ホーミング2発・2連弾威力1.5倍 | ホーミング3発・3連弾・ギャラクシー砲 太さと威力1.8倍 |

- **面クリア強化（3択）**: 装甲強化（最大HP+1・全回復、上限8）／出力強化（パワーLvの下限+1）／急速チャージ（ため速度+35%）
- スコア = 走行距離(m) ＋ 撃破点 ＋ チップ10点。ボスは 2000×面数

## 4. 描画構成

canvas(背景・敵) ＋ SVG(ロボ・残像) ＋ canvas(弾・爆発・粒子・ビネット) の3枚重ね。論理解像度 640×400、内部2倍。

## 5. 画面

- タイトル: ロボの自動デモが背景で流れる → SELECTで機体を選び START
- プレイ: 左上HP・機体名・パワーLv・ためゲージ、右上SCORE／面と距離。ボス戦は上部に名前とHPバー
- 面クリア: 強化3択（十字キー左右＋A、またはカードを直接タップ）
- ゲームオーバー: スコア・ベスト・「もういちど」
