**機体別の個性**

| 機体 | 最大HP | 走る速さ | ジャンプ |
|---|---|---|---|
| A | 標準（5） | 標準 | 標準 |
| B | **+1** | 0.92倍 | 標準 |
| C | **−1** | 標準 | 標準 |

- 機体を切り替えても回復はしない（上限を超えた分だけ切り捨て）
- ロボCは**ファンネル**を2基（パワーLv3で3基、Lv4で4基）従える。機体の後ろを漂い、ホーミング弾はファンネルから順番に出る。ため中とギャラクシー砲の発射中は銃口の周りに集まって回る
- ロボBは状態で技が変わる：立ち／ジャンプ／しゃがみ × パンチ／キック の6種。しゃがみキックは足元、しゃがみパンチは低空の敵に届く
- ロボBの打撃は敵弾を打ち消す。結晶スパイクは打撃・ムーンサルト・ギャラクシー砲で壊せる（通常弾は通過）
- ダメージ（2026-10-03 再調整）：ショット2／ホーミング1／2連弾 2×2／**パンチ6＋拳圧3**／**キック10**／**斬撃6**／ムーンサルト14＋着地6／ギャラクシー砲 毎秒45
- **パンチは常に拳圧が飛ぶ**（Lv1から。約170px先まで届く）。打撃の間合いも拡大（パンチ64→84、キック78→96）
- ため技のボスへのダメージは別枠で大きい：ムーンサルト30＋着地18／ブーストラッシュ24／月光斬30／ギャラクシー砲は1.3倍
- ボスが自機の前へ降りてくる間隔を短縮（5〜8秒 → 3.2〜5.5秒）
- 目安（パワーLv2・無敵の自動操作で攻撃し続けた場合の STAGE 1 ボス撃破時間）：射撃A 28秒／C 24秒／パンチ連打 15秒／キック連打 17秒／斬撃連打 15秒
- 敵の耐久：ドローン2／隕石2／スパイク6／ウォーカー6／ボス60
- ボスは5〜7秒ごとに自機の目の前まで降りてくる（格闘が届く間合いを作るため）

- **最終ボス**: 第1形態＝地上の皇帝機（低い突進斬り〔予告帯あり・足場の上なら当たらない〕／3way弾×2／踏みつけ衝撃波）。耐久が半分になると変形（1.6秒無敵・FINAL PHASE）。第2形態＝飛行（ビット3基の狙い撃ち／高低の掃射レーザー／全方位12発／隕石／降下）
- ボス出現時、画面内の排熱口とレーザーゲートは消える（ボス戦に持ち込まない）
- 背景は面の切替時に1回だけ描く（実測 3〜12ms）。毎フレームの負荷は変わらない

- **ボス戦の入り**: 規定距離で画面スクロールが止まる → WARNING → 上下に黒帯が入り、ボスが右から約3.4秒かけて進入（この間は無敵・攻撃なし）→ BATTLE START。戦闘中は画面固定で、自機は画面内を自由に動ける
- **足場2つ**: ボス登場と同時に浮遊足場が下からせり上がる。低い足場（高さ80・1回のジャンプで届く）と高い足場（高さ150・低い足場から1回のジャンプ、または地上から2段ジャンプ）。下からはすり抜けて乗れ、**足場の上で下を押すと降りる**（足場の上ではしゃがめない）。衝撃波や低いレーザーは足場の上でかわせる。ボス撃破で消える
- ボス撃破 → STAGE CLEAR → **強化を3択から1つ** → 次の面（HP+1回復）。5面クリアで MISSION COMPLETE → 2周目（敵の耐久1.5倍・全種類の敵が最初から出る）
- 色替えは面の切替時に1回だけ（canvas の `color` 合成で事前描画レイヤーを塗り直す）。実行時コストは増えない

## 4. 描画構成（2026-10-03 軽量化で作り替え）

- **canvas 1枚**（不透明）に 背景 → 敵 → 残像 → 自機 → 弾・爆発 → 画面効果 の順で描く。SVGと前景canvasは廃止。ビネットはCSSの重ね（毎フレームの描画なし）
- 自機は `robot-action.html` のSVGと同じ部品・同じ関節を canvas で描く。**大きさは 0.8倍**（`RK`）。当たり判定・銃口・打撃の届く高さも 0.8倍に合わせ、敵の高さ（ドローン・ウォーカーの弾・高いレーザー）を合わせ直した
- 論理解像度 640×400、内部2倍。**フレームが重い状態が1.6秒続くと内部解像度を 2 → 1.5 → 1 と自動で下げ**、それでも重ければ軽量モード（粒子と加算合成の重ね描きを減らす）
- 敵・足場のグラデーションは1回作って使い回す

### 操作の即応性

- ジャンプの先行入力（着地の0.13秒前に押しても跳ぶ）、足場の端から落ちた直後0.09秒は跳べる
- 打撃（ロボB・D）の先行入力0.16秒：連打がつながる
- ヒットストップを短縮（撃破 35ms→12ms、打撃 50ms→20ms、ボス撃破 100ms→60ms）
- コマ落ちしてもゲームの速さを落とさない（1フレームの上限を33ms→50msにし、長いフレームは2回に分けて計算）
- STAGE 2 の滑りを弱めた

## 5. 画面と演出（2026-10-03 追加）

- **タイトル**: 機体選択カード4枚（機体の絵・名前・耐久/速さ/跳躍のバー）。十字キー左右／SELECT／カードのタップで選び、START。背景では選んだ機体の自動デモが流れる

- **エンディング**: 最終ボス撃破で MISSION COMPLETE、面の戦績と通算の戦績、背景に祝砲 → 「2周目へ」→ 強化3択 → 2周目
- **ゲームオーバー**: スコア・到達面・通算撃破・TIME・ベスト
