# SPEC — 298｜STAR SHOOTER

- 作成日: 2026-09-06
- フォルダ: `298-star-shooter`
- ジャンル: 縦スクロールシューティング
- 想定プレイ時間: 1回1〜5分

## 1. コアループ（何が面白いか）

シューティングの「撃つ」を自動化して、「避ける」だけに集中させた。自機は指の46px上に出るので指で隠れない。30秒ごとのボスが明確な区切りとご褒美（大量得点＋強化アイテム2個）になっていて、続けたくなる。

## 2. 操作

- ドラッグ: 自機を指の少し上に追従させて移動
- 弾は常時オート連射（発射操作は不要）
- 指を離しても自機はその場に留まる

片手・親指1本で完結。二本指操作・スワイプジェスチャ・長い説明文を必要としない。

## 3. ルール

- 敵弾・敵本体に当たるとライフ-1（3機）、被弾でショットLvが1下がる
- Pアイテムでショット強化（最大Lv.4／最大時は+300点）
- 28秒ごとにボス出現。撃破で1200×ボス番号の得点

## 4. 難易度カーブ

雑魚の出現間隔は0.95秒→0.32秒、落下速度も時間で増加。ボスはHPが40ずつ増え、弾幕は3パターン（自機狙い5way／全方位12way／降り注ぎ）を周回、発射間隔がボスごとに0.12秒短くなる。

## 5. 手応え設計（ゲームデザイナー観点）

- 自機を指の上へオフセットしたのが最大の操作性設計（指の下だと自分の弾も敵弾も見えない）
- 被弾後1.8秒の無敵と点滅で、事故連鎖を防ぐ
- 敵弾は外周グローを付けた赤い球で、背景の星と絶対に混ざらない
- ボス出現時はWARNING表示とHPバーで、状況の切り替わりを明示

## 6. 画面構成

- タイトル: 番号 / タイトル / 一行コンセプト / 操作3行 / 「タップでスタート」
- プレイ: 左上にSCORE、右上にBEST、それ以外はゲーム画面
- リザルト: スコア / ベスト / ハイスコア更新演出 / 「タップでリトライ」

## 7. 技術

- 単一 `index.html`（共通ミニエンジンをインライン同梱）
- Canvas 2D / requestAnimationFrame / dt上限0.05秒でタブ復帰時の暴走を防止
- 音: WebAudioのオシレータ＋ノイズ合成（音声ファイル0本）
- 保存: localStorage にベストスコアのみ
- iOS: `touch-action:none` / `gesturestart`と`dblclick`のpreventDefault / safe-area padding / devicePixelRatio上限2.5
