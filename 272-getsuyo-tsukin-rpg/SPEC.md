## 4. 操作／設定UI（コントロールパネル）

**実装の1手目はここ**（鉄則4）。`public/static/js/controls.js` に集約し、UIはJSから注入する
（原本の `scripts/template.html` と `index.tsx` を書き換えないため）。

| 入力 | キーボード | 画面（スマホ） |
|---|---|---|
| 移動 | W A S D / ↑←↓→ | 左下の十字キー（アナログ・中央デッドゾーン0.22） |
| 走る | Shift（押しっぱなし） | 緑「走」（押しっぱなし） |
| ジャンプ | Space | 青「跳」 |
| 調べる／攻撃 | E | 橙「Ⓔ」 |
| ダイアログ送り | Space / E / Enter | 画面のどこでもタップ |
| 一時停止 | P / Esc | 右上 ⏸ |
| ミュート | M | 右上 🔊 |

- 入力は **Pointer Events に統一**し、十字キー・全ボタンで `setPointerCapture` を張る（押しっぱなしバグ対策）
- `visibilitychange` で自動ポーズ、`blur` でキーを落とす
- **明示ポーズあり**（`#pause-veil`）。ポーズ中は時計も止まる

### localStorage キー（鉄則: `tg.<番号>.<key>`）

| キー | 中身 |
|---|---|
| `tg.272.mute` | ミュート状態 |
| `tg.272.best` | 自己最高スコア |
| `tg.272.runs` | プレイ回数 |
| `tg.272.results` | 記録（上位20件）。`index.tsx` の `POST /api/results` と同じ形（ending / score / arrive_min / quests / created_at） |
