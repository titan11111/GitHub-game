# SPEC — 297｜SUSHI CATCH

- 作成日: 2026-09-06
- フォルダ: `297-sushi-catch`
- ジャンル: キャッチ / 判断アクション
- 想定プレイ時間: 1回60秒〜（注文達成で延長）

## 1. コアループ（何が面白いか）

「落ちてくるものを取る」だけのゲームに、『取ってはいけないものがある』を足しただけで一気に脳が働く。注文表を見る→落下物を判別する→皿を動かす、が1秒以内に回り続ける。注文を完成させると時間が6秒延びるので、上手い人ほど長く遊べる。

## 2. 操作

- ドラッグ: 皿を左右に移動（画面のどこを触ってもよい）
- タップ: その位置へ皿を即移動

片手・親指1本で完結。二本指操作・スワイプジェスチャ・長い説明文を必要としない。

## 3. ルール

- 注文にあるネタを受けると加点（コンボで加算増）
- 注文外のネタ／わさび爆弾を受けるとライフ-1、3回で終了
- 注文を全部そろえると+500点・残り時間+6秒・次の注文へ
- 制限時間60秒。時間切れはCLEAR扱い

## 4. 難易度カーブ

注文の種類数は1→3、必要個数は2→5へ増加。落下速度は注文ごとに+9px/s、出現間隔は0.72秒→0.24秒。わさび爆弾の出現率は6%→最大20%。

## 5. 手応え設計（ゲームデザイナー観点）

- いま必要なネタには黄色い枠が点滅する（注文表を見なくても分かる二重表示）
- 注文にあるが個数を満たした余りは減点せず+10点（理不尽さの排除）
- ネタは名前を漢字かなで直接書いてあるので、色だけに頼らず判別できる
- 受けた瞬間に皿が跳ねる／ミスは画面が赤くフラッシュ

## 6. 画面構成

- タイトル: 番号 / タイトル / 一行コンセプト / 操作3行 / 「タップでスタート」
- プレイ: 左上にSCORE、右上にBEST、それ以外はゲーム画面
- リザルト: スコア / ベスト / ハイスコア更新演出 / 「タップでリトライ」

## 7. 技術

- 単一 `index.html`（共通ミニエンジンをインライン同梱）
- Canvas 2D / requestAnimationFrame / dt上限0.05秒でタブ復帰時の暴走を防止
- 音: WebAudioのオシレータ＋ノイズ合成（音声ファイル0本）
- 保存: localStorage にベストスコアのみ
- iOS: `touch-action:none` / `gesturestart`と`dblclick`のpreventDefault / safe-area padding / devicePixelRatio上限2.5
