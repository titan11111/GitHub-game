## 0. この版で何が変わったか（2026-09-26・タイタン指示）

前版は **「端島漂着」＝一人称サバイバル**（遭難→水分・体温・体力・出血の4軸管理→ゴムボートで脱出）だった。
タイタン指示により、**物語をまるごと「子供のかくれんぼ」へ差し替える**。

| | 前版（端島漂着） | 本版（端島かくれんぼ） |
|---|---|---|
| 主人公 | 遭難した大人 | 鬼になった子供（目線 1.28m） |
| 目的 | 生きて島から脱出する | **日暮れまでに5人を見つける** |
| 緊張の源 | 脱水・低体温・失血 | **残り時間と、落ちていく光** |
| 敗北 | 死ぬ | 死なない。**日が落ちて終わる** |
| 様式 | 徹底したリアル（彩度を落とす） | **和風サイバーパンク**（下記 §7） |

### タイタンの決定（2026-09-26 ヒアリング結果）

1. **生存要素は全撤去**。水分・体温・出血・缶詰・貯水槽・ゴムボート脱出をすべて削除。残すのは「息切れ（走ると切れる）」だけ
2. **子供たちはただの子供**。生きている6人。幽霊でも電子体でもない。理屈をつけない
3. **持ち時間は6分**

### 撤去したもの（前版から削除）

`P.hydr` `P.temp` `P.enrg` `P.wet` `P.bad` `P.bleed` `P.hp` ／ `inv`（キット・ライター・布・缶詰）／
`things[]`（拾う物9個）／ `spots[]`（貯水槽・潮だまり・海水・進水）／ `rubberBoat` ／ 波高による勝利条件 ／
`deathCause()` ／ 崩落と越波の**ダメージ**（演出としての音・粉塵は残す）／ 台風の気象遷移

### 残したもの（舞台としてそのまま流用）

島の地形・護岸・建物12棟（うち入れる4棟）・岩山（MESA）・地獄段（STAIR）・ドルフィン桟橋・

## 1. 物語

夕方、島の広場に子供が6人集まる。じゃんけんをする。
**主人公が負けて鬼になる。** 十数える間に、5人が散っていく。

日が落ちるまでに全員を見つける。それだけの遊び。
見つけた子は、鬼のうしろについて歩く。5人そろったら、みんなで帰る。

見つけられないまま日が落ちたら、そこで終わり。残った子は、自分から出てくる。

## 2. 流れ（4画面）

```
① タイトル ─→ ② じゃんけん ─→ ③ 探す（6分） ─→ ④ 結末
   和風CP        和風CP            島（夕→夜）       和風CP
```

### ① タイトル

和風サイバーパンクの動く背景（2D canvas・手続き生成）。縦書きのネオン看板「端島」、
走査線、雨のような光の筋、青海波のワイヤー、グリッチ。ボタンは「じゃんけんをする」。

### ② じゃんけん（新規）

6人が輪になる。プレイヤーは **グー／チョキ／パー** から選ぶ。

- 5人の手は乱数。**プレイヤーが一人負けになるまで繰り返す**（「あいこ」の演出を挟む）
- **3回目で必ず決着**させる（3回目は一人負けの組み合わせを直接組む）。乱数の引き当てに任せると
  一人負けの確率が (1/3)^5 ＝ 1/243 しかなく、何回押しても終わらないため
- 1〜2回目に**他人が一人負けになる形**が出たら、相手の手だけを引き直す（主人公以外が鬼になると話が成立しない）
- 決着したら「鬼は十数える」。0→10のカウント演出。足音が散っていく音
- カウント中は画面が暗い（目をつぶっている）。10で目を開けて ③ へ

> 理不尽にしないための約束: **プレイヤーの選んだ手は改変しない**。相手の手だけを引き直す。

### ③ 探す（本編・6分）

| 経過 | 空 | 見え方 |
|---|---|---|
| 0–120秒 | 夕方（橙） | よく見える |
| 120–260秒 | 落ちていく | 影が伸びる |
| 260–330秒 | 薄暮（藍） | 懐中電灯が要る |
| 330–360秒 | 夜 | **ネオンだけが灯る**（和風サイバーパンクが前景化） |

### ④ 結末

- **5人そろった** → 帰り道シーケンス（3秒・子供たちが列で歩く）→ 「みつけた 五人」
- **日が落ちた** → 「日が落ちた」。見つからなかった子の**名前と隠れていた場所**を出す

## 3. 5人の子供

| 名 | 隠れ方の癖 | 気配の音 | 候補地（毎回この中から1つ） |
|---|---|---|---|
| **ミチル** | 一番小さい。近くの物陰 | 笑いをこらえる息 | 広場の瓦礫／31号棟の壁ぎわ／16号棟の角 |
| **タケシ** | 一番遠くへ走る | 走ったあとの荒い息 | 学校の奥／共同浴場の角／島の東端の護岸 |
| **サエ** | 高い所が好き | 鼻歌 | 岩山の祠／プールの底／貯水槽の陰 |
| **ゴロウ** | 建物の奥に潜る | 缶を蹴る音 | 65号棟の奥／総合事務所の奥／30号棟の一室 |
| **ハナ** | 水辺から離れない | 靴が砂を擦る音 | 桟橋の脚／竪坑桟橋跡／南護岸の切れ目 |

- 隠れ場所は**起動ごとにシャッフル**（15候補から5つ）。同じ場所に2人は入らない
- 候補座標が壁の中に入っていた場合は、**周囲を螺旋探索して立てる点へ寄せる**（`freeSpot()`）。**物陰・建物際・屋内・岩山・地獄段**以外（島のど真ん中の道端）は不可
- 隠れている間は**動かない**。しゃがんだ姿勢。光らない。矢印も出ない

### 発見の3段階

| 距離 | 何が起きるか |
|---|---|
| 14m以内 | その子の気配音が鳴る（**方向にパンする**）。音量は距離に反比例 |
| 6m以内 | ログに一行（「すぐ近くで、誰かが息を殺している」） |
| 3.4m以内 | ［**みつけた**］が押せる → 発見 |

発見すると、名前がネオンで一瞬出て、その子は**鬼のうしろに列で追従する**。
追従は前の子の1.4m後ろを追う簡易チェーン。段差は `groundY()` に追従。

## 4. 探すための手がかり（光らせない・矢印を出さない）

### 耳を澄ます

**立ち止まっていて、手の届く対象が何も無いとき**、アクションボタンが［耳を澄ます］に変わる。

- 最も近い**未発見**の子の方角へ、気配音が強くパンする
- 画面のその方向の縁が **2秒だけ淡く光る**（矢印ではなく「にじみ」）
- **クールタイム18秒**。連打で方角を三角測量させない

### 紛らわしい気配（既存の島の異物を流用）

巨大ネズミ・小さな虎・火星人も気配音を出す。近づいて調べると「子供ではなかった」。
**発見数にはカウントされない。** 時間を捨てさせるための罠として機能させる。

### 島の番人（爺さん・6人→3人に削減）

話しかけると、未発見の子のうち1人について **「方角」と「場所の種類」** を教える（例：「北の、屋根のあるところだ」）。
1人につき**2回まで**。3人で計6回。座標は言わない。

## 7. 様式：和風サイバーパンク（前版の「AI感ゼロ」原則を置き換える）

> 前版 §6 は「色を鮮やかにしない／光らせない」を全体原則としていた。
> 本版ではタイタン指示により、**タイトル・じゃんけん・結末・夜のネオン**に限って様式を切り替える。
> **プレイ中の探索そのもの**（目標を光らせない・矢印を出さない・絵文字を使わない）は前版の原則を維持する。

### 色

| 役割 | 値 |
|---|---|
| 地（藍） | `#080c16` |
| ネオン青 | `#3df2ff` |
| 朱 | `#ff2e5b` |
| 金 | `#f2c14e` |
| 藤 | `#8a6bff` |
| 文字（生成り） | `#e8e4da` |

### 語彙

縦書きのネオン看板／走査線（scanline）／グリッチの横ずれ／CRTのにじみ／
青海波・麻の葉をワイヤーで／漢数字（壱 弐 参 肆 伍）／電光の明滅／雨のような光の筋

### 維持する禁止事項（プレイ中のみ）

1. **目標を光らせない。** 子供の位置に柱・矢印・距離表示を出さない
2. **絵文字を使わない。** HUD・ログ・ボタン、すべて文字と細線のみ
3. **長調のアルペジオを鳴らさない。** 鳴っていいのは環境音・物音・気配・電子ノイズ
4. **危険を図形で予告しない。** 崩落の予告は音と粉塵（本版ではダメージなし＝驚かせるだけ）

### 様式を適用してよい場所

タイトル／じゃんけん／ポーズ／結末／**日没後に灯るネオン看板**／発見時の名前表示／HUDの枠線

### 実装で決めた数値

- **ネオン看板の高さは 8m 前後**。当初 11〜15m に置いたところ、立って正面を向いた画角（FOV 62°・
  目線 1.28m）から外れて一度も見えなかった。実測して 5.6〜8.6m へ下げた
- **看板が灯るのは `W.light < 0.22`**（およそ経過 4分20秒）。灯る瞬間に音と1行のログを出す
- **夜の環境光は `hemi = .055 + light*.70` / `sky = .03 + light*1.02`**。初期値（.16 / .10 始まり）では
  夜になっても壁が明るく、ネオンが背景に埋もれた
- **背景画（`#fx`）に大きな縦看板は置かない**。文字の上に重なって読めなくなったため、
  スカイライン＋窓のあかり＋横型のネオン棒＋水平線の光に置き換えた
- 絵を見せる3画面（タイトル／じゃんけん／結末）だけ `.sheet.art` で覆いを薄くし、本文に影を付けて読ませる

## 8. 技術・制約

- three.js r128（`three.min.js` をローカル同梱。CDN参照ゼロ）
- **子供の背丈は約1.0m**。頭は全高の 1/6（当初 1/4 で球にしたところ、2m の距離で人形に見えた）
- **追従の間隔は 2.0m**（鬼が0.5m進むごとに足跡を1点残し、n人目は 4点うしろを歩く）
- 和風サイバーパンクの背景は **2D canvas（`#fx`）で手続き生成**。three.js には触らない（タイトル中は3D描画を止めて電池を使わない）
- テクスチャはすべて Canvas で手続き生成（外部画像ゼロ）
- 効果音・環境音はすべて WebAudio の合成（外部音源ゼロ）。iOS の unlock は初回タップで `AC.resume()`
- **BGM だけ外部ファイル**（`鬼が笑う夜の隅.mp3`）。`preload="none"` で置き、じゃんけんボタンの
  初回操作で `load()` → `play()`。ポーズと結末では止める。`tg.259.mute` / `tg.259.vol` / `tg.259.bgm` に従う
- 気配の音は **StereoPanner で左右に振る**（対応していない端末では素通りして中央で鳴る）
- フォルダ合計サイズ：**4.4MB**（three.js 0.6MB ＋ BGM 3.7MB。20MB鉄則に対し余裕）
- `devicePixelRatio` は 1.5 で上限
- 走査線は CSS の `repeating-linear-gradient` 1枚。`prefers-reduced-motion` と設定で切れる

## 9. 座標と方位（実装の約束ごと）

- `+x` が **北**、`+z` が **東**。島の長辺（300m）が南北、短辺（100m）が東西 ＝ 実際の端島と同じ向き
- 広場（じゃんけんの場所・スタート地点）は `x=-120, z=-40`（ドルフィン桟橋の付け根）
- 画面上の方位帯（コンパス）は `yaw` から −90° 補正している
- 紙の地図は横長の用紙に合わせて **右が北**
