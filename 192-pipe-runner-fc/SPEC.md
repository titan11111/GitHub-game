# 192-pipe-runner-fc SPEC

## 批評

ユーザー要望は「スーパーマリオブラザーズ」。そのまま名称・キャラクター・音源・画像を再現すると権利面のリスクが高い。成功要素は、固有IPではなく「横スクロール」「慣性のある走り」「ジャンプの気持ちよさ」「踏みつけ」「ブロック叩き」「コイン」「旗ゴール」「FCらしい制約美」に分解できる。

## アウトプットイメージ

青空、雲、丘、レンガ床、パイプ風のゲートが並ぶFC風の横スクロールアクション。小さな配管工ではなく、赤い作業帽のオリジナル主人公「レンチ職人」が、歯車モンスターを踏みつけながらコインを集め、右端の旗塔を目指す。

## 設計

- タイトル: PIPE RUNNER FC
- 形式: HTML Canvas + JavaScript、単一 `index.html`
- 操作: PCは左右キー/A,D、ジャンプは Space/Z/W/↑。スマホは仮想ボタン
- コア体験: 1ステージを右へ進み、ブロックからコインを出し、敵を踏み、穴を避け、旗に到達する
- スコア: コイン、敵撃破、旗到達で加算
- モバイル対応: viewport固定、ダブルタップ防止、safe-area、DPR対応、WebAudio unlock
- レトロ様式: Canvas内は整数座標、ピクセル矩形描画、2層以上のパララックス、3声WebAudio

## 非目標

- 任天堂キャラクター、ロゴ、音源、ステージ形状、固有名称の使用
- 外部画像・外部音源の読み込み
