# 278-elevator-chanbara ｜ 昇降斬 ─ 二百階の金塊

## 一言

三機の昇降籠で二百階を駆け上がり、**先に金塊を掴んだ方が勝ち**の斬り合いレース。斬撃は殺すためではなく、相手を**落とすため**にある。

## 基本情報

| 項目 | 内容 |
|---|---|
| ジャンル | 対戦アクション（昇降レース × チャンバラ） |
| 構成 | 単一HTML（`index.html` のみ・外部依存ゼロ・画像/音声ファイルなし） |
| サイズ | 約48KB（20MB鉄則の0.24%） |
| 画面 | Canvas 論理800×600（DPR追従・`aspect-ratio:4/3`） |
| 音 | WebAudio の合成音のみ（ファイル不要・iOSはタッチで解錠） |
| 決着まで | 実測 51〜73秒 |

## 勝敗条件

**己の籠で200階に到達し、金塊を掴んだ方が勝ち。**

- 順位＝**自分の籠の階**。他人の籠や追い縄に乗っている間は一階も進まない
- 体力0は敗北ではなく **-12階の大落下**。試合は続く
- 3分経過で高い方の勝ち

## コアループ

```
▲で昇る（無防備）→ 並走になる → 追い縄で相手の高さへ渡る
→ 相手の籠に乗り込む（相手の綱が止まり、軋んで倍速で落ちる）
→ 斬って階を削る → ▼で己の籠へ戻る → また昇る
```

## 設計の芯：昇降と斬撃を噛み合わせる3つの規則

1. **昇るときは綱を両手で握る＝無防備**
   受・小斬・大斬・一閃・跳のどれかを選んだ瞬間、昇降は止まる。守るたび・斬るたびに高度を払う
2. **乗り込みは昇降を止める**
   相手の籠に飛び移ると相手は綱を握れず、籠は**通常の2倍**の速さで落ちる。ただし自分も昇れない
3. **追い縄が逆転経路を保証する**
   中央の足場は、誰も乗っていなければ**遅れている方まで降りてくる**。掴まると**相手の高さまで一気に引き上げる**（通常昇降の2.4倍速）。ここを潰すと遅れた側に手が無くなる

## 操作

| 入力 | キー | 内容 |
|---|---|---|
| ◀ ▶ | ← → | 籠の上を歩く（可動半幅74px） |
| 昇▲ | ↑ | 己の籠を上げる（0.075階/f ≒ 4.4階/秒） |
| 降▼ | ↓ | 己の籠を下げる／**他人の籠にいるときは己の籠へ飛び降りる** |
| 跳 | Space | 隣の籠へ。**高度差4.2階以内**でないと届かない |
| 小斬 | Z | 発生6・持続4・硬直11／8dmg・**-1.5階** |
| 大斬 | X | 発生15・持続6・硬直25／23dmg・**-4階**・受け崩し |
| 受 | C | 押した瞬間の**8フレームが弾き**。成功で相手42F硬直＋怒り+26 |
| 一閃 | V | 怒り100で解放。46dmg・**-14階**・ガード貫通・強制落下 |

空中で小斬／大斬 → **飛込斬**（15dmg・-3階）。単発技は**5フレーム分バッファ**され、速いタップでも落ちない。

## バランス指標（実測値）

| 項目 | 値 | 根拠 |
|---|---|---|
| 純粋な登坂時間 | 約45秒 | 200階 ÷ 4.4階/秒 |
| 実際の決着 | 51〜73秒 | 自動対戦3本×2セット |
| 1試合あたりの斬り合い | 3〜10回 | 同上 |
| 追い上げ補正 | 最大 +28% | 強すぎると斬った成果が消えるため+55%から下げた |
| 妨害のクールダウン | 13秒 | 無いと双方が妨害合戦で永久に決着しない |

## 立合い（開始処理）

3カウントの間、双方とも綱を握れない。**▲を押しっぱなしで待てる**ため、反応速度ではなく読み合いで決まる（0.3秒の入力遅れが1.4階の差として最後まで残る問題への対処）。

## 勝利演出

勝者は金塊を頭上に掲げて跳ね、口を開けて喜ぶ。金貨が降り、ファンファーレが鳴る。敗者は膝をつく。カメラは勝者へ寄る。

## iOS対応

- `user-scalable=no` ＋ `touch-action:manipulation` ＋ `gesturestart` 抑止 ＋ 350ms以内の連続タップ抑止（ダブルタップ拡大の四重防止）
- `overscroll-behavior:none`（引っぱり更新の抑止）
- 全ボタンが `pointerdown/up/cancel/leave` 対応。ボタン最小高52px
- **WebAudio は初回タッチで無音バッファを鳴らして解錠**
- `devicePixelRatio`（上限2.5）でバッキングストアを合わせ、回転時に再計算
- `env(safe-area-inset-*)` を上下左右に適用
- `prefers-reduced-motion` で一閃ボタンの明滅を停止

## 検証済み（Playwright / WebKit＝iOS Safari近似）

- ハーネス8項目 PASS（0.05MB・61 RAF/秒・エラー0件）
- 立合い前は昇らない／立合い後の差 0.009階（左右対称）
- 追い縄の引き上げ → 乗り込み → 綱の停止（-1.27階/秒）→ 斬撃で階が減る
- 3本連続で決着、毎回 斬り合いと妨害が発生
- 反撃するプレイヤーは3戦2勝、受け身は2戦0勝
