# 278-elevator-chanbara ｜ 昇降斬 ─ ELEVATOR CHANBARA

## 一言

三機の昇降籠を昇り降りしながら、高さ差を武器に斬り結ぶ 1on1 チャンバラ格闘。

## 基本情報

| 項目 | 内容 |
|---|---|
| ジャンル | 対戦型アクション（1on1 格闘） |
| 構成 | 単一HTML（`index.html` のみ・外部依存なし） |
| サイズ | 約23KB（20MB鉄則クリア） |
| 画面 | Canvas 800×600（`aspect-ratio:4/3` でレスポンシブ） |
| 初出 | 2026-09-03 リポジトリへ採番・配置 |

## コアループ

```
籠を昇降して高さを取る → 隣の籠へ跳ぶ → 飛び込み斬り／地上の三竦み
→ 弾き成功で怒りを溜める → 一閃で決める → 2本先取
```

## 操作

| 入力 | キーボード | 内容 |
|---|---|---|
| ◀ ▶ | ← → | 籠の中を歩く（可動半幅 74px） |
| 昇▲ 降▼ | ↑ ↓ | **自分が乗っている籠だけ**を上下（2.7px/f） |
| 跳 | Space | 隣の籠へ飛び移る（28フレームの放物線） |
| 小斬 | Z | 発生6・持続4・硬直11／8ダメージ |
| 大斬 | X | 発生15・持続6・硬直25／23ダメージ・**受け崩し** |
| 受 | C | 押した瞬間の**8フレームが弾き**。成功で相手42F硬直＋怒り+26 |
| 一閃 | V | 怒り100で解放。46ダメージ・ガード貫通 |

空中で小斬／大斬 → **飛込斬**（15ダメージ）。

## 設計上の要点

1. **三竦み**: 小斬で崩す ／ 大斬で受けを割る ／ 弾きで返す
2. **籠は放置すると落ちる**（0.17px/f の自然降下）。高さは維持コストを払って取るもの
3. **着地硬直が高低差に連動**: 落差170px超で18F、それ以下は7F。上から飛び込むリスク設計
4. **AIの攻めが体力に連動**: `aggro = 1 + (1 - hp/100) * 1.1`。追い詰めるほど激しくなる
5. **逃走AI**: 体力32未満かつ劣勢時、隣の籠へ逃げて高さを取り直す

## 勝敗

- 3ラウンド制・2本先取。制限時間60秒で体力判定
- 相打ち／時間切れ引き分けあり

## iOS対応

- `user-scalable=no` ＋ `-webkit-tap-highlight-color:transparent`（ダブルタップ拡大防止）
- Canvas に `touch-action:none`
- 全ボタンが `pointerdown/up/cancel/leave` 対応（`click` 非依存＝タップ遅延なし）
- `prefers-reduced-motion` で一閃ボタンの明滅を停止
- 音声なし → WebAudio unlock 不要
