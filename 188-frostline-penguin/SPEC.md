# 188 — FROSTLINE PENGUIN 仕様書

## ゲーム概要

ペンギン飛行隊が熱源兵器へ挑む、2ステージ構成の縦スクロールシューティング。初心者でも遊べる自動連射と小さい当たり判定を採用し、各面で雑魚ラッシュ、中ボス、休息、3フェーズボスを体験する。

独自フック「FROSTLINE」は、敵弾をかすめると冷気と倍率が上がり、ICEシールドで画面内の敵弾を凍結して経験値へ変換する仕組み。危険へ近づくほど、強化・スコア・緊急回避の全てが有利になる。

## 対象端末

- iPhone Safari（縦持ち、幅320px〜430px）を最優先
- iPad Safari、PC版Chrome / Safari / Edge
- GitHub Pagesで配信するビルド不要の静的ゲーム

## 画面 / 状態遷移

1. タイトル: TAP TO START、BEST、TOP 5、ミュート
2. 遊び方: 移動、自動射撃、グレイズ、ICEシールドを説明
3. ステージ1「氷空回廊」: 雑魚ラッシュ → 回避区間 → 中ボス → 休息 → ボス
4. ステージ2「オーロラ火山帯」: 回復・ICE補給 → 横風区間 → 強化中ボス → 最終ボス
5. ボス撃破: 入力停止、爆発連鎖、スローモーション。ステージ1後はそのままステージ2へ移行
6. リザルト / ゲームオーバー: スコア、ランク、実績、タイトルへ戻る

## 操作

- スマホ: Canvasをドラッグして移動、自動射撃、右下ICEボタン
- PC: 矢印 / WASDで移動、Space / Zで画面決定、XでICEシールド
- ボタン入力は`pointerdown`で即応し、pointer captureと短い振動を使用
- マルチタッチで移動とICEシールドを同時入力可能

## コアループ

移動・自動攻撃 → 敵弾を回避またはグレイズ → 撃破と経験値回収 → 武器強化 → ICEシールドで敵弾を経験値化 → 次の高密度攻撃へ挑む。

## 勝敗条件

- 勝利: ステージ2の3フェーズボス「THE MAGMA ORCA」の弱点コアを破壊
- 敗北: HPが0になる
- 被弾後1.5秒無敵。自機の被弾半径は5px、グレイズ半径は28px

## UI

- HUD: SCORE、グレイズ倍率、POWER、HP、FROST、ICE残数
- ボス戦: PHASEとボスHP
- 常設: ミュート、プレイ中はICEボタン
- 警告攻撃は敵の発光リングと警告音、ボス登場はWARNINGで予告
- safe-areaをHUD、ミュート、ICEボタンへ適用

## 音声

- WebAudio APIのオシレーターだけでBGMとSEを生成
- ショット、命中、撃破、被弾、ICE、警告、決定、グレイズ、レベルアップ、フェーズ移行を区別
- BGMとSEは別GainNodeで音量管理
- 初回タップでAudioContextを作成し、復帰時にresume。BGMタイマーは一つだけ維持
- ミュート状態をlocalStorageへ保存

## 保存

- `frostlineTop5`: ハイスコア上位5件
- `frostlineMute`: ミュート状態
- 外部通信、オンラインランキング、個人情報の保存は行わない

## ファイル構成

- `index.html`: Canvas、HUD、タイトル、遊び方、リザルト
- `style.css`: 縦画面レスポンシブUI、safe-area、タッチ対策
- `script.js`: 状態遷移、ゲームループ、描画、入力、音声、保存
- `stage2.js`: ステージ2進行、面間遷移、オーロラ火山帯の背景描画
- `SPEC.md`: 本仕様書
- `LEARNINGS.md`: 実装・検証知見

## 必須要件

- 自動連射、軽い慣性、HP、無敵、ICEシールド、経験値3段階強化
- 通常連射、拡散、追尾ミサイル
- 直進、蛇行、編隊、狙撃、耐久の敵と中ボス、3フェーズボス
- ステージ2は横風、赤熱配色、二重螺旋、移動する穴を持つ弾壁、安全レーン付き熱波で差別化
- グレイズは同じ弾から一度だけ加点
- ボス通常部位は65%軽減、発光コアは1.7倍ダメージ
- HPとスコアに応じて敵弾速度と攻撃間隔を0.82〜1.18倍で動的調整
- deltaTime上限1/30秒、DPR上限2、固定オブジェクトプール
- 高速自弾・敵弾は前位置から現位置の線分判定

## 任意要件

- 実機プレイ後にボスHP、グレイズ半径、経験値閾値を微調整
- ハイスコア実績の追加

## 実装制約

- 外部ライブラリ、画像、音声、フォント、APIを使用しない
- 合計3MB以内、相対パス、ビルド不要
- APIキー、`eval()`、`Function()`、ユーザー入力を渡す`innerHTML`、デバッグ出力を使用しない
- 自弾120、敵弾180、敵40、アイテム40、粒子250を上限とする

## テスト項目

- タイトル → 遊び方 → プレイ → 勝敗 → タイトルが通る
- ドラッグとキーボード移動、自動射撃、X / ICEボタンが機能する
- 無敵時間、グレイズ重複防止、経験値強化、ボス弱点・3フェーズが機能する
- 320px〜430pxでHUDと操作UIがsafe-area内に収まる
- WebKitで読み込みエラー、404、操作起因エラーが0件
- 60fps、3MB以内、オブジェクト数が固定上限を超えない
