# SPEC — 295｜TOWER STACK

- 作成日: 2026-09-06
- フォルダ: `295-tower-stack`
- ジャンル: タイミング / スタック
- 想定プレイ時間: 1回30秒〜3分

## 1. コアループ（何が面白いか）

操作はタップ1回だけ。ズレた分が切り落とされて土台が細くなるので、失敗が即座に「次の難しさ」に変わる。PERFECTを出すと幅が3.5px回復するため、上手い人だけが永久に積める——縮み続ける土台に対する唯一の抵抗手段が精度、という一本道の緊張感。

## 2. 操作

- タップ: 左右に動いているブロックをその位置で確定して積む
- 狙う目印として、土台の中心に光る「ピタリ帯」を常時表示

片手・親指1本で完結。二本指操作・スワイプジェスチャ・長い説明文を必要としない。

## 3. ルール

- はみ出した分は切り落とされ、次のブロックはその幅になる
- ズレ4.5px未満でPERFECT（幅+3.5px回復・コンボ加点）
- 完全に外す／幅が14px未満になると終了

## 4. 難易度カーブ

ブロック速度は 150 → 430px/s（段数×9）。幅の回復量よりも失敗のロスが大きいので、放っておけば必ず終わる。だが100%に近い精度なら理論上は無限に積める。

## 5. 手応え設計（ゲームデザイナー観点）

- 土台中心の光る帯＋落下ガイド線で、目測に頼らず狙える
- PERFECTは音のピッチが上がり続け、コンボが伸びるほど気持ちよくなる
- 切り落とされた破片が回転しながら落ちて画面外へ消える（失敗の可視化）
- 背景の色相が高さに応じて変わり、上空へ行くほど夜が深くなる
- 画面下の「土台の幅」バーで残り猶予が一目で分かる

## 6. 画面構成

- タイトル: 番号 / タイトル / 一行コンセプト / 操作3行 / 「タップでスタート」
- プレイ: 左上にHEIGHT、右上にBEST、それ以外はゲーム画面
- リザルト: スコア / ベスト / ハイスコア更新演出 / 「タップでリトライ」

## 7. 技術

- 単一 `index.html`（共通ミニエンジンをインライン同梱）
- Canvas 2D / requestAnimationFrame / dt上限0.05秒でタブ復帰時の暴走を防止
- 音: WebAudioのオシレータ＋ノイズ合成（音声ファイル0本）
- 保存: localStorage にベストスコアのみ
- iOS: `touch-action:none` / `gesturestart`と`dblclick`のpreventDefault / safe-area padding / devicePixelRatio上限2.5
