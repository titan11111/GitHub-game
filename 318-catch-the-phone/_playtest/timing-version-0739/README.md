# キャッチ・ザ・スマホ！

添付されたゲームを基に、病院・駅・電車内の3場面へ再構成した3D救出ミニゲーム。

## 遊ぶ

このフォルダでローカルHTTPサーバーを起動し、ブラウザで開く。

```
python3 -m http.server 8891 --bind 127.0.0.1
```

入口: http://127.0.0.1:8891/

3Dライブラリは同梱。外部CDNへの接続不要。ファイルを直接開く方法はモジュール制限があるため対象外。

## 操作

- WASD / 矢印: 移動
- Shift: 体力を使って走る
- SPACE: スマホ救出。白線が緑の範囲に入った瞬間に押す
- ESC / P: 一時停止
- タッチ: 左の十字キー、右の「走る」「救出」

完全救出は破損0%、かすりは25%、失敗は50%。破損した持ち主は追跡する。
救出には時間がかかる。全員を助ける必要はなく、残り時間と評価のバランスを選ぶ。
最高評価はブラウザのローカルストレージに保存する。途中セーブはない。

## 舞台

1. 白凪総合病院: 受付、会計、診察室、待合席、マスク、案内板、呼出音
2. 夕方の中央駅: 行先案内、電光掲示、柱、点字ブロック、改札
3. 終電、車内: ロングシート、窓の光、手すり、吊り革の揺れ、降車ドア

人物と設備は軽量な手続き型3Dモデル。商用大作と同等の写実表現ではない。
音はWeb Audioの合成音。実機iPhoneの音・速度・操作は未確認。
