## 0. ドキュメント情報

- 対象フォルダ: `324-day096`（公開時に改名を判断。番号は変えない）
- 作成日: 2026-10-17
- ステータス: 設計（4段ゲート 第2段）。実装は未着手

## 1. これは何か

暗い舞台で、大太鼓を両面から2人で打つ **3Dリズムゲーム**。
プレイヤーは手前の奏者になり、左右の親指で左右のバチを振る。

**核の手触り: 「いつ叩くか」に加えて「どう離すか」で音色が変わる。**
指をすぐ離せば（脱力）太鼓がよく響き、押したままにすると（力み）バチが皮に残って音が詰まる。
（根拠: 力が残るとバチの接触時間が長くなり響きが失われる — RESEARCH §3-2）

- 1プレイ: 1曲 約90秒
- 主戦場: iPhone Safari（縦画面）
- モード: **演目**（譜面ありのリズムゲーム）／**自由打ち**（楽器として好きに叩く）

## 2. 合格条件（満たさなければ未完成）

1. 指を短く離した打撃と押したままの打撃で、**音色の違いがはっきり聞き分けられる**（iPhoneのスピーカーで）
2. 判定のずれを設定で補正でき、補正値が保存される
3. 1曲を最後まで遊べて、結果画面に「段位（一〜五段）」と脱力率が出る
4. 明示ポーズ・ミュートがいつでも使える
5. iPhone 12 相当の端末で 60fps を目指し、最低でも 50fps 以上（harness で FPS を記録）
6. 公開実体は 20MB 以下（見込み 1MB 未満）
7. `alert()` を使わない／毎フレームの `createElement`・リサイズ処理・乱数計算をしない／公開時に `console.log` を残さない

## 3. 操作/設定UI（コントロールパネル）— 実装の1手目

> CLAUDE.md の鉄則4・`docs/rules/control-panel.md` に従い、ゲームの中身より先にこれを作る。

### 3-1. 入力方式

- **Pointer Events に統一**し、各タッチで `setPointerCapture` を呼ぶ。`touchstart`／`mousedown` の二重バインドはしない
- マルチタッチ: 左右の親指を同時に扱う（`pointerId` ごとに状態を持つ）
- 画面の下 45% を打撃エリアにし、左右に分ける（利き手設定で入れ替え可）

| 入力 | タッチ | キーボード（PC確認用） | 結果 |
|---|---|---|---|
| ドン（面打ち） | 打撃エリアの下側 3/4 をタップ | F（左）／J（右） | 面の中心を打つ |
| カッ（縁打ち） | 打撃エリアの上側 1/4（縁の帯）をタップ | D（左）／K（右） | 縁を打つ、乾いた木の音 |
| 大ドン（ため打ち） | 打撃エリアで**上へ 48px 以上スワイプ** | Shift＋F/J | 大きく振りかぶった強打。スワイプが 48px を越えた瞬間を打撃の時刻とする |
| 脱力の判定 | **指が触れている時間**で決まる（下表） | キーを押している時間 | 音色と得点倍率が変わる |

- **長押しは操作に使わない**（「押したまま」は力みとして扱うため。CRITIQUE R3）
- 打撃エリアの座標は、レイアウトが変わったとき（`resize`／`orientationchange`）だけ測り直す。`pointermove` のたびに `getBoundingClientRect()` を呼ばない

### 3-2. 脱力の判定（触れている時間）

| 触れている時間 | 判定 | 音 | 見た目 | 得点倍率 |
|---|---|---|---|---|
| 〜120ms | **脱力** | 減衰しない（よく響く） | バチがすぐ跳ね返る | ×1.0 |
| 120〜250ms | 並 | 離した瞬間から響きが早めに消える | バチが一瞬止まってから戻る | ×0.8 |
| 250ms〜 | **力み** | 押している間ずっと音を急速に抑える（皮をバチで押さえた状態） | バチが皮に残り、肩が上がる | ×0.5 |

- 音は `pointerdown` の瞬間に鳴らし始める（遅らせない）。触れている時間が判定を越えた時点から、ゲインを下げていく
- この3段階の境界値は設定オブジェクトにまとめ、調整できるようにする

### 3-3. ポーズ

- 画面右上に「‖」ボタン（44×44pt 以上）。Esc／Space でも開く
- ポーズ中は `AudioContext.suspend()` で曲の時間ごと止める。再開時は 3・2・1 のカウント後に `resume()`
- `visibilitychange` で隠れたら自動でポーズする（自動では再開しない）
- ポーズメニュー: つづける／やりなおす／設定／演目をえらぶ

### 3-4. 設定パネル（ポーズとタイトルから開く）

| 項目 | 値 | 既定 |
|---|---|---|
| おと（ミュート） | ON/OFF。**タイトル画面と演奏中の右上にも常に置く** | ON |
| 音量 | 0〜100 | 80 |
| タイミング補正 | −100〜+100ms（5ms刻み） | 0 |
| 自動補正 | 一定間隔の「テン」に8回合わせて叩き、ずれの中央値を補正値にする | — |
| 利き手 | 右利き／左利き（左右の打撃エリアを入れ替え） | 右利き |
| 画質 | 高（影あり・霞あり・pixelRatio 最大2）／低（影なし・霞なし・pixelRatio 1.5） | 高 |
| 譜面ガイド | ON/OFF（流れてくる音符を出すか） | ON |

### 3-5. 保存（localStorage）

| キー | 内容 |
|---|---|
| `tg.324.settings` | 上の設定一式（JSON） |
| `tg.324.best` | 演目ごとの最高点・最高段位・最高脱力率（JSON） |
| `tg.324.tutorial` | チュートリアル完了フラグ |

- 読み込みに失敗したら既定値で動く（try/catch）。キー名はこの後も変えない

### 3-6. 音声の unlock

- 最初の `pointerup`／`click`／`keydown` で `AudioContext` を作るか `resume()` する（`control-panel.md` の定型）
- `AudioContext` が作れない環境でも、ゲームは音なしで動く

### 3-7. iOS 対応

- body は `touch-action: manipulation`、canvas と打撃エリアは `touch-action: none`。ダブルタップ拡大・ラバーバンドを止める
- `100dvh` レイアウト、safe-area を考慮した余白
- 縦画面専用。横向きにされたら自動でポーズし「縦にしてください」と表示する（勝手に再開しない）

## 5. 演目（リズムゲーム）

### 5-1. 譜面の書き方（口唱歌）

譜面は1文字＝16分音符1つの文字列で書く。

| 記号 | 意味 |
|---|---|
| `D` | ドン（左右どちらの手でもよい） |
| `d` | ドン（直前と**逆の手**で打つ。ドコの「コ」） |
| `K` | カッ |
| `O` | 大ドン |
| `.` | 休み（ス） |

例: `D...d.D.K...O...`

### 5-2. MVP の演目

| 演目 | BPM | 長さ | 中身 |
|---|---|---|---|
| 一. 稽古 | 96 | 約60秒 | ドンとカッだけ。チュートリアル後の練習 |
| 二. 本番「宵の大太鼓」 | 120 | 約90秒 | ドン・ドコ・カッ・大ドンの全部。最後の8小節で大ドンを連打する見せ場 |

- 奥の相方は**地打ち**（土台のリズム。例: `D.K.D.K.`）を自動で打つ。これが拍のガイドになる
- 伴奏は合成音の締太鼓「テン」（高く短い音）を拍ごとに鳴らす。笛やメロディは MVP に入れない

### 5-3. タイミング判定

- 判定は `AudioContext.currentTime` を基準にする（`performance.now()` と混ぜない）。補正値を足してから比べる

| ずれ | 判定 | 点 |
|---|---|---|
| ±45ms 以内 | 良 | 100 |
| ±90ms 以内 | 可 | 50 |
| それ以上・打たない | 不可 | 0（連打数が切れる） |

- 1打の得点 = 判定点 × 脱力倍率（§3-2）× 連打ボーナス（10連ごとに +5%、上限 +50%）
- 縁打ちの指示に面を打った場合（またはその逆）は「可」扱い

### 5-4. 段位（結果画面）

指導者の5段階評価（RESEARCH §3-2）をそのまま段位にする。

| 段位 | 名前 | 条件 |
|---|---|---|
| 一段 | フォーム | 完走した |
| 二段 | 型ができている | 良・可の合計が 60% 以上 |
| 三段 | 大きな音 | 良が 60% 以上 |
| 四段 | 脱力 | 三段の条件に加えて、脱力率が 70% 以上 |
| 五段 | しなやかさ | 良が 85% 以上、かつ脱力率が 90% 以上 |

- 結果画面に出すもの: 点数、段位、良/可/不可の数、最大連打、**脱力率**、**力みが多かった区間**（小節番号）

### 5-5. チュートリアル（初回のみ・あとで設定から再生可）

1. 「右の親指でドン」→ 3回打つ
2. 「**押したまま**打ってみる」→「**すぐ離して**打ってみる」→ 2つの音を続けて聞かせ、違いを文字でも示す（ここがこの作品の核。飛ばせない）
3. 「上の帯でカッ」
4. 「上へはらって大ドン」

## 7. 3D 表現

- three.js **r128 を同梱**（`three.min.js`、257 と同じ版。CDN は読まない）
- 予算: 描画呼び出し 60 以下、三角形 60k 以下、影は1灯だけ（shadowMap 1024）

### 7-1. 舞台と光（RESEARCH §5）

| ライト | 位置・色 | 役割 |
|---|---|---|
| キー（SpotLight、影あり） | 太鼓の上方・やや奥。暖白（3200K相当 #FFD9A8） | 皮の上半分と人物の肩・髪に縁取りを作る |
| リム（DirectionalLight） | 奏者の真後ろ上方。薄青白 #CFE0FF、弱め | 輪郭を背景から切り離す |
| フィル（HemisphereLight） | 正面下からごく弱く（キーの10〜15%） | 衣装がつぶれない程度 |
| 床の光だまり | スポット直下に暖色の楕円（加算合成の板1枚） | 写真の床の質感 |
| 霞 | スポットの円錐に加算合成の半透明メッシュ（画質「高」のみ） | 煙の中の光の筋 |
| 打撃の閃き | インパクトでキーを +20%、50ms で戻す（大ドンは +40%） | 音と光の同期 |

- 背景は純黒にせず `#050403`。トーンマッピングは ACES Filmic
- 演目の開始: 完全な暗転 → 太鼓だけにスポット → 最初の大ドンで舞台全体が明るくなる（Kodo 公演の暗→明の対比）

### 7-2. 太鼓（RESEARCH §2・§6）

- 長胴型の大太鼓、直径 90cm 相当。櫓（やぐら）型の木の台にキャスター付き。打面は斜め上向きで、中心が奏者の肩の高さ
- 胴: 朱漆 `#6E1414`、clearcoat 相当の艶（r128 の MeshPhysicalMaterial で clearcoat 0.8）
- 皮: 生成り `#E8D9B5`、roughness 0.75。中央に打ち跡の汚れ（CanvasTexture で起動時に1回だけ生成）
- 鋲: 片面 48個 × 2面を `InstancedMesh` で1回の描画にする
- **皮の振動**: 頂点シェーダで (0,1) モードの凹み（ベッセル関数 J0 の近似）＋外へ広がる光の輪。強さは打撃の強さ、減衰は音の減衰と同じ時間

### 7-3. 奏者（CRITIQUE R2）

- **ローポリの塊のシルエット**（1体 3〜5k 三角形）。顔は描き込まず暗く落とす
- 手続きで組むリグ（腰・胸・肩・上腕・前腕・手首 × 左右、計 12 関節程度）
- 衣装: 黒地に縦縞の法被（テクスチャ1枚）、赤い紐 `#B01E2A`、白足袋
- 下半身は固定: 足を大きく開いた低い構え（前膝を曲げ、後ろ足を伸ばす）
- 特定の団体・人物に似せない（CRITIQUE R7）

### 7-4. バチと打撃アニメーション（RESEARCH §3-2・§3-3）

| 段階 | 時間（60fps換算） | 動き |
|---|---|---|
| 構え | 次の音符の 200ms 前に自動で振り上げておく（自由打ちでは常に振り上げ） | 頂点で止める（ため） |
| 振り下ろし | `pointerdown` から 2フレーム | 力を抜いて落とし、肘が開いたところで手首を返して一気に加速 |
| インパクト | 1フレーム | 皮が凹む・画面が 1〜2px 揺れる・光の輪・キーライトの閃き |
| 跳ね返り | 脱力: すぐ／並: 一瞬止まる／力み: 指を離すまで皮に残る | 力みのときは肩を上げて、こわばりを見せる |
| 大ドン | スワイプ中に頭上まで振りかぶる → 越えた瞬間に振り下ろし | 腰のひねりを大きく、閃きを強く |

- 動きの順番は **腰 → 胸 → 肩 → 肘 → 手首 → バチ先** と少しずつ遅らせる
- 振り下ろし中のバチには**スメア**（直近5フレームの位置をつないだ半透明の帯、加算合成）。帯のメッシュは使い回す（毎フレーム作らない）
- 待機中は 2.5秒周期で上体をわずかに上下させる（呼吸）
- 奥の相方は手前の動きより小さく、地打ちは常に「脱力」で打つ（お手本）

### 7-5. カメラ

- 手前の奏者の右肩越しで、やや見下ろす。太鼓の面が画面の中央上寄りに来る
- 大ドンでわずかに寄る（0.2秒で戻す）。演目の終わりに引きの全景へ

## 8. 音（Web Audio の合成。音声ファイルは使わない）

RESEARCH §4 の合成レシピに従う。1打ごとに作るノードは使い終わったら切り離す。

| 部品 | 中身 |
|---|---|
| 低音（体） | sine 70Hz。打撃の直後は ×1.3 から 80ms で下げる。減衰 2.0s |
| 芯（スピーカー用） | sine 185Hz と 205Hz（両面の (0,1) モードの組、調査の実測値）。減衰 0.8s。iPhone のスピーカーでも打感を出す（CRITIQUE R5） |
| 倍音 | sine × 3、芯の 1.59／2.14／2.65 倍。減衰 0.3〜0.6s |
| アタック | 帯域通過ノイズ 1〜3kHz、15ms |
| カッ | 低音・芯なし。高域ノイズ＋木の共鳴 1kHz、60ms |
| 大ドン | 音量 +4dB、ピッチの下がり幅を ×1.5、低音の減衰 3.0s |
| 力み | 触れている時間が 250ms を越えたら、全体のゲインを 80ms で −18dB まで下げる |
| 相方の地打ち | 同じ合成で、音量 −6dB、パンを少し奥寄りに |
| 締太鼓「テン」 | sine 900Hz＋ノイズ、40ms（拍ガイド） |

- 全体を `DynamicsCompressor` に通してから出力する（連打で割れないように）
- ミュートはマスターゲインを 0 にする（ノードは止めない）
