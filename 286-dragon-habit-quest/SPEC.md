# 286-dragon-habit-quest / ハビットクエスト

> 毎日「きょうは ◯◯ しましたか？」に **はい** と答えるだけ。
> 連続で「はい」と答えるほど攻撃力が上がり、**続けることが強さになる**のを体感させるブラウザRPG。

- 最終更新: 2026-09-05（UI全面整理・オンボーディング導入・連続ボーナス制）
- 対象: 小学生〜中学生（保護者と一緒に使う想定）
- 実体: `index.html` 単一ファイル。外部依存ゼロ（CDN・フォント・画像なし）

---

## 1. 設計の芯

**「情報量を減らし、"続けると強くなる"の一本だけを見せる」**

- 画面に出す数値は **3つだけ**: `Lv` / `🪙ゴールド` / `🔥れんぞく日数`
  - 旧版の HP・MP・EXP・ちから・かしこさ… は全廃 or オーバーレイへ退避
- 毎日の操作は **「はい」ボタン1タップ**。数値入力は初回設定のときだけ
- 継続の報酬を**ダメージ倍率**として毎回目に見せる（`れんぞく5日 → ×1.5！`）
- 積み上がりは数字ではなく **つみあげタワー**（1日クリア＝ブロック1個）で見せる

## 3. 8つのしつもん（オンボーディング）

1問1画面。カードをタップ→自動で次へ。もどるボタンあり。

| # | 質問 | 回答 | 確定する内容 |
|---|---|---|---|
| Q1 | なまえは？ | テキスト入力（最大8文字） | `hero.name` |
| Q2 | いくつ？ | ようちえん / 小1〜3 / 小4〜6 / 中学生いじょう | 目標値のプリセット |
| Q3 | からだ の しゅうかんは？ | スクワット / なわとび / ランニング / ストレッチ | クエスト①の種類 |
| Q4 | どれくらい やる？ | 3段階（Q2で数値が変わる） | クエスト①の目標値 |
| Q5 | あたま の しゅうかんは？ | どくしょ / しゅくだい / けいさん / えいご | クエスト②の種類 |
| Q6 | どれくらい やる？ | 3段階 | クエスト②の目標値 |
| Q7 | せいかつ の しゅうかんは？ | はやねはやおき / はみがき / おてつだい / かたづけ | クエスト③（回数なし） |
| Q8 | いつ やる？ | あさ / がっこうのあと / よる | 応援メッセージの文面 |

- 完了時に `setupDone = true` を保存。以後は起動即 `screen-main`
- やりなおしは `ov-config` →「しゅうかんを えらびなおす」（積み上げた進捗は保持）

## 4. ゲームルール

### 4-1. 1日のながれ
1. アプリを開く → 日付が変わっていれば今日の質問3つが復活する
2. 「きょうは ◯◯ しましたか？」に **はい！** → モンスターにダメージ
3. 3問すべて「はい」→ **きょうのクエスト コンプリート！**
   - コンプリートボーナス（合計ダメージの +50%）
   - **つみあげブロック +1**
   - ぜんたいの れんぞく日数 +1

「まだ」を選んだ場合は次の質問へ送るだけ。その日のうちに開き直せば**もう一度きかれる**（罰を与えない）。

### 4-2. ★連続ボーナス（この作品のいちばんの主張）

習慣ごとに `streak`（連続で「はい」と答えた日数）を持つ。

| れんぞく | こうげき倍率 |
|---|---|
| 1日目 | ×1.0 |
| 2日 | ×1.2 |
| 3日 | ×1.3 |
| 5日 | ×1.5 |
| 10日 | ×2.0 |
| 20日以上 | ×3.0（上限） |

式: `streak <= 1 ? 1.0 : min(3.0, 1.0 + streak × 0.1)`

- 質問カードに**答える前から**「れんぞく4日 → こうげき ×1.4」と表示する
  （＝続けている人ほど強いことを、毎回目で確認させる）
- 1日あくと `streak = 1` に戻る。ただし **つみあげブロックは絶対に減らさない**
- 連続が途切れたときは責めない文言にする:
  「きのうは おやすみ だったね。きょうから また つみあげよう！」

### 4-3. ダメージ
```
基礎 = 12 + Lv × 3
種類ボーナス = 目標値の段階（かるめ ×1.0 / ふつう ×1.2 / がんばる ×1.5）
どうぐボーナス = 該当アイテム所持で ×1.3
れんぞくボーナス = 4-2 の倍率
ダメージ = floor(基礎 × 種類 × どうぐ × れんぞく)
```

### 4-4. レベル
- EXPは画面に出さない。**クリアした日数**でレベルが決まる: `Lv = floor(totalClearDays / 3) + 1`
  - 「毎日やればレベルが上がる」という因果を1本に絞る

## 5. つみあげタワー（コア演出）

- 1日コンプリート = ブロック1個。メイン画面下部に**直近20個**を横並び表示
- 10個ごとに色が変わる: 🟫茶 → 🟦青 → 🟪紫 → 🟨金
- `ov-tower` で全ブロックを積み上げ表示＋習慣ごとの連続日数一覧
- ブロックが増える瞬間だけ、下から積み上がるアニメーション（0.4秒）

## 6. 技術方針

| 項目 | 方針 |
|---|---|
| 依存 | **なし**。Tailwind CDN / Google Fonts / FontAwesome を全撤去 |
| CSS | 素のCSS。ドット風の枠は多重 `box-shadow` で自前実装 |
| フォント | OS標準（`system-ui` → ヒラギノ角ゴ）。太字＋大きめで可読性優先 |
| 音 | Web Audio API の矩形波のみ（音源ファイルなし）。初回タッチで unlock |
| 保存 | `localStorage` キー `habit_quest_v2`。v1（`dq_habit_quest_save_v1`）は移行せず新規開始 |
| サイズ | 単一 index.html。20MB鉄則に対し数十KB |

### iOS鉄則（`/ios-game-base` 準拠）
- `user-scalable=no, viewport-fit=cover`
- `touch-action: manipulation` でダブルタップ拡大を防止
- `-webkit-tap-highlight-color: transparent`
- `env(safe-area-inset-*)` で上下パディング
- タップは `pointerdown` 起点で反応（クリック待ちの遅延をなくす）
- `user-select: none` / `-webkit-touch-callout: none`

## 7. やらないこと（スコープ外）

- 複数ユーザー・きょうだいアカウント
- サーバー保存・共有・ランキング
- 習慣の自由記述追加（選択肢から選ぶだけに固定＝UIを固定する目的のため）
- HP/MP の概念（削除済み。復活させない）
- 「まだ」を選んだことへのペナルティ演出
