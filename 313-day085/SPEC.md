# 313-day085 ｜ 巨忍 影丸（KYODAI NINJA KAGEMARU）

## 一言

**山村の屋根が膝までしかない巨大忍者**が、正宗と大手裏剣で落ち足軽・泥人形・仙人を蹴散らし、芭蕉天狗を討つベルトスクロールアクション。

## 0. 批評（設計前ゲート）

依頼の芯は「とにかくでかく・迫力」「UI操作を最高にしやすく」。一発生成で起きがちな失敗を先に潰す。

| 起きがちな失敗 | この作品での対策 |
|---|---|
| 「巨大」と言いつつ画面の1/3程度の主人公になる | 主人公は**画面高の約70%**。民家は膝、落ち足軽はくるぶしの高さ。巨大さは**比較対象（家・小兵）**で見せる |
| 迫力＝エフェクトの量だけになる | **ヒットストップ・画面揺れ・踏み潰し・家屋破壊**の4つで「重さ」を出す。斬撃は3段目で地面が割れる |
| ベルトスクロールの奥行き判定がシビアで当たらない | 巨大な正宗は**奥行き±48px**を一振りで薙ぐ。押しっぱなしで連撃。向きは**最寄りの敵へ自動で向く** |
| 忍術を取っても使い方が分からない | 拾った巻物は画面上部にアイコンで**ストック表示（最大3）**。SELECT一つで先頭から発動。初回取得時に名前を大書き |
| 中断できない・音が消せない | START＝ポーズメニュー、右上🔊＝ミュート。どちらも保存される |

## 1. 操作／設定UI（ゲーム内容より先に確定）

| ボタン | キーボード | 内容 |
|---|---|---|
| 十字 ◀▶ | ← → | 横移動（画面送り） |
| 十字 ▲▼ | ↑ ↓ | 奥行き移動 |
| A（赤） | Z / Space | **正宗で斬る**。押しっぱなしで3段連撃（横薙ぎ→返し→兜割り＋地割れ） |
| B（黄） | X | **大手裏剣**。貫通。押しっぱなしで連射（0.38秒間隔） |
| SELECT | C | **忍術**：ストック先頭の術を発動 |
| START | Enter / P / Esc | **ポーズ**（つづける／音 ON・OFF／操作説明／タイトルへ） |
| 右上 🔊 | M | ミュート切替（ゲーム中いつでも） |

- 入力は `fc-ios-controller.js`（titans-ui 共通部品）。Pointer Events＋`setPointerCapture`
- 共通部品は単独リポジトリでも動くよう**フォルダ内に同梱**（244・250と同じ扱い）。原本は `titans-ui/src/components/Controls/`
- 操作盤の各ボタンに**役割の文字**（斬る／手裏剣／忍術／ポーズ）を表示。SELECT/STARTは見た目の小判型を保ったまま**当たり判定は48px以上**
- 画面が隠れたら（`visibilitychange`）自動でポーズ

## 2. 登場するもの

### 主人公：影丸（巨大忍者）
- 身長は画面高の約70%。体力100。被弾後1秒無敵
- 歩くだけで**落ち足軽を踏み潰す**（地響き）
- 正宗：1段8／2段8／3段16ダメージ。3段目は地割れ衝撃波
- 大手裏剣：4ダメージ・貫通・回転

### 忍術（敵が巻物を落とす。ストック最大3）
| 術 | 効果 |
|---|---|
| 火遁・大炎陣 | 前方へ画面幅の炎の壁。触れた敵に14＋燃焼 |
| 雷遁・百雷 | 画面内の全敵に落雷16。空が暗転して閃光 |
| 筋斗雲の術 | 8秒間、金の雲に乗る。無敵・移動2倍・触れた敵に連続ダメージ |

### 敵
| 敵 | 大きさ | 体力 | 行動 | 巻物 |
|---|---|---|---|---|
| 落ち足軽 | くるぶし | 1 | 群れで寄って脛を突く（3） | 5% |
| 泥人形 | 主人公の半分強 | 14 | 鈍重な大振り（10）。倒すと小泥人形2体に割れる | 30% |
| 小泥人形 | 主人公の1/4 | 4 | 体当たり（5） | 5% |
| 熟練の仙人 | 雲に乗り胸の高さ | 9 | 瞬間移動して気弾（8・ゆっくり追尾） | 70% |

### ボス：芭蕉天狗
- 主人公より大きい。体力220。翼・高下駄・巨大な芭蕉扇
- **扇の突風**：主人公を押し戻し、木の葉を3列で飛ばす（奥行き移動で避ける）
- **句の弾幕**：「古池や蛙飛びこむ水の音」等の**文字そのもの**が飛んでくる。斬れば消える
- **天狗落とし**：飛び上がって影が追尾、急降下で衝撃波
- **烏天狗足軽の召喚**
- 体力50%以下で怒り（赤く光り、攻撃間隔が短くなる）

## 3. 舞台と流れ

鄙びた山村の夕暮れ。遠山・棚田・茅葺き民家・柿の木・地蔵・石灯籠。民家と灯籠は**斬ると壊れる**。

| 区間 | 内容 |
|---|---|
| 一 村の入口 | 落ち足軽の群れ → 泥人形 |
| 二 棚田 | 仙人登場 → 泥人形2体 |
| 三 山門 | 全種混成 |
| 四 天狗の庭 | 芭蕉天狗戦 |

- 各区間で敵の波が出ると画面が止まり、全滅で「GO ▶」
- 体力0 → コンティニュー（区間の頭から・スコア半分）
