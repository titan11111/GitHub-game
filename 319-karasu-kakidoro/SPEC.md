## 2. ゲームの流れ
- 1ステージ＝制限時間60秒（日没）。時間とともに**視界が狭まる（トリ目）**。光は「カラス」と「描いている線の先端」の周りだけ。柿だけはうっすら光る
- カラスは電線から出発。描ける距離に上限（インク）あり。柿に触れたらクリア。被弾すると電線に戻される（時間は戻らない）
- 時間切れ＝ゲームオーバー

### 3.1 柿の拾い方と残数（2026-10-13）
- 飛行ルート上の柿は**全部拾う**。ルートの終点（または木の柿が尽きた時）でクリア。欲張るほど長く飛ぶので被弾リスクが増える
- 被弾すると持っていた柿は**木に戻る**（拾得数は0に戻る）
- 木の柿は全部で16こ（各日の柿の数の合計）。HUDに「木の柿 Nこ」。保存キー `tg.317.taken`

### 3.2 とめさん（キョロキョロ／発見の速度）
- 視線は `right`(庭を見る) / `up`(電線を見る) / `left`(後ろを向く) / `sip`(お茶を啜る) をランダムに切替。**left・sipが隙**
- 視野(黄色い扇)に入ると「?」メーターが満ちる。満ちきると発見→全員が警戒（4秒、爺さんが急接近・構えが速い）。視野外ではメーターが減る
- 発見の速さは日ごとに上がる（二日目0.8 → 五日目1.7）。近いほど速い。電線の `up` 視線ではとまっているカラスも見つかる

### 3.3 声
- Web Audio合成（音声ファイルなし）。キャラごとに音色・高さが違う（爺さん=低いのこぎり波／とめさん=三角波／はじめさん=矩形波／くのいち=高い正弦波／サスケ=高い三角波／孫=明るい三角波）。ミュートで消える
- 吹き出しの縁の色＝話者の色

## 6. 柿の木の絵柄（2026-10-13）
- 絵柄は参考画像のフラットなベクター調（単色の幹と枝・とがった葉3色・ヘタ付きの柿）。**木は1本に絞った**（3種案から確定）
- モデル=富有柿の原木（岐阜県瑞穂市居倉。1820年頃に植えられた御所柿が起源、市天然記念物）。端正な丸い樹冠で左右対称、実は**最大5つ**（エンディングの木も5つで打ち切り）
- 樹形は写真と照合していない解釈（出典は樹齢・由来のみ）。柿は枝先のヘタまで枝が伸び、見た目32px・当たり判定 r=11
- 没案（hira=平核無の原木／hibaku=被爆柿の木）は git履歴 749cc80 に残る
