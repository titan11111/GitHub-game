## 2. ゲームの流れ
- 1ステージ＝制限時間60秒（日没）。時間とともに**視界が狭まる（トリ目）**。光は「カラス」と「描いている線の先端」の周りだけ。柿だけはうっすら光る
- カラスは電線から出発。描ける距離に上限（インク）あり。柿に触れたらクリア。被弾すると電線に戻される（時間は戻らない）
- 時間切れ＝ゲームオーバー

### 3.1 柿の拾い方と数（2026-10-13 改定：木になる柿は毎日5こ）
- **木の柿は毎日5こ固定**（多いと見づらく、カラスも狙いづらいため。旧「五日間で合計16こ」は廃止）。配置は**太枝の真下**（左2・右2・上1）で、毎日同じ。日ごとの高さ変化は廃止（実が枝から離れてしまうため。難しさは見張りの増加で出す）
- 飛行ルート上の柿は**全部拾う**。ルートの終点（または木の柿が尽きた時）でクリア。欲張るほど長く飛ぶので被弾リスクが増える。被弾すると持っていた柿は木に戻る
- 取った柿は翌日またなる（毎日5こに戻る）。HUDは「木の柿 Nこ」＝いま木にある数。保存キー `tg.317.taken`（日ごとの取得数）
### 3.2 とめさん（キョロキョロ／発見の速度）
- 視線は `right`(庭を見る) / `up`(電線を見る) / `left`(後ろを向く) / `sip`(お茶を啜る) をランダムに切替。**left・sipが隙**
- 視野(黄色い扇)に入ると「?」メーターが満ちる。満ちきると発見→全員が警戒（4秒、爺さんが急接近・構えが速い）。視野外ではメーターが減る
- 発見の速さは日ごとに上がる（二日目0.8 → 五日目1.7）。近いほど速い。電線の `up` 視線ではとまっているカラスも見つかる

### 3.3 声
- Web Audio合成（音声ファイルなし）。キャラごとに音色・高さが違う（爺さん=低いのこぎり波／とめさん=三角波／はじめさん=矩形波／くのいち=高い正弦波／サスケ=高い三角波／孫=明るい三角波）。ミュートで消える
- 吹き出しの縁の色＝話者の色

### 3.4 エンディング（木に残った柿 R=0〜5こ で6分岐／2026-10-14 改定）
五日間の合計取得数 T（各日最低1、5〜25）から R=clamp(5−round((T−5)/4),0,5)。
| R | エンディング | 孫 |
|---|---|---|
| 5 | 柿を手いっぱいに抱えた爺さん | 出る |
| 4 | 飛び跳ねる爺さん | 出る |
| 3 | 孫とステップを踏む爺さん | 出る |
| 2 | 指おり数える爺さん（腕組み・うなずく） | 出ない |
| 1 | しょんぼりする爺さん（ずーん） | 出ない |
| 0 | 絶望する爺さん（雨・涙） | 出ない |
- **孫はハッピー（R≥3）のときだけ登場**。場面B（縁側でお茶）は、ハッピー=「あの子は誰じゃ」でお茶ぶーっ／それ以外=孫抜きの独白
- 孫の動きはコミカル：速さにムラ・ぴょんぴょん・着地でつぶれる・4.6秒ごとに宙返りで転ぶ（★）。爺さんは孫を目で追って向きを変える
- 孫（尻尾あり＝正体は不明）。タップでスキップ
- R=4,5 は旧T式では届かなかったため、Tの換算を旧「3で割る」から「(T−5)/4」に変更（R=5はほぼ毎日1こ）

### 3.5 周回（2026-10-14）
- 一周（五日クリア→エンディング）するごとに `lap` +1（保存キー `tg.317.lap`）。爺さんたち（爺さん・とめさん・はじめさん・くのいち・サスケ）の**時間が+50%ずつ速く進む**（2周目×1.5、3周目×2.0…5周目以降×3.0で頭打ち）。動き・構え・発見・クナイ間隔がまとめて速くなる
- **服の色が周回ごとに変わる**（色相をずらす。肌・髪は据え置き）。声の吹き出し枠の色も追従。HUDに「2周目×1.5」
- エンディング後は `cleared` を0に戻し、一日目から

### 3.6 武器の長さ（2026-10-14）
- 竹箒 L=77（旧70の1.1倍）
- 高枝切りばさみ L=340（旧170の2倍）。**先端の速さは据え置き**（伸びる0.12→0.24秒、縮む0.25→0.5秒）。発動距離は旧220→260
- とめさん（おばあさん）は縁側（家＋障子つき）から**柿の木を見張る**：基本の視線は木の方向（-32°±9°でゆっくり首をふる）、手をかざす。left/sipが隙なのは従来どおり

## 6. 柿の木の絵柄（2026-10-13）
- 絵柄は参考画像のフラットなベクター調（単色の幹と枝・とがった葉3色・ヘタ付きの柿）。**木は1本に絞った**（3種案から確定）
- モデル=富有柿の原木（岐阜県瑞穂市居倉。1820年頃に植えられた御所柿が起源、市天然記念物）。端正な丸い樹冠で左右対称、実は**毎日5つ**（§3.1）
- 樹形は写真と照合していない解釈（出典は樹齢・由来のみ）。柿は枝先のヘタまで枝が伸び、見た目32px・当たり判定 r=11
- 没案（hira=平核無の原木／hibaku=被爆柿の木）は git履歴 749cc80 に残る
- **実のなり方の検証（2026-10-13）**: 柿の実は前年枝から伸びた新梢の葉のつけ根につき、結果枝の長さで着果数が決まる（宮城県の栽培資料）。旧版は「幹から出る細い弧の枝の先に、葉から離れてぶら下がる」形で不自然だった。現行は、太枝の真下に短い柄（約7px）でつけ、同じ新梢の葉を2〜3枚そえる。ヘタは上、実は下垂
