## 飛行モデル（2026-10-05 に力ベースへ全面変更）
旧実装は「入力＝速度」を毎フレーム代入しており、重力も慣性もなく、風は速度の目標値に足すだけだった。
現在は次の3つの力から加速度を作る。

1. **ローター推力**: `rpm` がスプールアップ（SPOOL=1.3）してから効く。接地アイドル `IDLE_RPM=0.72` は重量未満なので浮かない＝離陸に「よいしょ」が出る
2. **重力**: 常時 `GRAV=9.81`。ディスクを傾けると揚力の垂直成分が `cos(tilt)` だけ減って沈む（自動補正は6割のみ）
3. **対気速度に比例する抗力**: 風との相対速度に効くので、**無操作だと風下へ流される**。低速で強く（DRAG_L=0.30）、速度が乗ると並進揚力で弱まる（TRANS_LIFT=0.245）

水平移動はディスクの傾き（MAX_TILT=0.56 / 減速時 BRAKE_TILT=0.70）が `TILT_LAG=3.2` で遅れて追従し、その傾きが加速度になる。
→ 姿勢は見た目の飾りではなく**加速の原因**。止まるには早めに引き起こす必要がある。

安全弁: 全域で降下 −12m/s 上限。対地10m未満でコレクティブを下げている間は −5m/s 上限（▼での着陸は壊れない）。
地面効果は対地12m以下で最大+22%。

## 見やすさの装置
- **青い輪** = 真下の対地位置 / **橙の輪** = いま降りたら着く場所（水平速度×落下時間）/ 縦線 = 高度
- **橙の矢印** = 目標の方向と距離。画面外なら画面の縁に寄って方向を指す
- 計器4つ: 対地高度 / 速度 / **昇降（−5以下で赤）** / 目標まで
- 自動解像度調整: 45フレームごとに実測し、50 RAF/秒を割ったら解像度を下げる（下限0.8倍、上限はタッチ端末1.5倍）
