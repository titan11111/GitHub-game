# SPEC — 290｜BLOCK FEVER

- 作成日: 2026-09-06
- フォルダ: `290-block-fever`
- ジャンル: ブロック崩し / アーケード
- 想定プレイ時間: 1回2〜6分

## 1. コアループ（何が面白いか）

パドルは指のx座標に即追従するので「思った所へ置けない」ストレスがない。ブロックを連続で割るほどFEVER倍率が乗り、★を取るとマルチボール・拡大・減速で一気に画面が派手になる。ステージ更新のたびに色とレイアウトが変わる。

## 2. 操作

- ドラッグ: パドルを左右に移動（画面のどこを触ってもよい）
- タップ: 待機中のボールを発射
- 指を離してもパドル位置は保持される

片手・親指1本で完結。二本指操作・スワイプジェスチャ・長い説明文を必要としない。

## 3. ルール

- ボールを落とすと残機-1、0で終了
- 全ブロックを消すと次ステージ（行数・耐久ブロックが増える）
- ★アイテム: W=パドル拡大 / M=マルチボール / S=減速 / ♥=残機+1

## 4. 難易度カーブ

ステージごとにボール速度+16px/s、行数+1、耐久2〜3のブロックが増加。減速アイテムで一時的に0.72倍にできるため、詰んだ時の逃げ道を用意した。

## 5. 手応え設計（ゲームデザイナー観点）

- パドル反射角は当たった位置で決まる（真ん中=垂直、端=鋭角）ので狙って返せる
- 連続ヒット数でヒット音のピッチが上がる
- ブロック破壊は四角い粒子、パドル反射は上向きの粒子と、フィードバックを描き分けた
- 残機・ステージ・強化の残り時間を常時HUD表示

## 6. 画面構成

- タイトル: 番号 / タイトル / 一行コンセプト / 操作3行 / 「タップでスタート」
- プレイ: 左上にSCORE、右上にBEST、それ以外はゲーム画面
- リザルト: スコア / ベスト / ハイスコア更新演出 / 「タップでリトライ」

## 7. 技術

- 単一 `index.html`（共通ミニエンジンをインライン同梱）
- Canvas 2D / requestAnimationFrame / dt上限0.05秒でタブ復帰時の暴走を防止
- 音: WebAudioのオシレータ＋ノイズ合成（音声ファイル0本）
- 保存: localStorage にベストスコアのみ
- iOS: `touch-action:none` / `gesturestart`と`dblclick`のpreventDefault / safe-area padding / devicePixelRatio上限2.5
