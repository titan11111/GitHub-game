# 317-karasu-kaki 「夕暮れカラスの柿どろぼう」（モックアップ）

旧「セリフ箱RPG」(317-serifu-bako) を全面置換。**音楽4曲のみ流用**、他は新規。旧版は git履歴（`317-serifu-bako/`）に残る。

## 1. 操作/設定UI（最優先で決めた項目）
| 項目 | 決定 |
|---|---|
| 入力 | Pointer Events + `setPointerCapture`。スマホ=スワイプ／PC=マウスでなぞる。指の相対移動×1.5をカラス位置からの軌道に変換（指が軌道を隠さない） |
| 発進 | 下部「とびたつ！」ボタン／Space。**押すタイミングが攻略要素**（見張りは時間経過で巡回する） |
| 線を消す | ボタン／C |
| ポーズ | ⏸ボタン／P・Esc。タブ非表示で自動ポーズ。タイマーも止まる |
| ミュート | 🔊ボタン。BGM(`muted`)とSE両方に効く |
| 保存 | `tg.317.mute` `tg.317.cleared`（クリア済み日数） |
| iOS | CSSヘッダー（body=manipulation / canvas=none）、safe-area、WebAudio unlock、DPR上限2.5 |

## 2. ゲームの流れ
- 1ステージ＝制限時間60秒（日没）。時間とともに**視界が狭まる（トリ目）**。光は「カラス」と「描いている線の先端」の周りだけ。柿だけはうっすら光る
- カラスは電線から出発。描ける距離に上限（インク）あり。柿に触れたらクリア。被弾すると電線に戻される（時間は戻らない）
- 時間切れ＝ゲームオーバー
