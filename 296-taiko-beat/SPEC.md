# SPEC — 296｜TAIKO BEAT

- 作成日: 2026-09-06
- フォルダ: `296-taiko-beat`
- ジャンル: リズム
- 想定プレイ時間: 1回1〜4分

## 1. コアループ（何が面白いか）

レーンは2つだけ、判定は「重なった瞬間に押す」だけ。だがBPM138の裏拍・16分が徐々に混ざり、気づけば手が勝手にリズムを刻んでいる。コンボが伸びるほど数字が大きく表示され、切りたくなくなる。

## 2. 操作

- 画面左半分をタップ: 赤（ド）ノーツ
- 画面右半分をタップ: 青（カ）ノーツ
- マルチタッチ対応（左右同時押しも取れる）

片手・親指1本で完結。二本指操作・スワイプジェスチャ・長い説明文を必要としない。

## 3. ルール

- 判定: PERFECT(±58ms) / GOOD(±130ms) / BAD / MISS
- PERFECT+100点＋コンボ×3、GOOD+50点
- MISSでゲージ-13、BADで-8。ゲージ0で終了

## 4. 難易度カーブ

譜面は毎小節その場で生成。経過95秒で密度が最大になり、裏拍(0.5)の出現率が16%→58%、16分(0.25)が55秒以降に追加される。

## 5. 手応え設計（ゲームデザイナー観点）

- ノーツは着地予定地点に向かって一定速度で落ちるので、目押しの学習が素直に効く
- 判定結果を毎回大きな文字で返す（PERFECT/GOOD/BAD/MISS）
- コンボ数はコンボが伸びるほど文字が拡大
- 拍に合わせて画面全体がわずかに発光し、目でもリズムが取れる
- 太鼓の絵とレーン色で「左＝赤／右＝青」を毎フレーム提示

## 6. 画面構成

- タイトル: 番号 / タイトル / 一行コンセプト / 操作3行 / 「タップでスタート」
- プレイ: 左上にSCORE、右上にBEST、それ以外はゲーム画面
- リザルト: スコア / ベスト / ハイスコア更新演出 / 「タップでリトライ」

## 7. 技術

- 単一 `index.html`（共通ミニエンジンをインライン同梱）
- Canvas 2D / requestAnimationFrame / dt上限0.05秒でタブ復帰時の暴走を防止
- 音: WebAudioのオシレータ＋ノイズ合成（音声ファイル0本）
- 保存: localStorage にベストスコアのみ
- iOS: `touch-action:none` / `gesturestart`と`dblclick`のpreventDefault / safe-area padding / devicePixelRatio上限2.5
