確認質問はしない。下の手順をそのまま実行する。**唯一止まるのは 👤人間箱に当たったときだけ**。

### 手順

1. `node _tools/audit.mjs <フォルダ名>` を実行する
2. レポート冒頭の **👤 タイタンに聞きたいこと** を先に提示する。人間箱は**1バイトも触らない**
3. **⚙️機械箱の1件目**だけを直す。1周につき1件（複数まとめて直さない）
4. 再監査して × が減ったことを確認する。**減っていなければ停止してタイタンに報告**（＝空回りの合図）
5. `git add` → commit。コミットメッセージに **「audit: ×N → ×M」** を必ず入れる。1周＝1コミット
6. 機械箱が0件になるまで3〜6を繰り返す。**上限3周**。超えたら停止して報告

### 絶対にやらないこと

- `audit.mjs` / `game-harness.mjs` の書き換え（採点基準を触らせない）
- 人間箱の項目を推測で埋める（`image_0.png` を勝手に別画像で代替する等）
- **参照切れが残っている状態で未参照ファイルを削除する**（修復材料を消す。017-action の hero.png 事故）
- 「たぶん直った」でのコミット。判定は **exit code のみ**、自己申告は読まない
- 承認なしで他フォルダへ横展開を**実行**すること（鉄則7。**候補の提案はループの最後に必ず出す**）
