# コントロールパネル（操作/設定UI）の共通化方針

> 2026-09-12 新設。2026-10-15 `CLAUDE.md` から移設（原則のみ CLAUDE.md に残す）。

> **背景**: 264フォルダ横断grepで、操作/設定UIが作品ごとにバラバラで、同じCSSが手コピーで10本連続していることが判明。
> **全数調査の結果と根拠**: `docs/20260912_コントロールパネル実装ポイント5選.md`（数値付き。着手前に必読）
> **位置づけ**: 鉄則7の例外ではない。**既存179本への一括横展開はタイタン指示があるときのみ**。下記は「新作」と「その作品を改修するとき」に適用する。

### 着手順序：コントロールパネルは「最初」に作る（2026-09-14 タイタン指示）

**新作の実装は、ゲームロジックより先にコントロールパネルから着手する。**

| 段階 | やること |
|---|---|
| 設計書（SPEC.md） | **操作/設定UIの欄を必須**にする。入力方式（キー＋タッチ）／ポーズの有無と出し方／ミュートの置き場／`localStorage` キー名（`tg.<番号>.<key>`）を、ゲーム内容を書く前に決める |
| 実装1コミット目 | **操作の骨組みだけを動く状態にする** — iOS用CSSヘッダー／Pointer Events＋`setPointerCapture`／仮想パッド（必要なら）／ポーズ／ミュート／設定の保存と読み出し。この時点で画面は空でよい |
| 実装2コミット目以降 | ゲームロジックを、動く操作パネルの上に載せていく |

**なぜ最初なのか（実測が根拠）**

後回しにすると入らないから。264フォルダの実績が証明している：

- 明示ポーズ **13本／264**（自動停止の `visibilitychange` は67本あるのに、プレイヤーが止められるのは13本だけ）
- ミュート状態の管理 **76本**（音量の語は123本にあるのに、47本は「鳴るが消せない」）
- `setPointerCapture` **61本**

どれも「後で付ければいい」と思って付かなかったもの。**先に骨組みを置けば、ゲームロジックはその上に載るだけで済む。**

### 共通化の置き場

`titans-ui/src/components/Controls/` に集約する（作成済み。2026-10-15時点の中身は FC iOS Controller＝`fc-ios-controller.css/.js`。十字キー・A/B・SELECT/START、Pointer Events＋`setPointerCapture`）。
設定パネル（ミュート・ポーズ・保存）はまだ無い。足りない部品はここへ追加し、各ゲームへの手コピーで増やさない。

### 新作・改修時に守ること（5項目）

| # | ルール | 理由・根拠 |
|---|---|---|
| 1 | **ミュートトグルを必ず置く** | 音量の語は123本にあるが状態管理は76本。**約47本が「音は鳴るが消せない」**。iPhone主戦場で致命的 |
| 2 | **`localStorage` キーは `tg.<フォルダ番号>.<key>` 形式**（例 `tg.292.best`） | GitHub Pagesは同一オリジン。接頭辞なしキー（`bestTime` `bonfireNote` 等）は**他ゲームと衝突する**。現状 camelCase / kebab-case / snake_case / 無接頭辞の4流派が混在（110本が使用） |
| 3 | **入力は Pointer Events に統一し `setPointerCapture` を必ず入れる** | `touchstart`+`mousedown` 二重バインドは6本必要で取りこぼす。`setPointerCapture` は61本しか入っておらず、**押しっぱなしバグの根因** |
| 4 | **iOS用CSSヘッダーは共通ファイルを参照する（コピペ禁止）** | 289〜298の最新10本が1バイト違わず同一＝手コピーが10連続。bodyは `touch-action:manipulation`、canvasは `none` の2段構えを崩さない |
| 5 | **明示ポーズ（プレイヤーが自分で止められる状態）を実装する** | `visibilitychange` の自動停止は67本あるが、明示ポーズは**13本のみ**。電車プレイ前提なのに中断できない |

### 仮想パッドの定石（70本から抽出。DOMオーバーレイ型で実装する）

```css
.dpad{ width:min(42vw,148px); height:min(42vw,148px); }  /* 画面比と絶対上限の両取り。px固定はSEで潰れる */
.dpad .arr{ pointer-events:none; }                       /* 子要素が親のタップを奪わない */
.dpad.press-u .arr.u{ opacity:1; }                       /* 押下表現はクラス付替えのみ（再描画ゼロ） */
@media (max-height:600px){ .dpad{ width:120px; height:120px } }
```

- canvas内に描かず **DOM側にオーバーレイ**する（`278-elevator-chanbara` が参考実装）
- `aria-label="十字キー"` を付ける（読み上げ配慮。現状ほぼ未実装）

### 音声unlockの定型（167本の共通形。崩さない）

```js
function unlock(){
  audioInit();                                          // try/catchでAC=nullに落とす＝音無しでもゲームは止めない
  if(AC && AC.state === 'suspended'){ AC.resume(); }     // iOSは必ずここを通す
  bgmStart();
}
```

### やらないこと

- 既存179本への**一括置換・横展開**（鉄則7。タイタン指示があるときのみ）
- 既存 `localStorage` キーの**勝手な改名**（セーブデータ・ハイスコアが消える。移行は指示があるときのみ、旧キーからの読み替えを入れてから）
- `titans-ui` を経由しない「その場かぎりの共通CSS」を各ゲームに増やすこと
