## 1. 企画の中心

**左右の障害物を読みながら登り、子猫を保護し、帰りは揺らさないよう慎重に降りる。**

登りのテンポと、子猫を背負った帰りの慎重さの違いが面白さ。単なる上昇距離競争にせず、「子猫のもとへ着く→なついてもらう→地上に連れ帰る」を1つの救出体験にする。1本60〜100秒、3本で4〜6分程度。時間制限なし。

タイトル候補（初期実装は1を使用）：
1. 電柱レスキュー！こねこをおうちへ：行きはすいすい、帰りはそーっと。
2. こねこ救助隊・そらまでクライム：小さな鳴き声に、会いにいこう。
3. のぼれ！にゃんこレスキュー：助けたあとも、気を抜かないで。

## 2. 世界観と見た目

夕方の小さな町。架空の救助隊員「ハル」が、電柱の上で動けなくなった子猫を迎えに行く。オレンジのヘルメット、青い作業着、背中の柔らかい救助バッグが特徴。

- 空は薄青〜夕焼け、電柱は灰色、障害は黄色と濃茶、子猫は白・三毛・黒の3匹。
- 電柱は中央。主人公が左右の側面を移り、背景の屋根が下へ流れることで高さを表現する。
- 電柱・横木・碍子・遠景の配線で題材を伝える。配線の結線や作業手順を再現するゲームにはしない。
- 救助用に通電停止済みの電柱という設定。失敗時は安全ロープに支えられ、主人公も子猫も傷つく描写をしない。
- 登りでは子猫の鳴き声が近づき、保護後はバッグから顔が見える。帰還時は飼い主に抱かれる絵を出す。

## 3. 画面と操作

縦画面、論理画面390×844。上部に高さ・体力・救助段階、中央に電柱、下部160pxを操作領域とする。PCの横長画面では縦のゲーム画面を中央に置き余白で囲う。端末横向きでも同じ比率で収め、操作ボタンは44CSS px以上を維持する。

| 操作 | キーボード | タッチ | 機能 |
|---|---|---|---|
| 左へ進む | ← / A | 左下「左」 | 左側の次の足場へ移動 |
| 右へ進む | → / D | 右下「右」 | 右側の次の足場へ移動 |
| つかまる・休む | Space | 中央「つかまる」長押し | 停止して体力・安心度を回復 |
| 子猫をなでる | Space長押し | 保護画面「なでる」長押し | 信頼ゲージを増やす |
| 一時停止 | Escape | 右上の停止ボタン | 再開・やり直す・タイトル |

左右は1回押すと1段進む。長押し自動進行なし。降りでは同じ左右操作で1段降りる。画面に「のぼる／こねこを保護／おりる」を常時表示し、操作ボタンの小見出しも「左上／右上」から「左下／右下」に変える。

## 4. 電柱と移動モデル

電柱を段番号0〜Nと、左右2レーンで表現する。0が地面、Nが子猫のいる足場。論理1段は64px。初期位置は段0・左レーン。足場は実際の登攀方法を再現せず、ゲーム用のわかりやすいマーカーで描く。

- 登りで左入力→段+1の左へ、右入力→段+1の右へ。降りでは段−1。同じ側の連続入力も可能。
- 1歩の移動時間は登り0.28秒、降り0.38秒。移動中の追加入力は保存せず無視する。キーリピートも無視。
- 左右が同じ更新ステップで押されたらどちらも受け付けず、同時押しで2段動かない。
- 移動開始時に次段の障害状態を確定してロックする。移動途中で突然障害が現れて被弾することはない。
- 衝突した場合は現在の段へ戻り、体力−18、救出後なら安心度−12、0.55秒操作停止。移動コストは追加請求しない。
- 成功した移動は到着時に段とレーンを更新し、体力コストを引く。
- 体力0でロープに支えられる演出→失敗画面。子猫の保護前なら電柱の地面から、保護後なら上の足場から再挑戦できる。
- カメラは主人公を操作領域より上に保ち、進行方向の次4段以上を見せる。最上部・地上はクランプする。

## 5. 体力と子猫の安心度

| 指標 | 登り | 降り |
|---|---|---|
| 体力 | 最大100、1歩−3、待機で減らない | 最大100、1歩−4、待機で減らない |
| つかまる | 静止中+15/秒 | 静止中+15/秒、安心度+18/秒 |
| 安心度 | 未使用 | 最大100。保護完了時100 |
| 急ぎすぎ | なし | 前回到着から0.25秒未満で次の歩行を開始すると安心度−8 |
| 待機回復 | 体力・安心度とも自然回復なし | 同左。「つかまる」で回復 |

つかまると移動入力を同時に押した場合はつかまるを優先。移動中のつかまるは、押し続けていれば到着後に開始する。

安心度25未満では子猫が震え、UIに「つかまって落ち着かせよう」。安心度0では歩行だけを禁止し、つかまるを使って25以上へ回復すると再開可能。安心度0を理由にゲームオーバーにしない。体力0が同じ瞬間に発生した場合は失敗を優先する。

休憩は無制限。急ぐほど高得点になりやすいが、休めばクリアできる。上級者への技量差は移動判断と衝突回数で作り、休憩できない行き止まりを作らない。

## 6. 障害物

| 障害 | 表示・動作 | 正解行動 |
|---|---|---|
| 張り出した看板 | 固定で片側を塞ぐ。進入禁止マーク付き | 反対側へ移動 |
| 鳥の羽ばたき | 片側だけ。待機2秒→予兆0.8秒→通行妨害0.8秒を反復 | 反対側か、妨害が終わるまで待つ |
| 風の吹き抜け | 指定段の片側だけ。平常2.2秒→予兆0.9秒→強風0.7秒を反復 | 反対側か、つかまって待つ |

静的障害も動的障害も、衝突判定は「移動先」にだけ置く。現在いる足場には後からダメージを出さず、休めることを保証する。予兆中は通行可能、妨害中だけ衝突する。予兆・妨害の残り時間を円弧で表示する。往路と復路で障害の配置は変えず、動的障害の周期は継続する。停止・保護演出中は周期を停止する。

1段に置く障害は最大1つで、反対側は常に空ける。乱数生成は初版では使わず固定配置にする。

## 7. 3本の救出ステージ

表の段は地面から数える。記載がない段は左右とも通行可能。「左看板」はその段の左を塞ぐ。

| ステージ | 高さ | 配置 | 子猫・狙い |
|---|---:|---|---|
| 1 商店街の電柱 | 16段 | 左看板4、右看板7、左看板11、右看板14 | 白猫「しろ」。左右と休憩を学ぶ |
| 2 公園わきの電柱 | 22段 | 右看板3、左鳥6、左看板9、右鳥12、右看板16、左鳥19 | 三毛猫「ミケ」。予兆を読む |
| 3 夕焼け坂の電柱 | 28段 | 左看板3、右風6、右看板9、左鳥12、左看板15、右風18、右鳥21、左看板24、右風26 | 黒猫「くろ」。帰りのペース配分 |

各動的障害はステージ開始時に待機状態、周期経過0秒とする。終端段0とNは障害なし。次の段だけでなく先の配置を見て進める視認性を維持する。

ステージ1では開始直後に「左右で1段ずつ登る」、体力60以下になった最初の1回に「つかまるで回復」を表示する。説明はプレイを長時間遮らず、初回だけ表示、タイトルから再閲覧できる。

## 8. 子猫保護と帰還

最上段到着で左右移動を停止し、救出画面に切り替える。信頼ゲージは0〜100。

1. 子猫が近づくアニメーション0.8秒。
2. 「なでる」長押しで信頼+40/秒。離すとその値を保持する。減衰・ランダム失敗なし。
3. 信頼100でバッグに入る演出1秒。体力100・安心度100にする。
4. 「ここからは、ゆっくり降りよう」を表示し、確認ボタンを押したら降りを開始する。
5. 段0へ到着すると飼い主へ引き渡し、ステージ結果を表示。「次の救助」で次へ進む。

最終ステージは3匹集合のエンディング→総合結果へ。子猫に触れただけ、保護ゲージを満たしただけではクリアにしない。地面への到着と引き渡しを必須にする。

## 9. スコアと失敗・再挑戦

ステージ得点＝max(0, 1,000＋帰還時安心度×5＋max(0, 180−プレイ秒数)×5−衝突数×100−再挑戦数×200)。最終的に整数へ切り捨てる。総合得点は3ステージの合計。

- プレイ秒数は登り・降りの操作可能時間と休憩時間のみ。保護ミニゲーム、演出、説明停止、一時停止中を除く。
- 再挑戦しても、そのステージの累積時間・衝突数・再挑戦数は持ち越す。スコアは帰還時だけ確定し、二重加算しない。
- 保護前の再挑戦は段0・左、体力100。保護後は段N・左、体力100・安心度100で降りから再開。動的障害は待機状態へ初期化。
- 「タイトルへ戻る→新しく始める」は新規ゲーム扱いで全ステージの途中状態を破棄する。
- 結果の主表示は「救助成功」と子猫。得点は副表示とし、低得点で救助を否定する文言を出さない。

## 10. 状態・音・保存

状態：TITLE → ASCEND → RESCUE → DESCEND → STAGE_RESULT → 次のASCEND。最終STAGE_RESULT → ENDING → TOTAL_RESULT。ASCEND/DESCENDからFAIL、各操作画面からPAUSEDへ遷移可能。停止解除後は元の状態へ戻り、押しっぱなし入力は持ち越さない。

- 足場移動音、鳥の予兆音、風音、子猫の鳴き声、保護・帰還の短い音を用意。音がなくても予兆を判別できる。
- 体力低下は息切れ、安心度低下はバッグの小さな揺れで表現する。大きな点滅は避ける。
- ミュート・ベスト総合得点・初回説明既読だけlocalStorageへ保存。保存できない環境でも進行可能。
- 子猫の保護済みフラグ、ステージ、移動予約、指の状態をリトライ時に明示的に初期化する。

## 11. ブラウザ・スマートフォン要件

- 入口は`index.html`。相対パスで素材を読む。外部CDNと外部フォントは必須にしない。ゲーム配信ファイル合計3MB以下を納品制約とする。
- viewportに`width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover`を指定。ノッチとホームバーを避けるsafe-areaを設定。
- 操作ボタン44CSS px以上。390×844と375×667の縦画面で、電柱と操作ボタンの両方が見えること。画面比率が違う場合はプレイ領域の表示段数と余白を調整し、ボタンを縮小しすぎない。
- ゲーム領域は`touch-action: none`。スクロール・長押しメニュー・ダブルタップ拡大を防ぐ。左右の連続タップを二重タップとして捨てない。
- Pointer EventsでpointerIdごとに押下管理し、pointer captureを使う。pointerup/cancel/lostpointercapture、blurで押下を解除。長押しボタンは1本の指を離しても別の指の押下を消さない。
- blur・画面非表示で自動停止。復帰時は手動再開。障害周期、歩行、体力、安心度、スコア時間、音声も停止する。
- CanvasのDPRは最大2、resizeで変換をリセット。論理座標と表示座標を分離し、タッチ座標の縮尺・余白を補正する。
- requestAnimationFrame＋固定1/60秒更新、最大5ステップ。長い停止後の滞留時間を捨てる。
- AudioContextはスタート操作で作成・再開。音が再生できなくてもゲームを開始できる。

## 12. 実装順と範囲

1. 8段の仮ステージで左右の1段移動、固定障害、体力、休憩を実装する。
2. 子猫保護、降り、安心度、帰還を接続し、1本を最後まで遊べる状態にする。
3. 固定配置3ステージ、鳥・風、再挑戦、スコア、エンディングを実装する。
4. 猫・町並み・音・タッチ操作を整えて受入条件を検証する。

初版にはリアル物理のロープ、配線シミュレーション、自由な電柱間ジャンプ、装備購入、オンラインランキングを入れない。

## 13. 受入条件と検証報告

- [ ] 3本すべてで登る→子猫保護→降りる→飼い主へ渡す→結果まで到達できる。
- [ ] 左右1入力で1段だけ動き、キー長押しや同時押しで多段移動しない。
- [ ] 全段で左右の少なくとも片側が安全。各ステージの登り・降り両方で通過可能。
- [ ] 移動開始後に鳥や風の状態が変わっても、確定済み移動に不意打ちの衝突を発生させない。
- [ ] 現在地で休憩でき、体力と安心度が上限100を超えない。安心度0から復帰できる。
- [ ] 体力0で失敗し、保護前後のそれぞれ正しい地点に再挑戦できる。
- [ ] 帰りは連続移動で安心度が減り、0.25秒以上の間隔では減らない。停止時間を間隔計測へ混入させない。
- [ ] なでる途中で指を離す・一時停止する・アプリを切り替えると増加が止まる。
- [ ] 保護しただけでクリアにならず、地上で1回だけスコア確定する。再挑戦で減点を消せない。
- [ ] 390×844、375×667、PCで操作を表示できる。タッチ連打でもズーム・スクロールしない。
- [ ] リトライ10回で音・処理速度が多重化せず、コンソールに致命的なエラーなし。
- [ ] 保存拒否、音声再開失敗でも遊べる。配信ファイル合計3MB以下。
