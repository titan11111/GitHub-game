## 企画書の確認範囲

- ユーザーの2つの題材を、それぞれ独立した仕様にした。
- 操作、初期数値、敵・障害、固定ステージ、状態遷移、敗北・再挑戦、保存、モバイル要件、受入条件を記載した。
- 本書で指定した面白さ、所要時間、難易度は実装後にプレイ検証して調整する。
