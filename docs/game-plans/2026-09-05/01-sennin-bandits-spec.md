## 1. 企画の中心

**敵の振りかぶりを見て避け、杖で吹き飛ばし、溜まった仙気でまとめて倒す。**

単なる連打ゲームにしない。「近づく→予兆を読む→回避→反撃→仙術」の循環を成立させる。最初の20秒で移動、攻撃、回避を体験できる。1周の目安は4〜6分、3ステージ構成。敵を倒す感触と、仙人の飄々とした強さを主役にする。

タイトル候補（初期実装は1を使用）：
1. 雲海仙人伝 ― 山道の盗賊退治：一振りの杖で、山里に平和を。
2. 仙人無双・竹林道中：ひらりとかわして、どかんと仙術。
3. ひげ仙人と三つの山道：盗賊どもよ、修行が足りぬ。

## 2. 世界観と見た目

舞台は中国の山水画を思わせる架空の山里。白ひげ・青緑の道服・木の杖を持つ仙人「雲松」が、盗賊に奪われた薬と米を取り返す。実在の王朝や人物を再現する歴史ゲームではない。

- 竹林、石橋、山門、霧の山並み。背景は彩度を抑え、主人公と攻撃予兆を見分けやすくする。
- 主人公は白・青緑、雑魚は茶・えんじ、ボスは黒・金。危険は赤い形と動作でも伝え、色だけに頼らない。
- 敵の撃破は煙・星・転がる演出。流血なし。最後に盗賊が逃げ、村人が荷物を取り戻す。
- 棒人間だけで納品しない。杖、ひげ、服の裾、頭巾で役割を識別できるスプライトまたはCanvas描画を作る。

## 3. 画面と操作

横画面、論理画面960×540。上部にHP・仙気・ステージ名、下部に操作領域。ワールドは横スクロールし、カメラは主人公の進行方向を少し先読みする。スマートフォン縦向きでは一時停止して横向き案内を表示する。回転後も勝手に再開せず、再開ボタンを出す。

| 操作 | キーボード | タッチ | 役割 |
|---|---|---|---|
| 左右移動 | ←→ / A・D | 左下の左右ボタン | 間合い調整 |
| ジャンプ | Space | 右下「跳ぶ」 | 障害物と地上攻撃を避ける |
| 杖攻撃 | J | 右下「杖」 | 地上コンボ、空中は単発 |
| 回避 | K | 右下「回避」 | 向いている方向へ短距離移動 |
| 仙術 | L | 右下「仙術」 | 仙気を消費する範囲攻撃 |
| 一時停止 | Escape | 右上の停止ボタン | 再開・最初から・タイトル |

左右とアクションは同時押しできる。攻撃・ジャンプ・回避・仙術は押した瞬間に1回発動し、押し続けて自動連打しない。左右同時押しは停止。仙術不足時は発動せず短いUI反応のみ。

## 4. 主人公と戦闘の初期値

単位は論理px・秒。数値は設定オブジェクトに集める。

| 項目 | 初期値・仕様 |
|---|---|
| HP | 最大5。敵攻撃・落下は1ダメージ |
| 移動速度 | 230px/s |
| 重力・ジャンプ | 1,800px/s²、上向き初速640px/s。空中ジャンプなし |
| ジャンプ猶予 | 足場を離れて0.10秒、着地前入力バッファ0.12秒 |
| 被弾保護 | 0.9秒。点滅し、保護中は追加ダメージなし |
| 杖の攻撃範囲 | 向いている側へ75px。主人公の胴を中心に高さ70px |
| 杖コンボ | ダメージ1→1→2。各攻撃の全長0.30/0.30/0.42秒 |
| 有効判定 | 1・2段目は開始0.08〜0.16秒、3段目は0.12〜0.22秒 |
| コンボ入力 | 各段終了前0.12秒の追加入力を1回だけ予約。途切れたら1段目へ戻る |
| 吹き飛ばし | 通常40px、3段目120px。ボスの移動量は半分 |
| 回避 | 0.22秒、速度500px/s、最初の0.16秒無敵、再使用0.7秒。地上のみ |
| 仙気 | 0〜100。杖が命中した敵ごとに+6、撃破で追加+8 |
| 仙術「雲龍掌」 | 仙気60消費、発生0.12秒、半径230px、全敵3ダメージ、1秒再使用不可 |

1つの攻撃IDは同じ敵に1回だけ当たる。仙術の命中で仙気は増えないが撃破加算は通常どおり。待機中の自然回復なし。ダメージ処理は、回避無敵→被弾保護→HP減算の順に判定する。HPが0になったフレームでは敗北を優先し、相打ちでクリアにしない。

行動優先順位：死亡 > 被弾 > 回避 > 仙術 > 杖 > 通常移動。回避は杖を中断でき、仙術中は回避不可。攻撃中の移動速度は通常の40%。空中杖は1ダメージの単発で、仙術は地上のみ。敵への接触自体にはダメージを付けない。

## 5. 敵と攻略

敵は「待機／接近→予兆→攻撃→隙→復帰→撃破」の明確な状態を持つ。画面外から攻撃しない。攻撃予兆が始まった敵は、攻撃完了まで向きを変えない。

| 敵 | HP | 行動・予兆 | 反撃の機会 |
|---|---:|---|---|
| 棍棒盗賊 | 3 | 95pxまで接近、0.55秒振りかぶり、前方100px攻撃 | 攻撃後0.7秒停止 |
| 石投げ盗賊 | 2 | 250px付近で止まり、0.7秒予兆後に石1発。石は水平260px/s | 投げた後1.1秒停止。石は杖で消せる |
| 盾持ち盗賊 | 4 | 正面の杖を防ぐ。0.8秒予兆後180px突進（0.45秒） | 突進後1秒は盾を下げる。背後・仙術も有効 |

同時に攻撃予兆へ入れる敵は最大2体。攻撃権を得られない敵は待機・間合い調整をする。敵は足場端で止まり、画面外へ追い出されたらカメラ内側へ復帰する。プレイヤーを囲めても、押し出して地形に埋めない。

ボス「黒岩頭領」：HP18。棍棒の扇状振り（予兆0.7秒・攻撃0.2秒・隙0.8秒）と直線突進（予兆0.9秒・攻撃0.5秒・隙1秒）を交互に使用。HP9以下では各予兆を0.15秒短縮し、攻撃後の隙は維持。増援なし。常時スーパーアーマーで通常の攻撃キャンセルは起きないが、ダメージとヒット反応は表示する。

## 6. ステージと進行

| ステージ | 構成 | 敵数 | 学ぶこと |
|---|---|---|---|
| 1 竹林の入口 | 全長2,800px、平地中心。開始地点は安全 | 棍棒4、石投げ2 | 移動・杖・回避。最初の1体は単独 |
| 2 渓谷の石橋 | 全長3,600px、低い段差と2か所の穴 | 棍棒4、石投げ3、盾2 | ジャンプと盾の隙。途中にHP+1の桃 |
| 3 山門の砦 | 前半1,200px＋幅960pxのボス場 | 棍棒2、盾2、ボス1 | 仙気を蓄えてボスへ |

敵配置は固定データで管理。橋の穴は幅120px以下、上り段差は70px以下とする。敵の接近だけで落下を強制しない。穴に落ちたら1ダメージで最後に安定して立った安全地点へ戻す。

各ステージは全敵撃破後に出口が開き、出口に到達すると次へ進む。残敵数と閉じた門で条件を表示する。ステージ移行でHP+1（最大5）、仙気は持ち越し。ボス場入口をチェックポイントとし、敗北時はステージ先頭またはボス場入口へ戻る。再挑戦時はHP5・仙気0、該当区間の敵・アイテム・区間スコアを初期化する。

スコアは雑魚100点、ボス1,000点、各ステージ初回クリア時HP×100点。前の区間の確定スコアと再挑戦区間の仮スコアを分け、繰り返し撃破による加点稼ぎを防ぐ。時間制限なし。結果にはスコア・総プレイ時間・再挑戦数を表示する。

## 7. 状態・演出・保存

状態：TITLE → TUTORIAL（初回のみ／スキップ可）→ PLAYING → STAGE_CLEAR → PLAYING → ENDING → RESULT。PLAYINGからPAUSEDとGAME_OVERへ遷移可能。RESULTから再挑戦・タイトルへ移れる。

- 杖命中時に最大50msのヒットストップ、3段目と仙術に小さな画面揺れ。設定で揺れをOFFにできる。
- 仙術は墨の龍と雲の輪で可視化。エフェクトの内側がダメージ範囲と一致する。
- ボス撃破→奪われた荷物が戻る→村人の礼→結果画面まで用意する。
- 音量ON/OFF、ベストスコア、チュートリアル既読のみlocalStorage保存。失敗時はメモリ内で継続する。
- リトライでイベントリスナーやアニメーションループを増殖させない。

## 8. ブラウザ・スマートフォン要件

- 入口は`index.html`。相対パスで素材を読む。外部CDNと外部フォントは必須にしない。ゲーム配信ファイル合計3MB以下を目標ではなく納品制約とする。
- viewportに`width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover`を指定。操作領域はsafe-areaを避け、タッチ目標44CSS px以上。
- ゲーム領域は`touch-action: none`、スクロール・長押しメニュー・ダブルタップ拡大を防ぐ。連打・同時押しを妨げる全画面のタッチ抑制処理は入れない。
- Pointer EventsでpointerIdごとに押下を管理。pointer captureを使用し、pointerup/cancel/lostpointercaptureで解除。キーボード入力も合成して一方の解除で他方を消さない。
- blur・画面非表示で入力を全解除し一時停止。復帰後は手動で再開。停止中は敵、タイマー、予兆、音声も停止。
- Canvasは論理座標と表示座標を分離し、DPRは最大2。resizeで変換行列をリセットする。タッチ座標は表示倍率と余白を補正する。
- requestAnimationFrame＋固定1/60秒更新、1フレーム最大5ステップ。余分な滞留時間を捨てて長い復帰時の瞬間移動を防ぐ。
- 音はスタート操作でAudioContextを作成・再開。音の許可失敗でもゲームを開始できる。
