# 手書き動物アプリ - 企画書

**企画日**: 2026-08-11  
**ターゲット**: 全年代（特に子ども・ファミリー）  
**プラットフォーム**: Web ブラウザ (モバイルファースト)

---

## 🎮 コアコンセプト

**タイトル**: 「かきました」- 描いた動物が動く魔法

ユーザーが手書きした動物を写真撮影 → AI が認識 → その動物がリアルタイムで画面内を動き回る。

---

## 🎯 ゲームループ

### 1回のプレイ（30秒版）

```
描く（30秒）→ 撮影（1秒）→ 動く（15秒）→ 終了
```

### 深いプレイ（5分版 - リプレイ性重視）

```
描く → 撮影 → 動き回す → 動物が増える（複数体対応）
    → 背景との相互作用 → ゲームクリア（全部署の動物を集める）
```

## 🎪 ゲーム体験フロー

### Step 1: 「描く」画面
```
白いキャンバス上に自由に描画
制限時間: 60秒
提供ツール: ペンサイズ変更、色選択（3色程度）
```

### Step 2: 「撮影・認識」
```
描いた絵を写真撮影 OR カメラで直接キャプチャ
AI が「何の動物か」判定（TensorFlow.js）
認識失敗時: 「何か別のものが見えました」 → リトライ
```

### Step 3: 「動く」ステージ
```
認識された動物がキャンバスに出現
ランダムに移動・ジャンプ・回転
環境との相互作用:
  - クリック/タップで動物に触る → リアクション（音 + アニメ）
  - 画面の端に到達 → 折り返す or 消える
  - 複数体なら競争・群れ行動
```

### Step 4: 「収集・ギャラリー」
```
作成した動物はギャラリーに保存
同じ種類を何度も描いたら「図鑑完成度」が上がる
（スコア化：子どもの達成感向上）
```

## 🎨 ビジュアル案

### カラーパレット
- 背景: #F0F4FF (淡い紫)
- 動物: 種ごとに異なる（ウシ=茶色、鳥=青、魚=オレンジ等）
- UI: #FF6B6B （アクセント）

### デザイン案 3 パターン

#### 案A: シンプル・ミニマル
```
白背景 + 動物だけ目立つ
適年齢: 5～8才
```

#### 案B: ゲーム感・にぎやか
```
背景にグラスモーフィズム（うっすら透ける UI）
効果音・パーティクル満載
適年齢: 8～12才
```

#### 案C: アート・シュール
```
背景が「描かれた世界」（鉛筆のテクスチャ）
ユーモアのあるリアクション
適年齢: 全年代（推奨）
```

**→推奨: 案C（アート感+汎用性高）**

## ⚙️ 技術実装案

### 絵認識方法
```
選択肢1: TensorFlow.js (mobilenet)
  ・メリット: 軽い、オフラインで動く、動物認識強い
  ・デメリット: 精度~80%、カスタマイズ困難

選択肢2: ml5.js (Image Classifier)
  ・メリット: セットアップ簡単、学習可能
  ・デメリット: 若干重い

選択肢3: クラウド API (Google Vision / AWS)
  ・メリット: 精度 95%+
  ・デメリット: 通信必須、コスト、遅延

→推奨: 選択肢1 (TensorFlow.js mobilenet) + フォールバック案C
```

### アニメーション実装
```
Canvas または Three.js
・移動: Perlin Noise ベース（ぶらぶら歩き）
・ジャンプ: タイムベース Easing（ease-out）
・リアクション: キーフレーム化（tap → bounce → smile）
```

### 技術スタック
```
フロント: Vue.js / React (状態管理)
Canvas: PixiJS (軽量) または Phaser (ゲーム向け)
認識: TensorFlow.js
音声: Web Audio API
```

## 📝 エンジニアへの実装仕様

以下をエンジニアリング部へ渡す。

1. **キャンバス描画**: HTML5 Canvas で自由描画
2. **撮影**: 描いた絵を ImageData として capture
3. **AI**: TensorFlow.js mobilenet で分類
4. **アニメーション**: Canvas 上で 60FPS 再描画
5. **タッチ反応**: click/touch イベントでリアクション

**プロトタイプゴール**: 
- 描く → 撮影 → 認識 → 1体が画面内を歩く
