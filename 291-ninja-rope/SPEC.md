# SPEC — 291｜NINJA ROPE

- 作成日: 2026-09-06

- 想定プレイ時間: 1回30秒〜2分

## 1. コアループ（何が面白いか）

操作は「押す／離す」だけ。だが離すタイミングで飛距離が変わるので、低い位置で離す＝遠くへ、高い位置で離す＝上へ、という物理の直感がそのまま上達につながる。押しっぱなしにすれば次のアンカーへ自動で掴み直すため、初心者でも落ちにくい。

## 2. 操作

- 押す: 射程内で自分より上・前方にあるアンカーへロープを張る
- 押し続ける: 掴み直しを自動で行う（初心者救済）
- 離す: ロープを切り、その瞬間の速度で飛ぶ

片手・親指1本で完結。二本指操作・スワイプジェスチャ・長い説明文を必要としない。

## 3. ルール

- 画面下に落ちると終了
- 小判を拾うと距離+4m
- 回転する鉄輪に触れると終了

## 4. 難易度カーブ

アンカー間隔と高さのばらつきが距離に応じて広がる。鉄輪は140m以降から出現し出現率が上がる。ロープ長は掴んでいる間じわじわ縮み、放置しても振り子が失速しない。

## 5. 手応え設計（ゲームデザイナー観点）

- 掴める候補アンカーに点滅リングを出し「どこを掴めるか」を毎フレーム提示
- スイングは半径拘束＋径方向速度除去の物理で、加速感が自然に出る
- 忍者は速度方向へ傾き、残像が付く
- 連続スイング数をSWINGカウントで表示

## 7. 技術

- 単一 `index.html`（共通ミニエンジンをインライン同梱）
- Canvas 2D / requestAnimationFrame / dt上限0.05秒でタブ復帰時の暴走を防止
- 音: WebAudioのオシレータ＋ノイズ合成（音声ファイル0本）
- 保存: localStorage にベストスコアのみ
