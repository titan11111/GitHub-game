# 帰り道ヒーロー

「人生の歩み」をテーマにした横スクロール型アクションゲーム。プレイヤーは時間（ステージ）の経過とともに変化する環境を走り抜け、最終目的地を目指します。

## 🎮 ゲーム概要

小学生から勇者へ、7つの帰り道を冒険する横スクロールアクションゲームです。

### ステージ構成

1. **小学生** - 基本の台とトゲ
2. **中学生** - 動く台と振り子
3. **高校生** - トゲと落石
4. **大学生** - 動く障害物とジャンプ台
5. **新社会人** - 押しつぶす壁と電気バリア
6. **サラリーマン** - 複合的な障害物
7. **勇者** - ファンタジー系の障害物

## 🚀 プレイ方法

### 操作方法

#### デスクトップ
- **左右矢印キー**: 移動
- **上矢印キー / スペースキー**: ジャンプ
- **Zキー**: 攻撃（Aボタン）
- **Xキー**: オメガビーム発動（Bボタン）

#### モバイル / タッチ
- **スティック**: 移動・ジャンプ
- **Aボタン**: 攻撃
- **Bボタン**: オメガビーム発動

## 🎯 主な機能

- **ステートマシン**: ゲーム状態の明確な管理
- **CollisionEngine**: 高度な当たり判定システム
- **Actor基底クラス**: オブジェクト指向設計
- **ランダム障害物生成**: 毎回異なる配置
- **モバイル対応**: タッチ操作サポート
- **パフォーマンス最適化**: フレームレート制御
