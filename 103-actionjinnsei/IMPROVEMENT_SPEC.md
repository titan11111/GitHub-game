## 1. [x] 攻撃クールダウンの設定

### 現状
`config.js` の `ATTACK.cooldown` が `0`（クールダウンなし）。
ボタン連打で弾が無限に出るため、ゲームが簡単すぎる。

### 改善方針
攻撃レベルごとにクールダウンを設定し、高レベルになるほど爽快感を維持しながらバランスを保つ。

```js
// config.js 変更案
PROJECTILE: {
  light:     { ..., cooldown: 15 },  // 光：やや遅め（序盤）
  fire:      { ..., cooldown: 12 },
  exploding: { ..., cooldown: 20 },
  axe:       { ..., cooldown: 25 },
  pierce:    { ..., cooldown: 15 },
  beam:      { ..., cooldown: 8  },  // ビーム：速射（終盤ご褒美）
}
```

## 2. [x] 敵の密度・出現パターン改善

### 現状
- 生成間隔: 90フレーム（1.5秒に1体）
- 最大同時出現: 5体
- 出現位置: カメラ右端の1点から固定で出てくる

### 改善方針

#### 2-1. 密度調整
```js
// config.js 変更案
ENEMY_SPAWN: {
  interval: 60,    // 90→60フレーム（密度1.5倍）
  maxCount: 8,     // 5→8体
  spawnXOffset: 850
}
```

#### 2-2. 出現位置のバリエーション
現在は右端1点からしか出ない。以下を追加する：

- **空中出現**（flyingタイプ）: 画面上方から降下
- **地下から出現**（後半ステージ）: 地面から湧き出す演出
- **ステージ後半の集団出現**: ボス手前200ユニット付近で一気に3体スポーン

#### 2-3. ステージ別出現間隔
| ステージ | 間隔（フレーム） | 最大数 |
|---------|----------------|--------|
| 1〜2    | 75             | 5      |
| 3〜4    | 65             | 6      |
| 5〜6    | 55             | 8      |
| 7       | 45             | 10     |

## 3. [x] 回復システムの安定化

### 現状
敵撃破時に5%の確率でmedkit（+30HP）ドロップ。確率が低く運に左右される。

### 改善方針

#### 3-1. 撃破数に応じた保証ドロップ
```
10体撃破ごとに1個のmedkitを確定ドロップ
```

#### 3-2. ステージ内の固定回復ポイント
各ステージの中間地点（ステージ長の50%）に「休憩エリア」を設置。
テーマに合わせた演出とセットにする（例：小学校のベンチ、社食など）。

#### 3-3. ステージクリア回復量の見直し
現在は+50HPだが、HPが低いほど多く回復するよう調整。
```
回復量 = 50 + (maxHp - currentHp) * 0.3
例：HP10→ +50 + 90*0.3 = 77HP回復
```

## 4. [x] ステージ別テーマ演出

### 現状の課題
- ステージ1・2の背景色が同じ（`#87CEEB`）
- 背景の色変化だけで、各ステージの「生活感」が薄い

### 改善方針：ステージごとの固有オブジェクト

各ステージに「背景装飾オブジェクト」と「テーマ障害物」を追加する。
いずれもCanvas描画（四角形・多角形ベース）で実装可能。

## 6. [x] ボス交渉システム

### コンセプト
ボスが出現したとき、即バトルではなく**「交渉フェーズ」**が入る。
1〜3択の選択肢から選び、成功すれば回復して次ステージへ。失敗すれば戦闘開始。

### フロー

```
ボス出現
  ↓
【交渉フェーズ】
  ボスとの会話ダイアログが表示される（ステージ別セリフ）
  ↓
3択の選択肢が出る
  ↓
  ├─ 成功 → HP回復（+40）→ 次ステージへ
  └─ 失敗 → 通常ボス戦開始
```

### 選択肢の成功/失敗ルール

| 方式 | 詳細 |
|------|------|
| ランダム方式 | 選択肢ごとに成功率を設定（正解1つ）。全部ランダムにするとゲーム性が薄い |
| スコア依存方式 | その時点のスコアが高いほど成功率アップ。「うまくやってる人は交渉も強い」 |
| **ヒント方式（推奨）** | 選択肢のひとつに文脈ヒントを忍ばせる。正しい選択肢を選べば成功 |

### ステージ別ダイアログ案

| ステージ | ボス | ボスのセリフ | 選択肢例 |
|---------|------|------------|---------|
| 1 | 学級委員 | 「廊下は走らないって言ったよね？」 | A:「走ってない」 / B:「ごめんなさい」/ C:「先生に言う！」 |
| 2 | 先輩 | 「おい、挨拶は？」 | A:「チッ」/ B:「お疲れ様です！」/ C:「なんですか？」 |
| 3 | 番長 | 「俺の縄張りに入ったな」 | A:「勝負しろ」/ B:「道を間違えました」/ C:「話し合いましょう」 |
| 4 | 教授 | 「レポートは出したか？」 | A:「明日出します」/ B:「出しました！」/ C:「何のことですか？」 |
| 5 | 上司 | 「まだ帰るのか？」 | A:「仕事は終わりました」/ B:「すみません残ります」/ C:「有給です」 |
| 6 | 部長 | 「お前の将来、俺が決めてやろうか」 | A:「お願いします」/ B:「自分で決めます」/ C:「考えます」 |
| 7 | 魔王 | 「勇者よ、何故戦う？」 | A:「世界を守るため」/ B:「帰りたいから」/ C:「あなたを倒すため」 |

### UIデザイン
- ゲームを一時停止してダイアログを全面表示
- ボスの大きなイラスト（既存の多角形描画）を左に表示
- 選択肢は3つのボタン、タップ/クリック対応
- 成功時: 緑のフラッシュ＋「交渉成功！」テキスト
- 失敗時: 赤のフラッシュ＋「交渉決裂！」→ ボス戦BGMに切り替え

### 実装ファイル
- 新規: `js/negotiation.js`（ダイアログ制御、選択肢ロジック）
- 変更: `main.js` の `bossActive` 判定部分にフェーズ分岐を追加
- 変更: `index.html` にダイアログUIを追加
- 変更: `css/style.css` にダイアログスタイル追加
