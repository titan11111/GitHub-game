# むしあみ日和｜里山昆虫図鑑

画面上の虫を虫取り網で捕まえ、58種類の図鑑を完成させる、スマートフォン・PC対応のブラウザゲームです。通信なしでもゲーム本編が動き、図鑑は端末内へ自動保存されます。追加収録した40種類は、すべて日本に生息・定着している虫です。

## 遊び方

- 虫の少し先に網を合わせて、画面をタップまたはクリックします。
- キーボードでは矢印キーで網を動かし、Space / Enterで振れます。
- 60秒の間に昼→夕暮れ→夜と時間が進みます。天気と時間によって出会える虫が変わります。
- 連続で捕獲するとコンボ倍率が上がります。網スタミナがなくなったら少し待ってください。
- 虫は生態に応じて、地表歩行・草木移動・花間飛翔・巡回飛翔・樹幹静止・夜間飛翔・跳躍・水面移動・水中遊泳など10種類の動きをします。
- 晴れ・曇りの夜は水辺にゲンジボタルとヘイケボタルが現れ、それぞれ異なる周期で明滅します。小雨時は飛翔しません。

## 採用した10のモダン技術

1. **HTML5 Canvas + DPR描画** — Retina画面でもくっきりしたフィールド描画
2. **Pointer Events** — マウス・タッチ・ペンを同じ操作系で処理
3. **Web Audio API** — 外部音源なしのリアルタイム効果音合成
4. **Vibration API** — 対応スマートフォンで捕獲時の触覚フィードバック
5. **Service Worker** — ゲーム本編と素材をキャッシュしてオフライン起動
6. **Web App Manifest** — ホーム画面追加とスタンドアロン表示
7. **Local Storage** — 図鑑、最大サイズ、捕獲数、設定を自動保存
8. **Web Share API** — 図鑑の達成記録を端末の共有画面へ連携
9. **Page Visibility API** — アプリ切替中はゲーム時間を安全に一時停止
10. **Seeded Procedural Generation** — 日付シードによる天候・出現・移動の生成

加えて、`prefers-reduced-motion`、Safe Area、ダブルタップズーム防止、キーボード操作、Web Share非対応時のClipboardフォールバックにも対応しています。

## ファイル

- `index.html` — ゲーム画面と各モーダル
- `style.css` — レスポンシブUIと演出
- `game.js` — 描画、捕獲、図鑑、保存、音、入力処理
- `manifest.webmanifest` / `sw.js` — PWA・オフライン対応
- `assets/collector-sprites.png` — 添付素材から採用した虫取り名人のポーズ画像
- `assets/summer-field-bgm.mp3` — 夏のフィールドBGM（`111-actioncat/夏マップを歩こう.mp3`から60秒・96kbpsへ最適化して転用）
