## 1. ゲーム概要

- ジャンル: 1日シミュレーション / 3択バランス
- 一言説明: 同じ主人公で月〜金を連続する。07:00〜23:00 の3択。成果を最大化するゲームではない
- 想定プレイ時間: 5〜10分
- 想定プレイヤー: iPhone Safari 片手
- クリア体験の要点: 仕事・体力・集中・満足のバランスで S〜D が決まる

## 2. 対象環境

### 必須
- 配信先: GitHub Pages
- 最優先端末: iPhone Safari
- 対応画面幅: 320px〜430px
- 実装方式: HTML / CSS / JavaScript の静的ファイルのみ
- スクロールなし（`overflow:hidden` / `touchmove` 禁止）

### 任意
- PC: キーボード `[1][2][3]` と Enter

### 未確定

## 4. コアループ

- タイトル → 月〜金の連続プレイ → 23:00でその日の結果 → 翌朝へ引き継ぎ
- 場所は状態。朝は家。出勤すると職場。出勤しなければ在宅。17時以降に退勤で家へ。終電まで残ると自動で帰る
- 選択後、結果文の上で仕事系5種の棒人間を 0.8秒（ASCII/絵文字＋CSS）。休憩はフェーズ2。HUDは同時に補間。増減チップは出さない
- 選択肢は時刻＋場所でフィルタする。07:00は家（身支度・朝ごはん・出勤）。資料作成・打ち合わせは9時以降。昼寝は12〜16時のみ。早めに寝るは家のみ
- 上司が席に立つ／同僚の休憩誘いは職場のみ。チャットや電話は在宅でも来る。曜日で出る顔が変わる
- HP / MP / SAT / 連続仕事回数は翌朝へ持ち越す（睡眠で少し回復）。WORKは日ごとにリセット
- HP≤25 で仕事: OVERWORK。HP≤45 で休憩: RECOVERY BONUS。連続仕事4回以上は曜日が遅いほど重い
- 各日は加重幾何平均で 0〜100。金曜終了時に5日平均で週ランク（成長／疲弊の解釈）

## 5. 画面 / 状態遷移

- `title` → `play` → 日次 `result` → 翌日 `play`（金の result は週まとめ）
- ヘルプはオーバーレイ1枚（4行）
- 情報は上、操作は下。時計と本文を大きくし、状態は計器1段にまとめる（スクロールなし）

## 6. 操作

- タップ（`pointerdown`）が本体。最低 56×56
- ダブルタップズーム防止、長押しメニュー防止
- ♪ でミュート。状態は `localStorage`

## 7. 音声

- BGM 5本（title / day / night / overwork / result）は HE-AAC `.m4a`。初回タップ後に再生
- 夜は `hour>=20` で 0.8秒クロスフェード。HP≤25 は overwork
- SE 10種は事前ロード＋`currentTime=0`

## 8. 画像

- `images/` に PNG-8。OGP 1200×630、favicon、行動アイコン12、イベント urgent、ランク S/A
- テキストと数値は画像に置き換えない

## 9. 保存

- `TODAY_EXE_DAY038_SAVE_V1`: high / bestRank / plays
- `TODAY_EXE_DAY038_WEEK_V1`: 月〜金の days / 翌朝 carry
- `TODAY_EXE_DAY038_MUTE`: ミュート

## 10. 実装制約

- 公開実体 20MB 以下（現状約 9.5MB）
- 外部 CDN なし
- iOS 自動再生禁止のため、開始タップで Audio unlock

## 11. テスト項目

- タイトルから月曜開始、23:00で火曜へ引き継ぎ、金曜で週判定
- ミュートの再訪保持
- iPhone 縦でスクロールしない
- 音は開始タップ後のみ
