# 221 / Day45 — ダンゴムシの谷渡り（仮）

## 一言説明
操作できない虫を、ブロックの積み方だけでゴールさせるテトリス。

## 確定ルール（2026-08-30 タイタン確認済み）

### フェーズ1｜橋を架ける（プレイヤーが操作する）
- 谷に縄が渡してある。その上にテトリスのブロックが落ちてくる
- **10列**。積み切る（落ち切る）と橋が完成し、フェーズ2へ自動移行
- 谷の下には濁流が流れている

### フェーズ2｜渡る（プレイヤーは操作しない）
- ダンゴムシが**左から順番に**橋へ入る
- **通れるのは「短い辺（1コマ幅）」の部分だけ**
- 壁に当たったら方向転換する。**前回右に曲がったなら今回は左、前回左なら今回は右**（交替性転向反応＝実在のダンゴムシの習性。ランダムではなく完全に決定論的）
- 通れなかった → 丸まって落下し、川底の濁流へ（`assets/dangomushi-ball.svg`）
- 渡り切った → 谷の反対側に到達＝クリア

## 描画方針
- **Canvas 2D の擬似アイソメトリック投影**（HD-2D風／基本は俯瞰、少しだけ立体）
- Three.js は使わない（単一HTML方針・iOS Safari の初回ロード・グリッドの読みやすさを優先）
- `screenX = ox + (gx - gy) * TILE_W/2` / `screenY = oy + (gx + gy) * TILE_H/2 - gz * BLOCK_H`
- ブロック1個 = 天面／左面／右面 の3ポリゴン塗り。画像アセットは使わない
- **着地予測ゴースト必須**（斜め見下ろしだと落下先が読めなくなるため。これが無いと操作性が破綻する）

## アセット
- `assets/dangomushi.svg` … 真上から見た歩行状態（右向き）
- `assets/dangomushi-ball.svg` … 丸まった状態（落下・被弾時）

## 短辺判定（確定・実装済み）

各ピースの外接矩形を見て、**短い方の辺に接するマスが抜ける**。

| ピースの形 | 判定 | 結果 |
|---|---|---|
| 縦長（幅 < 高さ） | 上下の短辺が抜ける | 縦棒なら上下2マスが道になる |
| 横長（幅 > 高さ） | 左右の短辺が抜ける | 横棒なら両端2マスが道になる |
| 正方形（幅 = 高さ） | 短辺が無い | **Oピースは絶対に抜けない完全な壁** |

マスの3状態:
- **壁**（ブロックが残っている）… 通れない。ぶつかると交替性転向
- **道**（短辺が抜けた穴）… 通れる
- **空**（そもそもブロックが無い）… 橋が無い。踏むと濁流へ落下
