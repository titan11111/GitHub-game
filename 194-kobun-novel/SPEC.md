# SPEC — 194-kobun-novel『月夜綺譚（つきよきたん）』

## 一行説明

月夜の山をさまよう男の身に起きる怪異を、**純古文の本文（常に三行）**と選択肢でたどる和風サウンドノベル。読み進めながら中学〜高校基礎レベルの古語を収集する。

## ねらい

- 古文を「訳す対象」ではなく「読んで進む物語の言葉」として体験させる
- 一場面 = 三行という制約で、一息で読める分量に固定する
- 選択肢の語尾をすべて意志の助動詞「〜む」で統一し、文法を操作そのもので体得させる

## 画面と操作

| 要素 | 内容 |
|---|---|
| 表紙 | 「触れて始めよ」タップで WebAudio を解錠して開始（iOS 必須） |
| 本文 | 常に三行。一文字ずつ筆写表示。タップで送り切る |
| 古語 | 本文中で朱＋傍点。触れると語義の付箋が開く |
| 訳ボタン | 現代語訳（三行）の表示切替 |
| 選択肢 | 短冊。番号は一・二・三。結末では藍色に変わる |
| 音 | 都節音階の間欠BGM＋風の環境音。ミュートは localStorage に保存 |
| 単語帳 | 全25語。習得済みのみ開示 |
| 結末巻 | 全26結末の到達状況。未到達は伏せる |

## 物語構造

- 場面数: **44**（すべて `start` から到達可能／死にリンクなし）
- 結末数: **26**
- 分岐の柱: 笛（山神・白鹿）／道しるべ（塚の女・夜明け）／古庵（月姫・古狐）
- 結末では「岐れ道へ立ち戻らむ」で直前の分岐に戻れる（履歴スタック）

## 古語データ

- 語数: **25**（あり・けり・いと・あはれ・をかし・あやし・おそろし・めでたし・いほり・うた・よむ・たまふ・ぬ・む・ゆかし・かなし・いみじ・まめなり・つれづれ・かしこし・おどろく・つとめて・もがな・ゆめゆめ・なほ）
- 各語に `forms`（本文中の表記ゆれ）を持ち、本文を分かち書きして該当箇所だけを強調する
- 「む」は本文に出さず、初回の選択時に習得させる（選択肢の語尾＝意志の「む」であるため）

## 意匠（純和風）

- 書体: 見出し・本文とも **Yuji Syuku**（筆書き楷書）、解説等は **Shippori Mincho B1**
- 配色: 墨 `#17120f` / 和紙 `#efe4cd` / 朱 `#b03a2e` / 藍 `#22405f` / 金 `#c39a4e`
- 造形: 巻物（上下に軸）・縦書きの章題帯・木札ボタン・短冊の選択肢・朱印・和綴じ本のモーダル
- 背景: 夜空のグラデーション、月、霞、障子の格子、舞う花びら（Canvas）
- アイコン画像は使わず、すべて漢字一文字（月・笛・庵・狐・歌 …）で表す

## 技術構成

ビルド不要の静的構成。ゲームフォルダ直下にフラット配置（`js/` `css/` は作らない）。

| ファイル | 役割 |
|---|---|
| `index.html` | マークアップのみ |
| `style.css` | 意匠すべて |
| `dictionary.js` | 古語25語 |
| `story.js` | 物語44場面 |
| `script.js` | 進行・筆写・音・保存 |

- 外部依存は Google Fonts のみ（Tailwind / FontAwesome / Tone.js は撤去）
- 音は音源ファイルを持たず Web Audio API で合成
- 通信量 **0.09MB**（3MB鉄則に対して十分な余裕）

## 三行を守る仕組み

1. データ側で `lines` と `modern` を必ず3要素にする（検証スクリプトで担保）
2. `.honbun__line` は `white-space: nowrap`
3. 起動時・フォント読込後・回転時に、**全44場面中で最も長い行**を隠し要素で実測し、
   3行すべてが折り返さない最大の文字寸法を `--honbun-size` に設定する

→ 端末幅ごとの実測値: 320px→12px / 390px→14.5px / 430px→16px / 768px→19px（いずれもはみ出しゼロ）

## iOS 対応

- `viewport-fit=cover` ＋ `env(safe-area-inset-*)`
- `touch-action: none`、選択・ドラッグ・長押しメニュー・ジェスチャ拡大を抑止
- ダブルタップズーム防止。ただし **操作部（button / .kogo / スクロール領域）では `preventDefault` しない**
  （touchend の preventDefault は後続の click を取り消し、連続タップが無反応になるため）
- 開始タップで AudioContext を生成し、無音バッファを再生して解錠。復帰時に `resume()`
- タップ時に `navigator.vibrate(12)`＋`:active` の縮小＋効果音の三点フィードバック
