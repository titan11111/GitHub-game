# SPEC.md — 317-day089 セリフ箱RPG Slash Order Tale

## 概要
- タイトル画面 → セリフ落とし → スラッシュ → 物語RPG（家→駅→解決→エンディング）のシンプルRPG
- あらゆるキャラのセリフがランダム。スラッシュの順番で物語の順番が決まる
- 3Dは擬似3D（Canvas透視投影の回廊）。Three.js不使用（20MB鉄則・CDN監査回避）
- 単体 `index.html`＋既存アセットのみ。新規バイナリ追加なし

## 進行フロー
1. TITLE：タップで開始（Audio unlock＋BGM開始）。JPEGを背景に使用
2. DROP：落ちてくるセリフブロック6個をタップで箱へ回収。箱が満タンで次へ
3. SLASH：箱の6個を指／マウスでなぞって斬る。通過順がセリフ順（1〜6位表示）。「おまかせ」あり
4. STORY：6拍を4幕で再生（家→駅→異変→解決→ED）。「つぎへ」で進行。背景は幕で色変え
5. ENDING：3種分岐（ハッピー／不思議／爆笑）。プレイ回数・見たEDを保存

## 6拍の割当（固定話者＋ランダム本文）
1. 家・主人公（朝の目覚め）
2. 家・母（送り出す一言）
3. 駅・駅員（異変の知らせ）
4. 駅・異変そのもの（ナレーション）
5. 街・仲間（解決のひらめき）
6. エンディング（ナレーション＋オチ）

本文は18種プールから6種を抽選。各20字前後でどの拍にもハマる抽象度にする。
ED分岐＝斬順セリフの文字コード合計 mod 3。

## 操作/設定UI（コントロールパネル・最初に実装済）
- ミュートトグル（右上、常時）。`tg.317.muted`
- 明示ポーズ（右上）。モーダルで再開／はじめから。`visibilitychange`でも自動停止
- 保存キー：`tg.317.muted` `tg.317.plays` `tg.317.endings`（接頭辞統一）
- 入力：Pointer Events＋`setPointerCapture`。スラッシュはpointermove軌跡と矩形交差
- iOS用CSSヘッダー（touch-action二段構え・safe-area・二重タップ防止）

## 音声
- BGM：`Hard_Target_Lock.mp3` を`<audio loop>`1要素で再生（iOSはunlock後にplay）
- SE：WebAudio短ビープ（タップ／回収／斬／進行）。失敗時もゲーム継続

## ファイル
- `index.html`（単体、外部CDNなし）
- BGM 1曲参照、JPEG 1枚をタイトル背景に参照（未参照アセットを残さない）
- 他3曲は予備として残置（監査で未使用扱いの場合は次回圧縮・整理）

## 受け入れ条件
- harness PASS、合計20.00MB以下、consoleエラー0
- タップ→回収→斬順→6拍→EDの通しプレイが指だけで完走できる
