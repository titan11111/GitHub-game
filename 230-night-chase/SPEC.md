# 230-night-chase｜仕様書

## 1行でいうと
夜の峠を、前半は逃げる車を**追い**、後半はパトカーから**逃げる**。飛び出すけものを**よける**。

## 遊びの芯
アクセルを踏むほど勝ちに近づくが、**踏むほど自車は画面の前へ出て、道幅の狭い所へ自分から入る**。
速さと安全が同じレバーの両端にある、というのが唯一のルール。

## 操作
| 入力 | 効果 |
|---|---|
| ▲ / ↑ / W / 画面を上へなぞる | アクセル。速度と画面上の前進位置が上がる |
| ▼ / ↓ / S / 画面を下へなぞる | ブレーキ。速度が落ち、車は後ろへ下がる |
| ◀ ▶ / ← → / 画面を横へなぞる | ハンドル |

- 無操作の巡航（速度0.84）は**じりじり不利**。踏み続ける判断を毎秒させるための基準値
- ブレーキは3.0/s で効き、アクセルの立ち上がりは1.85/s。**止まるのは速く、戻るのは遅い**

## 勝敗
| 区間 | 条件 | 負け |
|---|---|---|
| 前半（0〜50%） | 逃げる車を追う | 車間 > 430 で見失う |
| 後半（50〜100%） | パトカーから逃げる | 車間 < 18 で追いつかれる |

GOAL = 16000（全開でおよそ25秒）。

## けもの
### 種の差
| 種 | 速さ | 被害 | 特徴 |
|---|---|---|---|
| いのしし | 遅め | 0.50 | 走りながら**加速**して突っ切る。重い |
| たぬき | 中 | 0.34 | ライトに**固まる** |
| ねこ | 速い | 0.30 | 道半ばで**引き返す**フェイント |

### 個体の性格（同じ種でも3通り）
各個体は生成時に性格を1つ引く。`spd`（速さ）`stop`（途中で固まる率）`turn`（引き返す率）
`warn`（予告の長さ）`size`（体格）が変わり、**姿勢にも出る**（臆病＝耳を伏せて腰を落とす／気が強い＝前傾）。

- いのしし: 突進 / のろま / 用心
- たぬき: かたまり / うろうろ / ずぶとい
- ねこ: フェイント / 一直線 / びびり

### 出現の仕方（4通り）
| 種別 | 内容 |
|---|---|
| side | 路肩から（基本・42%） |
| far | 遠くに先に見える＝読ませる出し方（20%） |
| onroad | すでに道の上をうろついている（22%） |
| near | 手前から。反応時間が短い。序盤は出さない（16%） |

### 見せ方
夜道なので**目の反射光**が最初に見える。待機中と固まっている間は両目が光り、これがそのまま警告になる。

## 様式
パンクメタルのフライヤー。黒 `#050507` / 骨色 `#EDE6D8` / 血の赤 `#C8102E` / 毒の黄 `#E8DB00` の4色。
タイトルは Impact の版ズレ組み、養生テープ、手でちぎった帯、ポスターの裂け目。**画像と外部フォントは1つも使わない**。
本編にも同じ粒子とビネットを重ね、タイトルと地続きにしている。

## 性能の制約
- `DPR` 上限は **1.6**。粒子の乗る絵なので等倍の精細さは不要で、描画量を4割落とすため
- 粒子とビネットは**1枚に焼いて1回だけ貼る**。毎フレーム塗ると DPR2 で 17fps まで落ちる（実測）

## 未解決
**全開固定が最も強い**。丁寧に走る方針より成績が良い状態が残っている。詳細と数値は `LEARNINGS.md`。
