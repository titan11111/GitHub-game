# SPEC — 292｜GRAVITY FLIP

- 作成日: 2026-09-06
- フォルダ: `292-gravity-flip`
- ジャンル: 重力反転アクション
- 想定プレイ時間: 1回30秒〜2分

## 1. コアループ（何が面白いか）

操作が1つしかないのに、床側と天井側という2つの安全地帯があるため「どちらに居るべきか」の判断が常に発生する。交互スパイク地帯ではタップがリズムゲームになる。

## 2. 操作

- タップ: 重力の向きを上下反転（空中でも可）
- 連打で微妙な高さ調整も可能

片手・親指1本で完結。二本指操作・スワイプジェスチャ・長い説明文を必要としない。

## 3. ルール

- 針・壁に触れると終了
- 青いオーブを拾うと距離+3m、連続取得でCHAIN倍率
- スコアは走行距離(m)

## 4. 難易度カーブ

速度は330→700px/sへ増加、障害物間隔は距離に応じて最大46px縮む。壁ブロックは必ず片側に通り道があり、理不尽な即死配置を作らない設計にした。

## 5. 手応え設計（ゲームデザイナー観点）

- 反転時にリング状の衝撃波・画面の軽い振動・ピッチ違いの効果音
- 現在の重力方向を右端の三角アイコンで常時提示
- オーブは必ず「安全な側」に配置され、正解ルートの誘導灯になっている
- 走査線の斜めスクロールで速度感を出す

## 6. 画面構成

- タイトル: 番号 / タイトル / 一行コンセプト / 操作3行 / 「タップでスタート」
- プレイ: 左上にDISTANCE、右上にBEST、それ以外はゲーム画面
- リザルト: スコア / ベスト / ハイスコア更新演出 / 「タップでリトライ」

## 7. 技術

- 単一 `index.html`（共通ミニエンジンをインライン同梱）
- Canvas 2D / requestAnimationFrame / dt上限0.05秒でタブ復帰時の暴走を防止
- 音: WebAudioのオシレータ＋ノイズ合成（音声ファイル0本）
- 保存: localStorage にベストスコアのみ
- iOS: `touch-action:none` / `gesturestart`と`dblclick`のpreventDefault / safe-area padding / devicePixelRatio上限2.5
