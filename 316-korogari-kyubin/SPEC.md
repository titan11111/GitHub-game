# 316 ころがり急便 — SPEC

転がる配達人が、道なりに走る偽配達人の軽トラより先に、廃村の受取人へ荷物を届ける3Dアクション。全十便。

## 操作/設定UI

| 項目 | 内容 |
|---|---|
| 入力 | 画面下のファミコン型コントローラー（自動で前進）。十字キー左右＝曲がる／下＝ブレーキ／A＝ジャンプ／B＝ダッシュ。キーボードは W A S D・スペース・Shift |
| ポーズ | START で一時停止／再開。画面が隠れたら自動で一時停止 |
| ミュート | 「届け先の廃村」画面の「音：あり／なし」。`tg.316.mute` に保存 |
| セーブ | `korogari-kyubin`（解放済みの村・最速タイム）。接頭辞なしの旧形式。改名するなら旧キーからの読み替えを先に入れる |
| 操作説明の置き場 | タイトルには置かない。配達伝票（出発前の画面）の「操作」欄 |

## 画面の流れ

闇（「お届け物です」）→ 触れる → タイトル → 届け先の廃村 → 配達伝票 → 3・2・1 → 配達 → 新聞（配達完了／荷物、届かず）

## 場面と音楽

audio 要素は1つだけ。src を差し替え、音量は GainNode で動かす。

| 場面 | 曲 | 理由（波形の実測） |
|---|---|---|
| タイトル・村えらび・配達伝票 | Nine_Turns_of_the_Key | 出だしが最も静か（-27dB）で、そこから大きくうねる。闇から題字が出る流れに合う |
| 配達（第1〜7便） | Cold_Glass_Confession | 音量が最も一定（変動幅5.5LU）で拍が強い。走り続ける場面で波が邪魔にならない |
| 配達（第8〜10便：濃霧の鉱山・夜の都市伝説の村） | The_Uninvited_Guest | 前半75秒が静かで後半に膨らむ。追ってくるものが出る後半の村向き |
| 配達完了の新聞 | Through_the_Morning_Veil | 低音が最も少ない。生きて帰れた側の曲 |
| 受取拒否（失敗の暗転〜号外） | 無音＋低いうなり | 曲を切って、効果音と文字だけにする |
| 一時停止 | 鳴っている曲を1/4の音量に | |

曲の差し替えは `index.html` の `TRACK`、音量は `VOL` の1行ずつ。

## 合格条件

- フォルダの公開実体が20MB以下
- コンソールエラー0件、リクエスト失敗0件
- 上の表のとおりに曲が切り替わる（`window.__g.music` で確認できる）
