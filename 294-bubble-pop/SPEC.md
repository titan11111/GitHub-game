# SPEC — 294｜BUBBLE POP

- 作成日: 2026-09-06
- フォルダ: `294-bubble-pop`
- ジャンル: パズル / シューター
- 想定プレイ時間: 1回3〜8分

## 1. コアループ（何が面白いか）

狙いを定める楽しさと、繋がっていた塊がごっそり落ちる爽快感。壁バウンド込みの照準ガイドを出しているので「勘で撃つ」ストレスがなく、代わりに「どこを狙えば大量に落ちるか」という本来の面白さに集中できる。

## 2. 操作

- ドラッグ: 照準（壁反射2回まで軌道を点線でプレビュー）
- 指を離す: 発射
- 真横〜真下には撃てないよう角度を制限

片手・親指1本で完結。二本指操作・スワイプジェスチャ・長い説明文を必要としない。

## 3. ルール

- 同色3つ以上つながると消える
- 消えた結果ぶら下がりになったバブルは落下し、1個30点のボーナス
- 6発ごとに天井から新しい行が降りてくる
- 危険ラインまで届くと終了／全消しで+500点と色数追加

## 4. 難易度カーブ

色数は4色開始、26発ごとに1色増（最大6色）。追加行の間隔は6発→最短4発まで短縮。全消しすると盤面リセット＋色数+1で、上手い人ほど濃い盤面になる。

## 5. 手応え設計（ゲームデザイナー観点）

- 照準の点線プレビューが最大の親切設計。壁バウンドを含めて着弾点まで見える
- 落下ボーナスは別トーストで通知し、狙う価値があると学習させる
- 天井が降りてくる残り発数を常時HUD表示（不意打ちにしない）
- 次に撃つ色は必ず盤面に存在する色から選び、詰みを防ぐ

## 6. 画面構成

- タイトル: 番号 / タイトル / 一行コンセプト / 操作3行 / 「タップでスタート」
- プレイ: 左上にSCORE、右上にBEST、それ以外はゲーム画面
- リザルト: スコア / ベスト / ハイスコア更新演出 / 「タップでリトライ」

## 7. 技術

- 単一 `index.html`（共通ミニエンジンをインライン同梱）
- Canvas 2D / requestAnimationFrame / dt上限0.05秒でタブ復帰時の暴走を防止
- 音: WebAudioのオシレータ＋ノイズ合成（音声ファイル0本）
- 保存: localStorage にベストスコアのみ
- iOS: `touch-action:none` / `gesturestart`と`dblclick`のpreventDefault / safe-area padding / devicePixelRatio上限2.5
