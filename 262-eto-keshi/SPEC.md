# 262-干支けし ときどき猫 — SPEC

最終更新: 2026-09-27

## これは何か

十二支の駒を並べ替えて消す、**3分一本勝負のタイムアタック**。成績は「3分で何枚消せたか」。
題は「干支けし ときどき猫」、副題は「猫は残る。」——十二支に入れなかった猫が盤に混じっている。

- エントリ: `index.html`（`eto-keshi.html` へのリダイレクト。旧URL維持のため改名しない）
- 公開: https://titan11111.github.io/262-eto-keshi/
- 素材: `animals.js`（干支12体＋猫の描画）、`Twelve_Symbols_Rising.m4a` / `.mp3`（BGM。iOS向けにHE-AAC優先）

## ルール

| 項目 | 内容 |
|---|---|
| 盤面 | 9列 × 12行 |
| 制限時間 | **180秒（3分）**。手数制限なし |
| 成績 | **消した枚数**（干支＋猫の合計）。点数と猫の数は副成績 |
| 交換 | 隣接1マスと交換。**縦・横・斜め**すべて可 |
| 消える条件 | ①同じ干支3つ ②十二支の順に3つ（逆順・戌→亥→子の一周も可） |
| 自分の干支 | 開始前に12支から1つ選ぶ。自分の干支が消えると**隣接8方向の猫も一緒に消え**、猫1匹につき+50点×連鎖 |
| 点数 | `消した枚数×10×連鎖 + 猫の数×50×連鎖` |
| 猫の発生率 | 新規生成時 9%（`CAT_RATE`） |
| 手詰まり | 「猫けし」（下記）が使える。回数切れなら自動シャッフル |

### ランク（消した枚数）

| ランク | しきい値 |
|---|---|
| 神域 | 600枚以上 |
| 達人 | 450枚以上 |
| 一人前 | 300枚以上 |
| 端数 | 150枚以上 |
| 猫勝ち | 150枚未満 |

根拠（2026-09-27 WebKit 390×844 の自動プレイ実測）: 即断ボット 294手/1380枚、1.2秒考えるボット 104手/450枚。1手あたり約4.3枚。

## 操作／設定UI（コントロールパネル）

| 項目 | 実装 |
|---|---|
| 入力 | Pointer Events 一本化。`setPointerCapture` あり。タップ2回でも、スワイプ（`SWIPE_MIN = 0.18セル`）でも交換できる |
| 当たり判定 | `cellAt()` が周囲9マスから最寄りを選ぶ（`CELL_HIT = 0.92セル`）。指の太さを吸収する |
| 救済 | **「猫けし」**。手詰まりのときだけ押せる。盤面の猫をまとめて消す（1匹50点）。**1ゲーム2回**。猫が0匹のときは回数を消費せずシャッフル |
| ヒント | 最後に消えてから**30秒**動きがないと、1手で消える組（そろう3マス＋交換相手）が金の輪と星で光る。盤が動いた時点で消える |
| ミュート | HUD右端の 🔔（BGMと効果音の両方）。`tg.262.mute` に保存 |
| 明示ポーズ | **未実装**（タブが裏に回ると時計とBGMは止まる） |
| localStorage | `tg.262.best-cleared`（3分で消した最高枚数）／`tg.262.mute`／`etokeshi_me`（前回選んだ干支・旧キーのまま）。旧 `etokeshi_best`（点数）は指標が違うため引き継がない |
| 低刺激対応 | `prefers-reduced-motion` で画面ゆれ・光柱・ヒントの点滅を止める |

## 画面の流れ

タイトル（十二支の輪＋最高枚数）→ 遊びかた → 干支えらび（4×3）→ プレイ（3分）→ 時間切れ（ランク・消した枚数・点数・猫・最高）→ もう一度／干支えらび

## やらないと決めたこと

- 手数制（30手）は廃止した。時間制と併用しない
- 猫けしを手詰まり以外でも押せるようにしない（時間内の枚数稼ぎが1ボタンになるため）
