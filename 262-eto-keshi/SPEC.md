# 262-干支けし ときどき猫 — SPEC

最終更新: 2026-10-03

## これは何か

十二支の駒を並べ替えて消す、**3分一本勝負のタイムアタック**。成績は「3分で何枚消せたか」。
題は「干支けし ときどき猫」、副題は「猫は残る。」——十二支に入れなかった猫が盤に混じっている。

**2026-10-03 追加**: 交点◇で接する **4駒を浮かせて回転**（左/右ボタン・ドラッグ・収める）。

- エントリ: `index.html`（`eto-keshi.html` へのリダイレクト。旧URL維持のため改名しない）
- 実体: `eto-keshi.html`
- 公開: https://titan11111.github.io/262-eto-keshi/
- 素材: `animals.js`, `Twelve_Symbols_Rising.m4a` / `.mp3`
- 回転の設計メモ: `docs/rotation-mechanism.md`

## ルール

| 項目 | 内容 |
|---|---|
| 盤面 | 9列 × 12行 |
| 制限時間 | **180秒（3分）**。手数制限なし |
| 交換 | 隣接1マス（縦・横・斜め） |
| 回転 | 内部交点◇で4駒を時計/反時計回り。軸または「収める」で確定。配置が変われば消去判定 |
| 消える条件 | 同じ干支3つ、または十二支の順3つ（逆順・一周も可） |
| 自分の干支 | 開始前に選択。消えると隣接8方向の猫も消え +50点×連鎖 |
| 出現する干支 | **12種すべて**（6種だけに絞る仕様ではない） |
| 落下補充 | 袋方式（各干支を同数混ぜてから取る） |
| 猫けし・ヒント・ミュート | 従来どおり（SPEC 2026-09-27） |
