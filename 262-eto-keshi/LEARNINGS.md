# 262-干支けし ときどき猫 — LEARNINGS

## 2026-09-26 プレイ画面を飛鳥時代風へ／消去の爽快感を作り直す

### やったこと

**1. 見た目（飛鳥時代）**
- 配色を藍×金（江戸寄り）から飛鳥の顔料へ総入れ替え。朱（丹塗り）・緑青・黄土・白亜（漆喰）・墨・金。
- 盤を「伽藍（がらん）」の額に入れた。DOM側で組む：瓦屋根（軒丸瓦の列）＋丹塗りの枠＋礎石。canvasの升目計算に干渉しないよう、枠は `.garan` の padding として持ち、`resize()` が `getComputedStyle` で実測して差し引く（数値の二重管理をしない）。
- 駒を**軒丸瓦の複弁蓮華文**にした。外縁の珠文・花弁8枚・中房、隅に干支の印。丸い駒がそのまま瓦に見える形なので、絵を足さずに時代が変わる。
- 猫は座布団（江戸）をやめて**礎石**（四角い石＋のみ跡）に。自分の干支が隣にいるときは**光背**が出る。
- 盤の地（漆の板・連子窓の縦桟・布目・中央の蓮華文透かし・四隅の忍冬唐草）は毎フレーム描かず、`resize()` 時に1枚のオフスクリーンcanvasへ焼いて `drawImage` するだけにした。
- 背景の忍冬唐草はインラインSVGのdata URI（外部画像を増やさない）。

**2. 消したときの爽快感（7つ足した）**
| 仕掛け | 中身 |
|---|---|
| ヒットストップ | 消える瞬間、盤だけ 0.07〜0.12秒 止める。消える駒のアニメだけは進める |
| ふくらみ→白熱 | 縮むだけをやめ、1.0→1.38倍に膨らみ白熱→弾けて回転しながら消える |
| 衝撃の輪 | 消えた升ごとに金の輪が広がる |
| 花びらと金粉 | 粒を10〜20個へ増量。**3割を金色に固定**（漆の暗い盤では駒色の粒が沈むため） |
| 画面ゆれ | 連鎖数と消した枚数で 2.6〜9px。`prefers-reduced-motion` で0 |
| 仏の光 | 5枚以上まとめて消すと金の光柱が立つ |
| 音 | 単音のpopをやめ、**鐸（たく）**＝倍音4本重ねの鐘に。連鎖ごとに**律音階**で音が上がる。4枚以上で太鼓のひと打ち |

連鎖表示は漢数字（二連・三連…）。5枚以上は「大あたり」。`navigator.vibrate` も連鎖に応じて（iOS Safariは無反応だが害なし）。
