## 2026-09-27 救済を「猫けし」へ／30秒で光るヒント／題字の角印を外す

### やったこと

- **救済ボタンを「自分の干支けし」→「猫けし」に差し替え**。手詰まり時に盤面の猫を**まとめて**消す（1匹50点・猫カウントに加算）。1ゲーム2回・手数は消費しない。盤に猫が1匹もいないときは回数を消費せずシャッフルへ落とす。消したあと落下でそろった分は連鎖として `resolveMatches` に流す
- **30秒ヒント**。消えてからの経過を `idle` に秒で積み、30秒で `findHint()` が1手で消える組（交換する2マス＋そろう3マス）を探して金の輪＋四方の星でキラキラさせる。盤が動いた時点（`resolveMatches` の締め）で `idle=0` / `hintCells=[]` に戻す。`prefers-reduced-motion` では回転と点滅を止めて静かな光だけにする
- タイトルの角印「流通禁止」を削除

### 測ったこと（WebKit / 390×844・DPR3、計測用に HINT_SEC=3 へ落とした複製で実施）

| 項目 | 実測 |
|---|---|
| ヒント発火 | 1.0秒時点 `hintCells=[]` → 4.6秒時点 `["0,0","1,1","2,2","0,1"]`（3マス＋交換相手1マス） |
| キラキラが描かれているか | canvas の 180ms 差分で **20,281画素**が変化（点滅している実体がある） |
| 猫けし | 猫14匹 → 0（残3は落下後に新規生成されたぶん）／`cats 0→14`／`score +1390`（14×50=700＋連鎖分）／`rescues 2→1`／`moves 30→30`（消費なし） |
| pageerror / requestfailed | 0件 / 0件 |
| harness | RESULT PASS（RAF 61/秒・通信量1.46MB） |

### 学び

- **ヒントの対象マスは「交換後の一致位置」と「交換する2マス」で重複する。** Set で潰さないと同じマスへ二重に光を描いて1マスだけ濃くなる（初版で `0,4` が2回入った）
- 救済の入口（手詰まりのみ・2回まで）は据え置き、**消す対象だけを差し替えた**。猫はマッチ不能の障害物なので、消せば詰みも同時に解ける

## 2026-09-26 プレイ画面を飛鳥時代風へ／消去の爽快感を作り直す

### やったこと

**1. 見た目（飛鳥時代）**
- 配色を藍×金（江戸寄り）から飛鳥の顔料へ総入れ替え。朱（丹塗り）・緑青・黄土・白亜（漆喰）・墨・金。
- 盤を「伽藍（がらん）」の額に入れた。DOM側で組む：瓦屋根（軒丸瓦の列）＋丹塗りの枠＋礎石。canvasの升目計算に干渉しないよう、枠は `.garan` の padding として持ち、`resize()` が `getComputedStyle` で実測して差し引く（数値の二重管理をしない）。
- 駒を**軒丸瓦の複弁蓮華文**にした。外縁の珠文・花弁8枚・中房、隅に干支の印。丸い駒がそのまま瓦に見える形なので、絵を足さずに時代が変わる。
- 猫は座布団（江戸）をやめて**礎石**（四角い石＋のみ跡）に。自分の干支が隣にいるときは**光背**が出る。
- 盤の地（漆の板・連子窓の縦桟・布目・中央の蓮華文透かし・四隅の忍冬唐草）は毎フレーム描かず、`resize()` 時に1枚のオフスクリーンcanvasへ焼いて `drawImage` するだけにした。
- 背景の忍冬唐草はインラインSVGのdata URI（外部画像を増やさない）。

**2. 消したときの爽快感（7つ足した）**
| 仕掛け | 中身 |
|---|---|

## 2026-09-27 干支の絵を写実寄りへ／曲BGM（iOS）／タイトル・エンディングを和へ

### 絵（animals.js 全面描き直し）

- 12体＋猫を**土人形の記号**から**顔の肖像**へ。共通部品（`eye` 虹彩＋瞳孔＋ハイライト2点、`nose`、`mouthW`、`whisk`、`furlines`）を先に作り、各獣はその組み合わせで描く。**目の作りを1か所に集約したので、12体の眼差しが揃った**。
- タイタン指摘の7種（子・丑・寅・辰・巳・午・戌）を作り直し。**丑は角を上へ反らせる／午は横のたてがみを削って耳を立てる**の2点で「別の動物に見える」問題が消えた。最初の版は丑の角が口ひげ、午は耳が垂れてヤギに見えた（実際に描いて初めて分かった）。
- **大きさの正規化**：`bakeOne()` が 320px で試し描き → `getImageData` で実描画範囲（αバウンディングボックス）を測る → その箱を出力キャンバスの98%へ拡大して中央へ置く。**「猫と同じ大きさに」は手で係数を合わせず、測って合わせる**。獣ごとに輪郭の張り出しが違うので、係数合わせでは永久に揃わない。
- 結果、札の中の絵は **約0.55R → 1.26R**（見かけで2倍以上）。猫も同じ経路で焼くので、盤上・選択画面・タイトルの3か所すべてで寸法が一致する。
- 盤の猫は `drawCatFace()`（その場描き）をやめて `bakeNekoSprite()` に統一。**同じ絵を2か所で別々に描いていると、片方だけ直して食い違う**。

### 曲BGM（Twelve_Symbols_Rising）

- **iOSは `<audio>.volume` を無視する**。音量を作れるのはWebAudioのGainだけなので、`createMediaElementSource(el) → bgmGain → master` に必ず通す。経路作成に失敗した環境用に `bgmRouted=false` の代替（`el.volume`／`el.muted`）も残す。
- 再生開始はユーザー操作の中だけ。`bindTap`→`unlock()`→`syncBgmVol()`→`play()` の順で、最初のタップ（「消せ」）で鳴り始める。`play()` の拒否は `catch` で握りつぶし、次のタップで拾う。
- **合成BGMは消さずに残し、`mp3State === 'fail'` のときだけ鳴らす**フォールバックにした。曲が読めない環境でも無音にならない。
- `preload="auto"` は **harnessで FAIL になる**（`リクエスト失敗: 1件`）。ハーネスの簡易サーバはRangeに応答せず、ページ終了時に取得中のメディアが中断され `requestfailed` として数えられるため。`preload="none"` にすると再生開始は変わらず（`play()` が読み込みを起こす）FAILだけ消える。**初回ロードで1.4MB落とさなくなる副産物つき**。
- 192kbps MP3 4.2MB → `afconvert -f m4af -d aach -b 64000` で **HE-AAC 1.4MB**。`<source>` は m4a を先、mp3 を後ろに置く（選ばれた方だけ落ちる）。公開実体 5.48MB で20MB鉄則内。

### タイトル・エンディング（和）

- タイトルは**縦組み**。横組みの題字が干支リングの文字に必ず当たるので、`writing-mode:vertical-rl` にして中央の細い一列に収めた。角書き「猫は残る。」は `row-reverse` で題字の左に添える（縦書きは右から左）。
- **`.ring span{position:absolute}` が落款の `<span>` まで掴んでいた**。落款が題字の真ん中に重なったのはこれが原因で、CSSは正しく見えるのに効かない。タグを `<i>` に変えて解決。**子孫セレクタで位置を決めている親の中に、別用途の同じタグを置かない**。
- WebKitで縦書き要素の高さが文字数どおりにならない件は `inline-size:max-content`（縦書きでは高さ）で固定する。
- 昭和レトロの部品（黄×黒のハザード帯、Dela Gothic One、ネオン枠）を全廃。**青海波の地・円相・麻の葉の帯・朱の角印・木札のボタン・奉書紙の書付**へ差し替え。エンディングは罫の入った和紙に墨の判定字＋朱の下線＋朱印「終了」。
