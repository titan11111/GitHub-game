## 1. これは何か

夜の廃墟を舞台にした一人称ウェーブ制スナイパー。ライブラリを使わず、Canvas 2D に
擬似3Dの透視投影を自前実装している。ゾンビは `x`（横）と `d`（奥行き）だけを持ち、
`焦点距離 / d` でスケールされて描画される。

## 2. 中核メカニクス

### 2-1. 焦点距離としてのズーム

スコープは画像の拡大ではなく **カメラの焦点距離の補間** として実装する。

| 状態 | 焦点距離 |
|---|---|
| 素の構え | 430 |
| スコープ | 1180 |

`S.zoom`（0→1）を毎フレーム補間し、`focal()` が返す値が投影式に入る。望遠圧縮が
物理的に正しく生じるため、覗いた瞬間に「遠くを狙っている」感覚が立ち上がる。

### 2-2. 呼吸ゲージ（本作の核）

**照準は常に画面中央に固定されており、動いているのは世界のほう**である。
手ブレは以下のカスケードで全ゾンビの画面座標へ伝播する。

```
息を止める(steady) → breath消費 → holdQ → amp → sway → camX → project()の全ゾンビ
                     ↓
                   gasp(息切れ) ──┘
```

```js
S.holdQ += ((canHold ? 1 : 0) - S.holdQ) * min(1, dt * (canHold ? 4.6 : 6.5));
if(S.breath <= .002 && S.steady) S.gasp = min(1, S.gasp + dt*1.5);
else                             S.gasp = max(0, S.gasp - dt*.42);
S.amp = (10 + S.zoom*26) * (1 - S.holdQ*.88) * (1 + S.gasp*1.30);
```

| 係数 | 値 | 意味 |
|---|---|---|
| 基礎振幅 | `10 + zoom*26` | スコープで **10→36（3.6倍）** |
| 息止め | `1 - holdQ*.88` | 最大88%減。**約0.35秒かけて効く**（瞬間切替にしない） |
| 息切れ | `1 + gasp*1.30` | 最大2.3倍。**溜まるのは速く、抜けるのは遅い** |
| 消費/回復 | `.42 / .30` | 空まで2.4秒、満タンまで3.3秒 |

**設計意図**: 救済策（息止め）が切れた瞬間に罰（息切れ）へ反転する。これにより
「寄せる→止める→撃つ→戻す」のリズムが強制的に生まれる。

**連動の可視化**（プレイヤーが自分の状態を目で確認できること）:
1. **銃が同じ `amp` で揺れる** — 息を止めると銃身が目に見えて静まる
2. **安定度バー** — `1 - amp/58` を呼吸ゲージの下に表示
3. **心音** — 残量が減るほど速く鳴る（`.30 + breath*.42` 秒間隔）
4. **ラベル** — 「呼吸」→「息を止めている」→「息切れ」

### 2-3. 群れのリズム（潮）

ゾンビの移動速度は 2 層で変調される。

**層1: 群れ全体の潮**

| 状態 | 速度倍率 | 持続 | 演出 |
|---|---|---|---|
| 静寂 `calm` | ×0.52 | 2.4〜4.2秒 | 冷たい暗青の靄・低いサイン波 |
| 進行 `march` | ×1.00 | 3.0〜5.4秒 | なし |
| 突進 `surge` | ×1.85 | 1.5〜2.6秒 | 赤い脈動・低域ノイズ・うめき声3重・振動 |

遷移は確率的だが偏らせてある。**突進の後は必ず緩み、静寂の後は突進が来やすい**
（`nextTide()`）。突進の解禁確率はウェーブ数とともに `.28 + wave*.05`（上限 .66）へ上がる。

補間は **加速5.5 / 減速2.6** と非対称。「急に走り出す」恐怖を優先している。

**層2: 個体の突進**

一体ずつ独立したタイマーで不意に踏み込む。倍率は種別ごと（歩行体2.05 / 走行体2.70 /
巨躯体1.35）、持続0.40〜1.10秒。55%の確率でうめき声を伴う。

最終速度 = `基礎速度 × 個体突進 × 群れの潮`

## 3. 敵

| 種別 | HP | 基礎速度 | 幅 | 突進倍率 | 歩幅 | 解禁 |
|---|---|---|---|---|---|---|
| 歩行体 | 2 | 26 | 46 | 2.05 | 1.00 | Wave1 |
| 走行体 | 1 | 58 | 36 | 2.70 | 1.55 | Wave2（30%） |
| 巨躯体 | 4 | 17 | 72 | 1.35 | 0.72 | Wave3（14%） |
| 肥大体 | 5 | 12 | 88 | **7.00** | 0.58 | 全Wave（**7体に1体**） |

速度はウェーブごとに `×(1 + (wave-1)*.11)`、個体差 `×(.85〜1.20)`。

### 反転種（2026-09-09 追加）

**3体に1体**が「反転種」として湧く。種別（歩行/走行/巨躯）とは直交する属性で、
どの種別にも付く。

- **出現比率**: 乱数ではなく通し番号 `S.spawnN % 3 === 0` で決める。
  必ず 1/3 になり、運で偏らない
- **配色**: 肌・服の色をビット反転（`255 - 各チャンネル`）する。
  歩行体 `#3f5638` → `#c0a9c7`。緑の群れの中で淡紫が1体だけ浮く
- **蛇行**: `z.x += cos(t * wf + ph) * wa * dt`（振幅 `wa` 210〜340 / 周期 `wf` 1.05〜1.80）。
  通常種の横揺れ（振れ幅 6〜29）に対し **291〜347** と一桁大きい（実測値）
- **狙い**: 見つけやすいが当てにくい。遠距離では横移動が小さく見えるので、
  引きつけるほど難しくなる

### 肥大体（2026-09-09 追加）

**7体に1体**。赤（胴・脚）と紫（肌・頭）の配色。基礎速度は全種で最も遅い 12 だが、
溜めのあと **99.6** まで加速する（実測。走行体の巡航 58 を超える）。

- **出現比率**: `S.spawnN % 7 === 0`。種別ごと差し替えるので反転種にはしない
- **比率の衝突**: 21体目は「7の倍数」と「3の倍数」の両方に当たる。そこで落ちた反転種は
  `S.invDebt` として次の非肥大体へ繰り越す。**肥大体 1/7 と 反転種 1/3 が両立する**
  （210体で実測: 肥大体30体・反転種69体）
- **3段の挙動**（実測値）

  | 段階 | 速度 | 長さ |
  |---|---|---|
  | 巡航 | 14.2 | 3.2〜6.4秒 |
  | **溜め** | 3.2（ほぼ停止・体が沈む） | 0.50秒 |
  | **猛ダッシュ** | 99.6 | 1.25〜1.80秒 |

- **溜めの予告**: 理不尽にしないため、突進の前に必ず 0.5 秒の溜めを置く
  - 見た目: 体が沈み込む＋**足元の赤い輪が広がる**（音を切っていても分かる）
  - 音: `growl()` が 36Hz → 98Hz へせり上がる。解放時に `roar()` ＋振動70ms
- **HP5 ＝ 装弾数5**。撃ち切るか、頭を1発で抜くかの選択になる


### 描画（2026-09-09 改修）

矩形の積み木から人体構造へ全面改稿した。

- **骨格**: 腰 `-.50h` / 肩 `-.795h` / 頭半径 `.072h`。頭の高さは全種別共通にして
  **ヘッドショット判定 `top + .21h` と幾何学的に一致させている**
- **歩容**: 膝・足首の2関節。`z.limp`（個体ごとの引きずり）で左右非対称に歩く。
  上下動も引きずり量に比例して不均等に跳ねる
- **姿勢**: 猫背の肩（`T.hu` で径が変わる球）、首の傾き `z.tilt`、走行体は腕を後ろへ振る
- **腕**: 上腕は服・**前腕は素肌**にして手までつながって見せる。手は体の前へ回り込み、
  奥行きぶん大きく描く（掴みかかる形）。近距離では指3本を追加
- **陰影**: 胴に縦グラデーション、月（画面右上）からの縁の光、血痕、ぼろ布のはためき
- **段階描画**: `h>40` で顎・眼、`h>88` でぼろ布・血痕・指。遠景はシルエットに留める

## 5. 銃の構え（2026-09-09 追加 → 同日 透視投影へ作り直し）

一人称のボルトアクション狙撃銃を画面右下に描画する。全てCanvasのプリミティブ。

### 5-0. 投影方式（2026-09-09 改修）

初版は**真横から見た側面図**を右下に貼っていた。世界は `f/z` の透視で描いている
のに銃だけ平面図だったため、正面のゾンビに対して銃口が画面の外を向いて見えた。

銃もローカル3D（`X=銃の右 / Y=銃の下 / Z=銃口方向＝奥`）で組み直し、
断面ごとに `f/z` で縮めて画面へ落とす方式に変えた。

| 記号 | 意味 | 値 |
|---|---|---|
| `GUN.f` | 銃専用の焦点距離 | 1150（世界の `focal()` より望遠にして前縮みを穏やかにする） |
| `GUN.zN` / `zF` | 銃床／銃口の距離 | 300 / 700（**銃口は銃床の 1/2.3 の大きさになる**） |
| `GUN.cant` | 銃のロール | 0.20rad |
| `GK` | 画面サイズ連動の倍率 | `clamp(min(W,H)/912, .40, .78)` |

- **軸の収束先は照準（画面中央）**。`gp(u)` の `u→∞` の極限が `(GX, GY)` になるので、
  銃身を延長すると必ず照準へ吸い込まれる＝「奥を狙っている」が幾何学的に保証される
- **据え位置は画面比率で持つ**（`nx/ny/fx/fy`、縦持ちは `tnx/tny/tfx/tfy`）。
  横長でも縦長でも同じ構図に落ちる。ローカル座標を直接持つと縦画面で銃が画面外へ出る
- **面の描き分け**: 視点は銃の左上後方にあるので、見えるのは**左側面と上面だけ**。
  上面 `#43574a`（月明かり）／左側面 `#0b100c`（影）で立体を出す
- **描画順**: 奥（マズルブレーキ）→ 手前（銃床）の painter's algorithm。Zバッファなし
- **反動**: `GDZ`（手前へ引く＝全体が大きくなる）と `GPT`（銃口が跳ね上がる。支点は肩＝`u:0`）

- **部品**: 銃身・マズルブレーキ・ハンドガード（放熱スリット）・バイポッド・レシーバー・
  排莢口・マガジン・グリップ（滑り止め）・トリガーガード・スコープ（マウント2点・
  対物/接眼・調整ダイヤル・レンズ反射）・銃床（チークピース・バットプレート）・
  ボルトハンドル・両手（指つき）・左前腕
- **呼吸連動**: `S.sway` と `S.amp` で銃身が揺れる。息を止めると**目に見えて止まる**
- **反動**: `S.recoil` を Z（手前）とピッチへ流す。平面回転ではなく奥行きで表現する
- **ボルト作動**: `S.cycle` に同期してハンドルが後退→前進（0〜45%で引き、45〜100%で戻す）
- **薬莢排出**: 発砲0.30秒後に排莢口の実座標から真鍮の粒子2つ＋金属音
- **装填**: `sin` カーブで銃を下げ、ロールを 0.22rad 足す
- **マズルフラッシュ**: 銃口の投影座標 `gp(1,0,0)` に描き、半径をその地点の縮尺に比例させる。
  **奥で光るので小さく鋭い**。全画面フラッシュと二重
- **スコープ時**: `(1-zoom)^.85` でフェードアウトする（覗いている＝銃は見えない）

## 5-B. 音（2026-09-09 全面改稿・Web Audio のその場合成）

**音声ファイルは1本も使わない。**全て `AudioContext` のノードから合成する
（この作品が 0.05MB で済んでいる理由）。

### バス構成

```
各音 ─┬─ dry ──────────────→ master → destination
      ├─ 残響(Convolver) ──→ master     ※IRもその場生成
      └─ 返り(Delay+FB) ───→ master     ※銃声のみ
```

- **残響**: `irBuf(2.1, 3.0)` でノイズ×指数減衰のインパルス応答を生成。
  立ち上がりを 14ms 遅らせて「壁が遠い＝廃墟が広い」を出す
- **返り**: 0.27秒ディレイ＋帰還0.34＋ローパス820Hz。向かいのビルから2〜3回返る
- **リミッターは入れていない**。`DynamicsCompressor` を試したが実測で **-13dB**
  持っていかれ音が痩せた（ピーク 0.898→0.205）。かわりに master を .72 にして、
  銃声単体 0.626 / 銃声＋唸り3体同時 0.767 のヘッドルームを確保している（実測）

### 個別の音

| 音 | 作り | 実測 |
|---|---|---|
| 銃声 | ①高域ノイズ48ms（クラック）②広帯域→170Hzへ閉じるノイズ（ボディ）③145→33Hzのサイン（腹） | ピーク0.626 / 尾1.10秒 |
| ゾンビの唸り | 鋸波＋かすれノイズ → **バンドパス3本のフォルマント**（あ／お／う／え）→ 距離ローパス → 定位 | 近0.0057 / 遠0.0009 RMS |
| 溜めの唸り | 鋸波 36→98Hz ＋ ローパス 190→940Hz を 0.46秒でせり上げる | — |
| 突進の号砲 | バンドパスノイズ520Hz ＋ 矩形波 124→50Hz | — |
| 着弾（頭） | バンドパス900→180Hz。**ゼロ交差 383Hz** ＝高く鋭い | ピーク0.069 |
| 着弾（胴） | ローパス700→120Hz。**ゼロ交差 83Hz** ＝低く鈍い | ピーク0.035 |
| 金属音 | バンドパスノイズ＋1.5倍音の矩形波（ボルト・装填・空撃ち・薬莢） | — |

### ゾンビの声が「群れ」に聞こえる仕組み

`groan(z)` はゾンビの実体を受け取り、3つを個体ごとに変える。

1. **距離で音量**: `.07 + near*.30`。近0.0057 / 遠0.0009 RMS ＝ **6.3倍差**（実測）
2. **距離で高域**: ローパス `460 + near*2400`Hz。遠いほどこもる
3. **横位置で定位**: `StereoPanner` に `(z.x - camX)/900`。
   実測の左右比 左 **135:1** / 右 **1:33**。姿が見えなくても居場所が分かる

母音・基本周波数（58〜98Hz）・ビブラート（4.5〜7.5Hz）は毎回ランダムなので、
同じ声が2回鳴らない。`createStereoPanner` が無い環境では定位だけ落ちる。
