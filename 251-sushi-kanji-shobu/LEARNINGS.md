## 2026-09-22｜客を黒い塊から顔のある2人にした

### 何をしたか

改修前の客は、CSS 2行の黒い角丸だった。

```css
.head{ position:absolute; bottom:0; width:30px; height:22px;
       border-radius:15px 15px 0 0; background:#0A1826; z-index:1; }
.head.a{ left:16%; } .head.b{ right:16%; height:17px; }
```

注文は吹き出し（`#bubble`）だけが喋っていて、**客本体は無言のシルエット**。
「待たせている相手」が人に見えていなかった。

これをインラインSVG 2体（常連の親父／若い女性）に置き換え、10通りの表情を付けた。
外部画像・外部フォント・追加リクエストはゼロ（通信量 0.05MB のまま）。

### いちばん効いた判断：**感情の状態を新しく作らなかった**

最初に考えたのは「表情用のステートマシンを別に持つ」だったが、コードを読んで捨てた。
この作品には、感情の出どころが**すでに全部揃っていた**。

| すでにあった値 | そのまま顔になるもの |
|---|---|
| `G.cur.wait / PATIENCE`（客の待ち時間） | 平常 → そわそわ → いらいら |
| `spawnOrder()` | 顔を上げて注文する |
| `pickFuda()` の正誤分岐 | 喜ぶ／面食らう |
| `giftTo()`・CPUの取得 | 相手側を向く |
| `finishNigiri()` | 頬張る |
| `wait <= 0`（客が帰る） | 怒って去る |

なので表情系が追加したのは `mood = {name, hold}` の2値と、既存の分岐に
`setMood(...)` を1行ぶら下げただけ。**ゲームロジックは1行も変えていない。**
`hold` が切れたら待ち時間から顔を導き直すので、「出来事の顔」と「状況の顔」が
自動で切り替わる。

> 再利用条件: 既存ゲームに表情・リアクションを足すときは、まず
> **「感情の根拠になる値がすでに動いていないか」** を探す。
> 大抵は残り時間・コンボ・ミス判定として既に存在していて、新しい状態は要らない。

### 描き分けの技術メモ

- 眉4種・目4種・口6種を**重ねて置き**、`#guest[data-mood="…"]` の属性セレクタで
  出すものだけ `opacity:1`。DOMの差し替え・再生成ゼロ（既存の「押下表現はクラス付替えのみ」と同じ思想）
- 体（`.fig`）と首から上（`.head`）を別グループにして、身を乗り出す／のけぞる／
  そっぽを向くを分離。SVGの `transform-origin` は**ユーザー単位で直接指定**した
  （`transform-origin:50px 70px`）。SVG要素の `transform-box` 既定は `view-box` なので、
  これが一番素直に効く
- 2人が同時に同じ動きをすると人形に見える。呼吸・まばたきの周期をずらし、
  反応の `transition-delay` を 0.07秒ずらした

### やらかしと修正

1. **撮影スクリプトがゲーム本体に負けた**
   表情を1つずつ固定して撮ろうと外から `data-mood` を書き換えたが、毎フレーム走る
   `applyMood()` と、進行中の `spawnOrder()` / CPU の `setMood()` に上書きされ、
   「joy を指定したのに order が写る」状態になった。10枚中6枚が別の顔だった。
   → **撮影用の別経路を作らず**、`state.paused = true`（veilは出さない＝画面を覆わない）で
   進行だけ止め、ゲーム本体の `setMood()` をそのまま呼ぶ方式に変更。10/10一致。
   *教訓: 検証のために本体と別の経路を作ると、検証していたのは別物になる。*

2. **客Aの口が口ひげと同化して「垂れたもの」に見えた**
   `order` / `oops` の開いた口が口ひげの直下に来て、暗い色同士がくっついていた。
   スクリーンショットを見るまで気付かなかった。→ 口ひげを2px上げ、口を下げて真円寄りに。

3. **WebKitが入っていなかった**
   `_tools/game-harness.mjs` は chromium を使うので気付かないが、iPhoneが主戦場なので
   表情の確認は WebKit で撮りたかった。`ms-playwright` に webkit-2287 しか無く、
   playwright 1.62 は webkit-2336 を要求して起動失敗。`npx playwright install webkit` で解決。
