# SPEC — 293｜IAI FLASH 一閃

- 作成日: 2026-09-06
- フォルダ: `293-iai-flash`
- ジャンル: 反射神経 / 居合
- 想定プレイ時間: 1回20秒〜2分

## 1. コアループ（何が面白いか）

1回の勝負が0.2秒で決まる。だからこそ「待つ時間」の緊張が全て。赤い偽の合図（フェイント）を混ぜたことで、単なる反射テストが読み合いになった。自分の反応時間がmsで出るので上達が数字で見える。

## 2. 操作

- 白い「斬」が出た瞬間にタップ: 抜刀
- 合図前のタップ: フライング（即敗北）
- 赤い「待」でのタップ: フェイントに釣られて敗北

片手・親指1本で完結。二本指操作・スワイプジェスチャ・長い説明文を必要としない。

## 3. ルール

- 相手より速ければ勝ち、遅ければ斬られて終了
- 相手の反応時間は撃破数ごとに 620ms → 170ms まで短くなる
- スコアは連続撃破数

## 4. 難易度カーブ

敵の反応時間 = max(170ms, 620 - 撃破数×34ms)。2人目以降フェイントが混ざり始める。待ち時間は1.1〜3.0秒のランダムで、待ちの長さから合図を予測できないようにした。

## 5. 手応え設計（ゲームデザイナー観点）

- 勝った瞬間に反応時間をmsでトースト表示（自己ベストが自然に意識される）
- 負けた理由（フライング／フェイント／遅い）を必ず言語化して結果画面に出す
- 夕暮れのシルエット構図・散る花びらで「待ち時間」を退屈にしない
- 相手の腕前をバーで可視化し、次が強いことを事前に伝える

## 6. 画面構成

- タイトル: 番号 / タイトル / 一行コンセプト / 操作3行 / 「タップでスタート」
- プレイ: 左上に撃破、右上にBEST、それ以外はゲーム画面
- リザルト: スコア / ベスト / ハイスコア更新演出 / 「タップでリトライ」

## 7. 技術

- 単一 `index.html`（共通ミニエンジンをインライン同梱）
- Canvas 2D / requestAnimationFrame / dt上限0.05秒でタブ復帰時の暴走を防止
- 音: WebAudioのオシレータ＋ノイズ合成（音声ファイル0本）
- 保存: localStorage にベストスコアのみ
- iOS: `touch-action:none` / `gesturestart`と`dblclick`のpreventDefault / safe-area padding / devicePixelRatio上限2.5
