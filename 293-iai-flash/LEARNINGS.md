# LEARNINGS — 293｜IAI FLASH 一閃

- 日付: 2026-09-06
- 位置づけ: 289〜298「片手で遊べる10本」の1本として新規制作

## 何をしたか

合図の一瞬に抜く、反射神経の真剣勝負。フェイントに釣られたら即敗北。

- 単一 `index.html`（外部CDN・画像・音声ファイルすべて0本）
- 10本共通のミニエンジン（入力・音・粒子・画面揺れ・タイトル/リザルト・localStorage）をインライン同梱
- BGMは音声ファイルではなく、WebAudioで4小節ぶんのサンプルをその場で合成し `AudioBufferSourceNode.loop = true` でループ

## 設計上いちばん効いた判断

勝った瞬間に反応時間をmsでトースト表示（自己ベストが自然に意識される）

### 自作プレイテスト（Playwright WebKit / 390×844 / 16秒間ランダム操作）

fps61 / コンソールエラー0 / ランダム連打では0撃破（＝フライング判定が効いている）

- タイトル → プレイ の遷移、ゲームオーバー → リトライ の復帰をスクリプトで実際に踏んで確認

### 追加検証（勝利分岐）

ランダム連打では原理上勝てないため、Playwrightでcanvasのピクセルを毎フレーム読み、
「白い合図だけ（g/r比 > 0.38）」を検出した瞬間にクリックする専用テストを実施。

- 結果: 41回の合図検知タップ → **5人撃破 / ベスト5が保存された**
- これで「勝ち・負け・フライング・フェイント」の4分岐すべてが実際に通ったことを確認
- 赤い偽合図では比率が上がらないため、テストは正しく釣られずに済んでいる

### `_tools/audit.mjs`（静的監査31項目）

- iOS適合8項目すべて ○（viewport / touch-action / user-select / タップハイライト / ダブルタップズーム防止 / safe-area / スクロール抑止 / WebAudio unlock）
- BGMループ設定 ○（`.loop = true` を検出）
- 20MB鉄則 ○（0.02MB）

## 未検証・正直に残すこと

- **iPhone実機では未確認**（検証はすべてPlaywrightのWebKitエンジン）。実機のタップ遅延・音の出方は別途 `/game-local-test` で見る必要がある
- 長時間プレイ（10分以上）でのメモリ挙動は測っていない
