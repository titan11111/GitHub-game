## 0. 結論（先に3行）

1. **見どころはバチ**です。脱力して振り下ろし、肘が開いたところで小指で握り込んで手首を返し、当たる直前にまた力を抜く。この **緩→締→緩** をアニメーションのタイミングで見せられれば、躍動感の大部分が出ます。[出典]
2. **光は「黒背景＋上後方からのスポット1灯」**が基本です。皮の縁と人の輪郭が光る逆光（リムライト）と、床にできる暖色の光だまりの2つで、写真の空気感はほぼ再現できます。[写真][出典]
3. **音はサンプルを使わず、膜の振動モードを合成**できます。基音にピッチが下がるエンベロープを掛け、倍音は非整数比にし、打った瞬間のアタックノイズを足す、の3要素で作れます。20MBの上限に影響しません。[出典][推定]

## 3. バチのデータ（最重要）

### 3-1. 物理仕様

| 項目 | 内容 | 根拠 |
|---|---|---|
| 標準寸法 | 直径約22mm × 長さ約400mm | [出典] Wikipedia「Bachi」 |
| 市販品の例 | 全長410mm、握り24mm、先端20mm（先へ向かって細くなる） | [出典] 鼓童ショップ |
| 大太鼓用 | 標準より長く太い。写真では前腕の約1.5〜2倍の長さに見える（推定で直径30〜40mm、長さ450〜550mm） | 傾向は[出典]、寸法は[推定] |
| 樫（かし） | 重くて硬い。大きな太鼓で厚みのある音が出る。小さな太鼓では高音が抑えられる | [出典] |
| 檜（ひのき） | 朴より少し硬く、安価 | [出典] |
| 朴（ほお） | 最も軽くて柔らかい。立ち上がりの鋭い短い音になる。大太鼓では軽すぎて「ぱたぱた」した音になる | [出典] |
| その他の材 | 楓・松・椈（ぶな）・竹 | [出典] |

→ **ゲームでの使い道**: 「バチの材」を選べるようにすると、音色（倍音の減衰と基音の強さ）と振りの重さ（アニメーションの慣性）を1つのパラメータで連動させられます。[推定]

### 3-2. 一打の動き（岩手県立大の研究、種市海鳴太鼓の指導法に基づく）[出典]

| 段階 | 体の状態 | アニメーション設計 [推定] |
|---|---|---|
| (1) 振り下ろし始め → (2) 肘の開き | **力を抜いて**腕を振り下ろす | ease-in（重力で落ちるような加速）。手首は柔らかく遅れてついてくる |
| (2) 肘の開き | **小指でバチを握り込みながら手首を返し**、バチを加速させる | ここで一気に角速度を上げる。バチ先の軌跡が鞭のようにしなる |
| インパクト直前 → (3) インパクト | 当たる直前に**再び力を抜く** | 接触は1〜2フレームで済ませ、すぐ跳ね返す（バチを皮に残さない） |
| インパクト後 | 跳ね返り | バチが反動で浮き、次の振り上げにつながる |

- **力が残っていると音が死ぬ理由**: 腕に無駄な力があるとバチが皮に触れている時間が長くなり、振動を邪魔して響きがなくなる。[出典]
- **指導者の5段階評価**: 1 フォームができていない → 2 フォームができている → 3 大きな音が十分出ている → 4 脱力ができている → 5 しなやかさ・バチがしなるような動き。[出典]
  - → この5段階は、そのままゲームの判定ランクやキャラクターの成長段階に使えます。
- **計測方法**: 手の甲と手首に9軸モーションセンサーを付け、200fpsの映像と同期して計測。「肘の開き」と「インパクト」は、手の甲の角速度がゼロを横切る点と一致した。[出典]
- **体幹**: 腕を激しく振る演奏では、体幹、特に腰を安定させることが課題になる。体がぶれると打点が中心から外れる。[出典] 人工知能学会 2016 の和太鼓関連発表（検索結果の要約で確認。本文は未読）

### 3-3. バチの見せ方 [推定]

- 振り上げの頂点で **3〜5フレーム止める**（ため）→ 振り下ろしは **2〜3フレーム**で一気に。この速度差が「躍動感」の正体です。
- 振り下ろし中のバチには **スメア（残像の帯）** を付ける。過去3〜5フレーム分の位置をつないだ半透明の三角形帯で十分です。写真のブレがこの表現にあたります。
- インパクトの瞬間に、①皮が凹む、②画面が1〜2px揺れる、③皮の上に光の輪が広がる、の3つを同時に出すと「当たった」感触が伝わります。

## 4. 音のデータ

| 項目 | 内容 | 根拠 |
|---|---|---|
| 大太鼓のモード | 両面の膜が連動する(0,1)モードのペアが、高湿度で約168Hz/193Hz、低湿度で約202Hz/227Hz。(1,1)モードは約333Hz、(2,1)モードは約468Hz | [出典] Rossing |
| 湿度 | 湿度が上がるとピッチが下がる（皮がゆるむ） | [出典] Rossing |
| 倍音の比 | 膜の振動モードは整数倍にならない（ベッセル関数の根の比に近い） | [出典] Rossing、Ando |
| 低域 | 長胴太鼓の打撃は200Hz以下に大きなエネルギーを持ち、強く打つほど音圧が上がる | [出典] Inter-Noise 2021 |
| ピッチの下がり | 強く打つと膜の張力が一時的に上がり、減衰とともにピッチが下がる（タムの特徴的な音色の要因） | [出典] Marogna ら（タムでの研究。和太鼓に当てはまるかは[推定]） |
| 胴の空気 | 胴の中の空気が基音のモードを最も大きく持ち上げる | [出典] 太鼓膜一般の研究 |

### 合成レシピ（Web Audio）[推定]

```
基音   : sine  f0 ≈ 60〜90Hz（体で感じる低音。170〜200Hzの実測値は「音の芯」として別に重ねる）
         ピッチ: 打った直後に f0×1.3 → 80ms で f0 へ下げる、減衰 1.5〜2.5s
倍音   : sine × 3〜4本、比 1 : 1.59 : 2.14 : 2.65（膜のベッセル比）、各 0.3〜0.8s で減衰
アタック: 帯域通過ノイズ（1〜3kHz）を 10〜20ms → バチが当たる「パン」
強弱   : velocity で 音量・f0の初期上昇量・アタックの明るさ を連動
縁打ち : 「カッ」= 基音なし、高域ノイズと木の共鳴（800Hz〜1.2kHz）を短く
```

- 口唱歌（くちしょうが）: ドン（面の中心）、ドコ（2連打）、カッ（縁打ち）、ス（休符）。譜面データをこの記号で書けば、そのままリズムゲームの譜面になります。[推定・一般知識]

### 3Dライティング設計 [推定・写真ベース]

| ライト | 位置・色 | 役割 |
|---|---|---|
| キー（SpotLight） | 太鼓の上方・やや奥、色温度3200K相当（暖白） | 皮の上半分を照らし、人物の肩と髪に縁取りを作る |

## 7. 人間の躍動感 [推定・写真＋出典]

- **下半身は固定し、上半身で打つ**: 足を大きく開いて腰を落とす。固定した太鼓を叩く演奏では足をほとんど動かさない。[出典]
- **ひねりの連鎖**: 腰 → 胸 → 肩 → 肘 → 手首 → バチ先、と遅れて動く（野球の打撃の研究と同じ、近い関節から遠い関節へエネルギーが伝わる流れ）。[出典] 川村ら（野球）からの類推
- **呼吸**: 振り上げで胸が上がり、打つ瞬間に息を吐く（腹が締まる）。待機中も 2〜3秒周期で上体をわずかに上下させる。
- **視線**: 打面の中心を見続ける。頭は打撃のたびに少しだけうなずく。
- **2人の対比**: 手前の奏者は大きく速く、奥の奏者は半拍ずらして控えめに動かすと、画面に奥行きが出る。

## 8. iPhone で実装するための制約

- 20MB鉄則: 音を合成すれば音声ファイルは0MB。人物はローポリ（1体 3〜5k三角形）＋ボーン12本程度で足りる。
- 影は1灯分（キーライト）だけ。shadowMap 1024。
- スメアと霞は加算合成メッシュにし、ポストエフェクトは使わない。
- 入力は Pointer Events に統一。左右の親指 = 左右のバチ。
